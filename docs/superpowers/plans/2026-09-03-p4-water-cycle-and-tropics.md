- [x] Task 0 —— 蒸发闭合分解与海陆比实测
      探针加 `[evap]` 行（海面平均风速、海气比湿差、海面蒸发）；语料写入器每个

- [x] Task 1 —— 水汽柱质量与凝结阈值（设计 §3）
      比湿是近地面值却按干空气柱质量换算成水量，可降水量与滞留时间双双偏大 2.6 倍。
      新增 `ClimateLayerLayout::moisture_column_mass_per_area`，对模型自己的饱和
      曲线沿标准大气廓线积分，不引入新系数；所有比湿到水量的换算改用它。
      只改一半会让降水塌到 1.02——阈值 0.9 本来就是靠偏大的水量撑着的，而 0.9
      出自 SPEEDY 的层状云闭合，SPEEDY 另有对流方案。阈值改锚在水汽滞留时间
      （Trenberth et al. 2007，约九天）上。
      改到一半又露出两处耦合，都已一并修：湿焓守恒的焓曲线要按 M_q/M_dry 缩放
      （§3.6，修后滞留 10.1 → 9.5 天、降水 2.563 → 2.685）；配对水汽的相对门与
      A4 §6.4 的热量同型病态，分母改为"配对量 + 外部水汽通量"（§3.7）。
      阈值最终取 0.70 而非 0.65：两者滞留都在观测区间内，0.65 在 Standard 多花
      一轮、破 60 秒线（§3.8）。
      发布态：可降水量 65.6 → 25.6（地球 25），滞留 23.0 → 9.5 天，降水 2.685
      （GPCP 2.81），副热带干带出现，时延 Draft 19.0 / Standard 57.5 秒。
      方程指纹 v14 → v15。

- [x] Task 2 —— 经向翻转环流（设计 §4）
      探针加 `[circ]` 与 `[qflux]` 两张表实测成因：低层在赤道与 ±30° 之间**向极**
      流动（埃克曼漂移），是涡动扭矩施加在低层的必然结果，任何热力项都压不过它；
      而把扭矩挪出低层会让海面风塌到 1 m/s（§4.2）。热力直接环流本来存在，被
      两层各自厚度松弛下的层界面回推压小了两个量级（§4.3）。
      设计：轴对称斜压厚度闭合——两层大气辐散厚度倾向的纬向平均斜压部分当作
      穿过层界面的质量交换（Vallis §3.4 模分解、Gill 1980、Betts–Miller），不引入
      新常数，只在每宏步一次的声明慢倾向里闭合（快内核零成本），柱质量账本不变；
      只闭合纬向平均，因为全尺度闭合会拆掉格点尺度湿反馈的唯一刹车（§4.4）。
      收尾撞出两件事（§4.8）：一个 Standard 种子踩到 P5 投影的厘米刀锋（分类器
      按厘米取整，投影态在 f32 上重解海平面），`to_wire` 改为只对超出一个量化
      厘米的差异报不符；首版闭合放在快内核每级，时延超标，改为慢倾向后回到预算。
      发布态（探针）：低层支 ±15° 内向赤道（7.5° N −2.29 m/s）、上层支向极、赤道
      低层辐合 −3.1e-6/s；赤道降水 1.81 → 4.37 / 3.21；海面风 5.37 → 6.12（地球
      6.6）；全球 P 3.06（越过 GPCP 包络上限 1.7 %）、E 3.18、滞留 8.4 天。
      未闭合并交裁定（§4.6）：输运界限的全局重分配抹掉 6–10 mm/day 的辐合水量，
      而就地降下（Kuo）在本模型触发 CISK 塌层，要等能量账本加位能或先验换成
      无输送先验；环流与信风强度为地球 4 倍，根在涡动扭矩幅度（10 倍）。
      方程指纹 v15 → v16。
      语料 / 扫描 / 时延：见下文收尾验证。

- [x] Task 2b —— 辐合水汽就地凝结，潜热按弱温度梯度平衡输出（设计 §5）
      用户裁定先修机制缺口。水汽输运改为保留通量形式两侧的超出与不足（辐合带进
      来的水、下沉稀释），不再全局重分配；超出量就地作对流凝结（Kuo 1965），其
      潜热不落任何一层而记为翻转环流位能的显式外部输出（WTG，Sobel et al. 2001；
      契约 §6.1 的先验已含该输送），能量账本闭合门不变。探针：全球 P 3.062 →
      2.886（回到 GPCP 包络内），辐合带（5° S）降水 4.53 → 6.62，副热带 22.5° N
      6.08 → 5.48，滞留 8.8 天，无 CISK。未闭合：热带外涡动水汽扩散 1e6 m²/s 把
      辐合带约 3 mm/day 的水往外搬（§5.4）。方程指纹 v16 → v17。收尾又撞出一处
      P5 刀锋：投影把终态实现水量写进了本该携带 P3 库存的字段，束校验与质量阶段
      逐位比较时一个种子差一个 ULP（256 m³）；改为投影写入库存本身（§5.5）。
      语料 / 扫描 / 时延：见收尾验证。
