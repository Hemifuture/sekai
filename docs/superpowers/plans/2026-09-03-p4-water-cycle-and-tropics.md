## 任务队列

- [x] Task 0 —— 蒸发闭合分解与海陆比实测
      探针加 `[evap]` 行（海面平均风速、海气比湿差、海面蒸发）；语料写入器每个
      种子加 `land=`。实测推翻"风偏强"的前提：风 5.11 / 5.76 m/s 低于地球 6.6，
      偏大的是饱和差，两者相乘给出接近地球的海面蒸发（设计 §1.1）。海陆比均值
      0.286 与降水相关系数仅 +0.16，湿偏差不是海陆比造成的（§1.2）。同时查明
      语料与探针是两条管线（§1.3）。

- [ ] Task 1 —— 湿度垂直结构
      单层湿度同时充当"近地面比湿"（体块蒸发的供体）与"柱平均湿度"（凝结的判据），
      两个角色互相矛盾，是 §1.1 那对补偿误差的根源，也是赤道辐合带的前置之一。
      C2 已有上层比湿，需要的是把两层的角色分清并给出诊断的近地面值。

- [ ] Task 2 —— 经向翻转环流
      赤道辐合带的另一个前置。`diagnose_axisymmetric_circulation` 只给纬向涡动
      动量加速度，没有翻转支。

- [ ] Task 3 —— 辐射先验的纬度结构
      行星反照率随纬度（NCC 1981 `a(x)`）、温室偏移随水汽（Manabe & Wetherald
      1967 固定相对湿度）。代价是 17 seed 语料重标定。解锁海冰接进物理与显式
      经向输送（A4 §4.3、§4.4）。
