## 任务队列

- [x] Task 0 —— 蒸发闭合分解与海陆比实测
      探针加 `[evap]` 行（海面平均风速、海气比湿差、海面蒸发）；语料写入器每个
      种子加 `land=`。实测推翻"风偏强"的前提：风 5.11 / 5.76 m/s 低于地球 6.6，
      偏大的是饱和差，两者相乘给出接近地球的海面蒸发（设计 §1.1）。海陆比均值
      0.286 与降水相关系数仅 +0.16，湿偏差不是海陆比造成的（§1.2）。同时查明
      语料与探针是两条管线（§1.3）。

- [x] Task 1 —— 水汽柱质量与凝结阈值（设计 §3）
      比湿是近地面值却按干空气柱质量换算成水量，可降水量与滞留时间双双偏大 2.6 倍。
      新增 `ClimateLayerLayout::moisture_column_mass_per_area`，对模型自己的饱和
      曲线沿标准大气廓线积分，不引入新系数；所有比湿到水量的换算改用它。
      只改一半会让降水塌到 1.02——阈值 0.9 本来就是靠偏大的水量撑着的，而 0.9
      出自 SPEEDY 的层状云闭合，SPEEDY 另有对流方案。阈值改锚在水汽滞留时间
      （Trenberth et al. 2007，约九天）上。
      改到一半又露出两处耦合，都已一并修：湿焓守恒的焓曲线要按 M_q/M_dry 缩放
      （§3.6，修后滞留 10.1 → 9.5 天、降水 2.563 → 2.685）；配对水汽的相对门与
      A4 §6.4 的热量同型病态，分母改为"配对量 + 外部水汽通量"（§3.7）。
      阈值最终取 0.70 而非 0.65：两者滞留都在观测区间内，0.65 在 Standard 多花
      一轮、破 60 秒线（§3.8）。
      发布态：可降水量 65.6 → 25.6（地球 25），滞留 23.0 → 9.5 天，降水 2.685
      （GPCP 2.81），副热带干带出现，时延 Draft 19.0 / Standard 57.5 秒。
      方程指纹 v14 → v15。
