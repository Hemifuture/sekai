# T0 测高校准计划（2026-08-21）

## 背景

2026-08-19 地形审计确立、M2 收官后仅存的 T0 质量根因："世界没有
低地"。草稿档实测陆地高程 p05/p25/p50 = 354/786/1204 m（地球约
10/200/550 m），海平面反解到参考零点下方 1363 m，大陆呈 400–2000 m
的高原世界；阶梯色带里绿色低地级几乎无面积即此病征。诊断阅读把成因
收敛为三候选：P3 台地-海面偏移（干舷未对实际海面闭环）、P2v5 陆壳
厚度分布过窄、P5 形成视界（100 kyr）不足以做出侵蚀-沉积低地。

本任务改 T0 产物 ⇒ **全链指纹与证据刷新**，故从 M2 隔离为独立
里程碑。设计草案（含验收包络、候选杠杆 L1–L4、科学锚与开放问题）：
`docs/superpowers/specs/2026-08-21-t0-hypsometric-calibration-design.md`。

依 AGENTS.md：算法产出上屏且用户亲自验收方为交付；参数一律科学
来源锚定；每任务一提交；提交前 fmt / clippy -D warnings / wasm /
受影响套件，收官全量调试回归。

## 任务

- [ ] Task 1 —— 诊断归因：扩展 `terrain_audit_probe` 输出
      ① P3 primary-relief 自身测高分位与其浴缸海面；② 陆地格元
      v5 陆壳厚度 CDF（对照 CRUST1.0 形状）；③ P3→P5 逐分位位移
      （归因 P5 改形量）；④ 洋盆-水量记账（海面为何 −1363 m）。
      产出：三成因份额结论 + 最小杠杆集建议，写入设计草案 §2/§8。
      验证：探针可重复、数值入档；不改任何产品代码。
- [ ] Task 2 —— 目标精锚与规格冻结：从 ETOPO 2022（或 ETOPO1）
      陆地 CDF 精锚 §3 包络带数值；按 Task 1 结论定杠杆集与常量；
      科学自审后交用户确认冻结。冻结即记录预期的指纹刷新清单。
      验证：包络值有数据出处记录；开放问题 §8 全部闭合。
- [ ] Task 3 —— 杠杆实施：按冻结规格实施（预期 L1 干舷闭环 +
      L3 形成纪元时长为主，L2/L4 仅在归因要求时启用）；新增测高
      包络门禁进入 surface-formation 产品套件；P5 既有六项形态
      门禁与沉积账本闭合（≤1e-8 / ≤1e-7）保持通过。
      验证（UI）：草稿档世界重建后，色带出现连片绿色低地与海岸
      平原；河流入海处有低缓地形；山脉长尾仍在。
- [ ] Task 4 —— 指纹与证据刷新：P3/P4/P5 阶段指纹、演化与 P5
      completion 证据数值、T1 v2 层级探针指纹、受影响 GPU 金样，
      全部按修订记录刷新；标准档证据重录一次。
      验证：全部门禁套件绿；刷新前后对照记入规格修订。
- [ ] Task 5 —— 门禁与验收：fmt / clippy -D warnings / wasm /
      发布档全量 + 调试档收官回归；计划核对；用户验收步骤（地图
      与球体各档位视察低地/海岸/色带）；交付报告 artifact 增补。
      验证：门禁全绿；最终验收归用户。

## 非目标

- 不动陆地占比语义与全球水量常数。
