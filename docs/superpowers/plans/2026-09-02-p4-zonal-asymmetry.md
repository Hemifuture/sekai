## 任务队列

- [x] Task 0 —— 度量 `near-surface-wind-non-zonal-variance-fraction`
      基线（Draft seed 42）：**0.0139**；陆 / 海偏离均方根 0.93 / 0.92 m/s。
      年平均近地面风偏离 5° 纬带面积加权平均的方差占比；只记录不设门。新增
      `tests/wind_asymmetry_probe.rs`（ignored / Release）打印 Draft seed 42 的该
      度量与纬带剖面，作为每个任务的前后对照。

- [x] Task 1 —— 低层大气连续方程带地形
      实测（seed 42）：0.0139 → **0.0338**，陆 / 海偏离均方根 0.93 / 0.92 →
      2.10 / 1.10 m/s；纬带剖面不变（信风 −12.0，西风 +5.8），求解稳定。
      `z_b = land_fraction · max(elevation − sea_level, 0)`，钳制 `H_ref − z_b ≥ H_ref/6`；
      快、慢两条连续路径的施主厚度改为 `H_ref − z_b + η`。方程指纹 v9 → v10。
      验证：Task 0 探针前后；P4 套件。

- [x] Task 2 —— 陆海 Rayleigh 摩擦对比
      `r_lower = r_sea · (1 + (ρ − 1) · land_fraction)`。seed 42 扫描（叠加 Task 1）：

      | ρ | 非纬向占比 | 陆 / 海偏离 m/s | 17.5° 信风 u（北 / 南） |
      | ---: | ---: | --- | --- |
      | 1（Task 1） | 0.0338 | 2.10 / 1.10 | −12.03 / −12.11 |
      | 2 | 0.0344 | 1.56 / 1.07 | −9.73 / −10.38 |
      | **3** | **0.0463** | 1.52 / 1.16 | −8.37 / −9.28 |
      | 4 | 0.0624 | 1.62 / 1.30 | −7.61 / −8.71 |

      钉 ρ = 3（设计 §5 的草地保守值）。副产物：过强的信风峰从 −12.4 降到
      −8.4 m/s，更接近地球年均信风 −6 ~ −7；南北半球出现可分辨的差异。

- [x] Task 3 —— 语料验证与收尾
      32 seed 冷启动扫描（Draft 24、Standard 8，多大陆、活跃）**32/32 通过**。
      17 seed 气候证据（Draft）：新度量 0.041–0.059（均值 0.047，基线 0.014）；硬门
      （水循环 3.8 %、TOA 6.8 W/m²）全过；`ocean-current-land-leakage` 均值 0.45 →
      0.38 m/s（仍 17/17 失败）。**两项变差**，如实记录：
      - 全球降水 2.80 → **2.56 mm/day**（GPCP 2.81），蒸发 2.91 → 2.66：信风峰从
        −12.4 降到 −8.4 m/s 后体块蒸发随风速下降。此前与 GPCP 的吻合建立在偏强
        一倍的信风上，是被补偿掉的误差；体块蒸发的风速参考（层平均风 vs 10 m 风）
        与传输系数归 P4 水热校正重新标定，本里程碑不做事后修形。
      - `orographic-rain-shadow-leeward-drying` 失败 1/17 → 9/17，`orographic-uplift-
        enrichment-ratio` 6/17 → 7/17：气流开始绕山而不是翻山，跨山气流减少。
        地形降水项按跨山风分量计算，绕流物理上正确但度量包络是按"翻山"钉的，同样
        交 P4 水热校正。
      产品级时延（应用关闭后）：Draft 22.1 s（不变），Standard 63.4 s（此前 51.2；
      终点 P4 5 → 6 轮，且机器仍有残余负载，需空闲时复测）。P4 设计文档方程节已改。
