# 潜在植被带 V1

1. 从本地 c21a62c 的独立工作区测量真实年温雨，核对分区数据与适用范围，冻结规格。
2. 在 Atlas 当前态中绑定 C2、分类与产物身份，用图内、共边、图外夹具验证。
3. 接入原生二维和球体填色、细床水面遮罩、点选与月度证据，复核海湾、首帧与新增成本，打开窗口供玩家验收。

## 每项承重技术的出处

- C2 年量归约见 `climatological_monthly_mean` 和 `climatological_annual_total_mm`。
- Ricklefs（2008）图 5.5，Stefan 的 plotbiomes 数字化，Navarro 等（2025）的最近多边形分类。版本见同期规格。
- 细床水体与显示层级见 2026-11-03 真值范围规格 R2、R3 和 2026-11-18 海岸验证记录。
