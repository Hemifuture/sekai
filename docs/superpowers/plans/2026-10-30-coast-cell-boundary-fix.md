# 六边形水岸修复：复用细域同源链

用户已要求修复放大后的六边形海岸。工作区沿用 coast-climate-spike，基线
`0b8b10b`，保持程序化初态、当前气候模型和目标陆比 25% 场景。

## 根因与修复边界

`flat_color` 把父格元的离散水类传给色板，Ocean/Lake 整格涂水，DryLand
低于海面时仍钳到绿色。只更换色板、增加细分或模糊边界均不能解决。
渲染、拾取和河口必须读取同一叶片的高程与水类，边界锚点复用 P5 的 P1 几何。

复用现有 LOD-1 至 R3 的代码，不导入该分支前置气候降阶、不导入其后 R4–R7
尚未完结的湖模型研究。湖 R3 已有局部直岸遗留，必须在本场景近景检查，不得
称任意湖形态都已科学验证。来源实现需在本分支重新验证，旧探针指纹不能照搬。

## 依赖与验收

复用批次优化需新增直接依赖 `rustc-hash`（已在 wgpu 依赖图中），用于内部小整数
键的湖游走缓存。来源 a362843 有深层批次耗时实测与回退记录；本轮不宣称相同
加速比。不得新增无人消费的缓存层或测试专用生产 API。

UI 在当前实验预设 Draft/42、目标陆比 25% 上验收：海岸不再锁死在父格边，
点击派生水类与画面一致，河线在可见水边终止。用户最终确认前不声称视觉验收完成。
