# 生成时延里程碑 A1 实施计划（2026-09-02）

上位：`AGENTS.md`；设计真相
`docs/superpowers/specs/2026-09-02-generation-latency-design.md`。

目标：Draft 全链 10–20 s，Standard ≤ 60 s（用户 2026-09-02）。基线 44.0 s /
77.3 s，P4 的两次求解占 88 %。一任务一提交，提交前跑 fmt / clippy / wasm 门禁。

## 任务队列

- [x] Task 0 —— 分阶段计时探针
      `causal.rs::timing_probe::stage_timing_probe`（ignored / Release，
      `SEKAI_PROBE_PROFILE` 选档）逐阶段打印 P1–P5 与两次 P4 的耗时和求解报告，
      `SEKAI_PROBE_TAG` 可把两次气候快照落盘供逐场对比。它产出了设计 §1 的基线
      与 §3.3 的扫描表。

- [x] Task 1 —— 快子步 Courant 目标 0.2 → 0.5 → 0.8，删除 1200 s 上限
      三处重复常量收敛到 `src/world/natural/global_circulation.rs`；世界层契约的
      「每宏步 ≥ 6 快子步」字面量改为从自转限推导（0.5 → 3，0.8 → 2）。设计 §3。
      先钉 0.5（Draft 全链 44.0 → 26.0 s；场差异 ≤ 0.37 %，P4 14 个二进制全绿）；
      Task 2 撤回后改钉 0.8 以补回预算（设计 §3.4：32 seed 冷启动扫描）。

- [x] Task 2 —— **终点 P4 热启动：实施后按扫描撤回**
      热启动（`67e8186`）实测 Draft seed 42 全链 26.0 → 16.5 s，但用户在应用里
      「新种子并重建」后构建失败。无头扫描用户设置（Standard、多大陆、活跃）：
      8 个随机 seed 中 5 个失败 `annual formation residual increased`，Draft 24 个
      中 1 个；其中两个是真正的失稳（残差 0.076 → 2.87、0.069 → 2.92，降水冲到
      11.5 mm/day）。逐轮日志：热启动首轮 E=3.02 / P=2.07（地形只动数米而降水跌
      22%，即设计 §6 问题 4 的瞬态敏感性），湿度预处理一步把 P 推到 3.27 越过 E，
      此后 P、E 一起失控，预处理停止后仍以每轮 ×1.6 发散——模式在高湿态的正反馈
      失稳，冷启动的轨迹恰好不经过该区域。撤回热启动（`generate_continuing`
      一并删除，YAGNI）。记入设计 §4.4 与 §6 问题 6。

- [x] Task 3 —— **编译配置按实测关闭，不改**
      `opt-level = 3 + lto = "fat" + codegen-units = 1` 的产品级全链（含质量评估）
      实测 Draft 19.2 → 22.3 s、Standard 53.4 → 59.5 s，两档都**变慢**约 15 %，
      构建时间 3 min。保持 `opt-level = 2`。

- [x] Task 4 —— 快张量的瞬态梯度输出改用普通投影
      原计划的簿记清理（张量分配、RK 合成的常量标量场重算、逐格线性查找层）实测
      两次求解合计 2.3 s / 44 s，且子步数已减 2.3×，不值得做。改做另一项实测出的
      热点：快张量的梯度输出每格都跑「可表示切向量」迭代修正（2 轮 × 3 分量 ×
      4 候选），而它只喂一个瞬态 RK 阶段加速度，设计本就规定瞬态量用普通投影、
      只有最终发布场保留严格修正。改后 Draft P4 起点 8.1 → 7.1 s，全链 16.6 →
      15.0 s；场差异 ≤ 0.07 %，循环数与残差不变。公开的 `gradient()` 路径不动。
      验证：门禁 + P4 套件 + 环流算子/稳态/瞬态套件 + P5 质量。设计 §5b。

- [x] Task 5 —— 产品级时延门与证据刷新
      产品级实测（走生产 stage graph，含质量评估与束校验），热启动撤回、CFL 0.8
      的最终态：**Draft 21.9 s（终点 9 轮），Standard 51.2 s**（seed 42）。32 seed

世界…已用 N 秒」：

1. Draft 档约 20–25 s 出图（产品级实测 seed 42 为 21.9 s；seed 间波动 ±5 s，
   目标 10–20 s **未完全达成**）。
2. Standard 档应在 60 s 内（产品级实测 51.2 s；最慢的扫描 seed 约 66 s）。
3. 字段目录选**年降水**、**近地面风**、**海表温度**：与改动前同 seed 的图相比，
   大尺度形态应一致（P4 的场差异 ≤ 1.2 %，海流最大）。
