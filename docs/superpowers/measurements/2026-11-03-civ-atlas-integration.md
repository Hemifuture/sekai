## 保留的限制

固定床面接入现有C2与当前已解析水文，不启用二次侵蚀演化。湖蒸发、地下水及长期
稳态未建模；两个气候质量建议（风跳变、季节半球相位）仍不满足。WASM构建不是
浏览器运行验收。没有独立复算全球千万面支持图的Euler、逐面库存或全部终端通量；
具体已有构造、引用／有限域／身份／汇总预算检查范围见A7。

截图通道和窗口激活曾多次失败；其失败不记为UI通过。尚需补齐降水／风／河网显示
的实际操作及用户本人视觉确认。完整性能目标与科学质量目标仍开放，不标记整体交付。

## 用户验证

从主目录运行 `cargo run --release --bin sekai`，或启动 `target/release/sekai.exe`。
新建项目选择Civ Atlas，按当前参数重建；查看地表、气候与河网，点选海陆、打开站点
气候，再保存和重开配方。旧来源配方仍保留原来源语义。
