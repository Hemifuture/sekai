# 潜在自然植被带 V1 验证

## 真实气候与图域

先于分类实现，在本地基线 `c21a62c` 上生成种子 42、Draft，对每个来源格调用生产的年温雨归约。按干陆比例大于零筛选的原始分位数见[设计规格](../specs/2026-11-18-biome-v1.md)。未使用降水字节值、面向种子的阈值或输出比例目标。

原始普查按来源格顺序输出制表符分隔的干陆比例、年均温和年降水三列，无表头。Rust Display 格式，LF 换行。文件 SHA-256 为 `346529d31da30c2250ce329558742bfb7d119b40e7747ffa75664923621c972c`。

在相同配方上，新产物的完整指纹为 `c6f6bf44071195680f01d1beaaf48e6218b89868528b8d7c0c54a58c90073e20`。13,267 个含干陆格中，3,322 个（25.0%）位于原图之外，点选标明由最近分区推定。下列数量按来源格计数，混合格与纯陆格各计一格。

- 苔原 1,655，北方针叶林 1,053，温带草原／荒漠 2,781。
- 疏林／灌丛 996，温带季节林 1,457，温带雨林 896。
- 热带雨林 895，热带季节林／稀树草原 1,477，亚热带荒漠 2,057。

Atlas 原子发布阶段使用 `ATLAS_CURRENT_VERSION`。旧配方保存的阶段版本有差异时走原有升级副本流程。细床和气候强迫继续使用自身指纹。全球只生成一份来源格分类与图外标志。叶片用一个 32 位属性选择已有 GPU 来源格字段或水色。切换植被与高程复用同一批已安装几何。

## 混合岸格与点选

高程与植被共用实际显示叶片的细床采样。来源格面积求积的扇心是原始站点，显示扇心是几何质心。在一个极小湖缘上，来源格求积记录了湖面，而同级显示叶片中心均落在干陆。此处点选应报告所绘叶片的干陆。原格面积比例仍来自求积。离线核对各选一处干湿面积都充分的海岸格和湖岸格，同时检查细床水类、GPU 顶点来源、点选类别与月度读数。

种子 42 的实际见证如下。

- 海岸格 33192 的干陆是亚热带荒漠，年均温 20.6 °C、年降水 47.9 mm。同格的海洋叶片读作水面。
- 湖岸格 18536 的干陆是温带季节林，年均温 13.0 °C、年降水 1993.2 mm。同格湖泊叶片读作水面。
- 另一个湖缘格 10715 的干陆为苔原，年均温 −29.7 °C、年降水 451.8 mm，检查面板标为图外推定。

## 原生画面与成本

同机 RTX 4080 SUPER、Vulkan、1280 × 720。使用生产 TemplateApp 与独立原生窗口，两个配方串行冷启动。首帧口径为生成请求到首次提交完整世界帧，包括当前视图 LOD 与 GPU 安装。

- 种子 42、Draft、二维 Equal Earth，首帧 18.855 s，C2 为 9.705 s，海岸连通为 5.449 s，植被段为 54 ms（包含已有的初始水量求和），GPU 安装为 60 ms。首帧提交后首次进程采样的峰值工作集为 631,042,048 字节。原基线为 18.892 s、611,614,720 字节。两个单次首帧相差 0.037 s，落在基线复测波动内。地图选中来源格 1072，温带季节林色与原生读回像素一致。点选报告 5.6 °C、1240.0 mm 和十二个月的温雨。[原生点选截图](assets/2026-11-18-biome-v1/map-inspector.png)
- 种子 27276201、Standard，球面相机对准南纬 29.86269°、东经 60.05317°，缩放与 R3 见证相同。首帧 17.527 s，植被段为 53 ms。与 c21a62c 高程视图逐像素比较，944 × 637 区域的 350,555 个海水像素位置完全相同。其余 250,773 个像素为亚热带荒漠色，GPU 回读为图例的 sRGB `#DCBB50`。[原生海湾截图](assets/2026-11-18-biome-v1/bay-globe.png)
- 验证时首次读回发现原生非 sRGB 附件直接呈现线性图例分量。现按目标附件在调色板上传时完成必要的 sRGB 编码。干陆分类、图例与地图的颜色对应，水色和海岸位置可用前述 R3 画面独立复核。

## 复核命令

分类夹具覆盖九个原图分区、共边优先级和极湿图外点。下面的单世界探针使用生产发布、着色来源与点选读数，保留在默认测试之外。

```powershell
cargo test --release --lib reference_chart_interiors_and_nearest_extrapolation
cargo test --release --lib atlas_biome_drawn_leaf_and_inspector -- --ignored --nocapture --test-threads=1
```

首次全量回归在 Windows 默认并发下，库测试进程连续两分钟没有新增输出和 CPU 时间。停止该次进程后，以单线程重跑全工作区 Release。本次未获取等待堆栈，原因未定。单线程全量通过 1,485 项，81 项默认忽略，另行运行的真实海岸与湖岸植被点选探针通过。格式检查、全目标全特性严格 Clippy、wasm32 全特性检查、原生 Release 构建及 Trunk 离线 Web Release 构建均通过。

## 原生验收入口

在本工作区运行 `cargo run --release --bin sekai`。选择 Civ Atlas，在已发布世界的“填色”下拉框选“潜在自然植被带”。可展开“植被带图例”，在二维地图和三维球体间切换，滚轮放大，再点击陆地与相邻水面。干陆读数包含植被名称、年温雨、图内或图外依据及十二个月气温与日降水率。水面显示水类。最终操作验收由用户完成。
