# C2 气候修复验证

## 根因隔离

植被版 `32236e4`、Atlas Draft/42：34,031 个来源格，2,400 个气候工作格。按生产报告的纬带分别检查日照、海温和空气温度。在 16,590 个纯海格中，七月减一月的方向分别有 16,590、15,576、5,331 格符合半球季节。原算法中纯海格的大气没有直接的季节短波热源。九月的 11392–11393 边出现最大风差 49.436 m/s，全年全球风速 RMS 为 7.739 m/s。

只改辐射分配，全部受检格的气温季相符合率从 0.5851 升到 0.9865，纯海格的空气温度从 5,331/16,590 升到 16,209/16,590。海温方向符合率则从 93.9% 变为 88.8%。这两种温度的精度须分别看待。按半球对齐后，海上空气的平均最暖月从北半球十一月附近移至九月附近。风跳变比仍为 6.358，位置与原版相同。

该边两端主要从工作格 419 与 439 取值，地形均高分别约 1967 m 和 4191 m，低层风已有不同的强度与方向。按一级面积重映射，两个来源格各自的权重主要落在不同的工作格，工作格常值在近距离形成陡变。改为在原 P1 对偶面上重建矢量，按来源格中心取样，Draft 的风跳变降至 3.769。High 的工作域为 13,824 格，与来源格尺度更接近，中心取样仍有 4.271。进一步按实际来源格面积对同一重建场求积，High 降为 3.979。独立将每个扇三角形四分再取样，最大差仍在三月的 9650–10100 边，比值 3.956，原界限两次均通过。该对照只用于验证，不增加生产采样。[修订规格和出处](../specs/2026-11-18-c2-climate-advisories.md)

## 最终发布结果

风跳变原上限为 4，半球季相符合率原下限为 65%。以下四个世界均通过既有发布校验。

- **Atlas Draft/42**：风跳变比 6.388 → 3.595，季相符合率 58.51% → 98.65%。TOA 净辐射 −2.441 W/m²，能量相对误差 5.97 × 10⁻¹⁰，水汽相对误差 3.84 × 10⁻⁹。全球蒸发 2.732、降水 2.841 mm/日，通量相对差 3.83%。
- **Formation Draft/42**：在相同构造初态下比较 20,252 个来源格。风跳变比 3.444 → 1.688，季相符合率 41.38% → 95.52%。TOA 净辐射 −1.651 W/m²，能量相对误差 5.07 × 10⁻¹⁰，水汽相对误差 4.29 × 10⁻⁹。
- **Atlas Standard/27276201**：独立种子兼档位对照，风跳变比 3.240，季相符合率 99.93%。TOA 净辐射 −2.417 W/m²，能量相对误差 1.27 × 10⁻⁹，水汽相对误差 3.16 × 10⁻⁹。
- **Atlas High/42**：以原 C2 的本地 `c21a62c` 同种子同档位对照，风跳变比 4.788 → 3.979，季相符合率 51.23% → 95.89%。修复前后中纬西风比例与背风雨影仍有建议失败。High 的数值不代表所有种子或作者参数。

## 初态、配方与湖岸

对照版直接提升 Formation 阶段版本会改变地形随机流。同一 Draft/42 由此重抽构造初态并出现 102 片 L6 湖水，超过原上限 100。最终将地形流保留在原版本 5，同时提升产物版本。逐字节核对新旧构造、基底、初始起伏三份序列化快照的联合 BLAKE3，均为 `11add21ef854d81a557b04c2a8df39371f0bf1cb09aa579396c7d31503406543`。

最终湖岸有 40 个湖、88 片 L6 湖水。封闭岛屿比 0.0087，落在格边的岸线比 0.0300，硬切边比 0.0227。G1–G4 及父层陆地比例检查沿用原标准。审计平台的层级探针指纹随耦合气候与地表更新为 `0c4a34830437db94dd7cd1a2ab00db0ef107bae207372b7099de2165dd982f0f`。阶段缓存键保留产物版本，旧配方需升级副本。

## 生成成本

回归及编译结束后，同机串行冷进程生成 Atlas Draft/42，各执行一次。两个 Release 程序采用同一个调用入口，不设 RUSTFLAGS，不读取持久世界缓存。以 `32236e4` 的植被版作为对照，完整生成分别为 18.277 s 和 18.283 s，采样进程峰值工作集分别为 212,746,240 和 213,041,152 字节。此处仅计生成器，到可交互首帧还需原生呈现与 GPU 安装。这一对样本只用于量级核对。

## 原生验收

打开修复版原生程序，选择 Civ Atlas、Draft、种子 42 和「潜在自然植被带」。生成后检查左侧世界摘要，报告达标时原来的两条橙色建议消失。最终 v8 截图中，放大后的来源格 66 为温带季节林，年均温 11.1 °C、年降水 1,278.3 mm。面板同时显示十二个月的温雨和所选 L4 叶片的旱地类别。[原生截图](assets/2026-11-18-c2-climate-advisories/native-map.png)

运行 `cargo test --release --lib atlas_canonical_current_probe -- --ignored --nocapture --test-threads=1` 可复核默认 Atlas 的生产质量状态、库存校验和完整指纹。

全工作区 Release 单线程回归通过 1,486 项，81 项默认忽略。另行运行的真实 Atlas 发布与库存探针通过，Draft/42 的完整当前态指纹为 `644e78450b91edd9ffb16954e1adadd11d20105312b463d1303788f414daa8df`。新增引擎用例验证了保留随机流时产物升版仍导致缓存未命中。格式、严格 Clippy、wasm32 全特性检查、原生和 Web Release 构建均通过。
