# Atlas 粗水体与逐月汇流实测

本机 Windows 原生 Release，seed 42、默认 Atlas 形状、C2 Draft，实际 34,031 个来源格。
使用已批准的[单层全球真值和修订 R2](../specs/2026-11-03-world-truth-scope-design.md)。

## 生成与首帧

模型 2 的[原生冷发布记录](2026-11-03-civ-atlas-integration.md)为 232.047 秒、峰值工作集约
2.78 GiB。该场景的细水体支持曾展开到 5,701,224 个节点，见[水体支持测量](2026-11-03-atlas-water-authority-layer.md)。
模型 3、4 直接使用上游海陆湖分类和逐格面积求积，缩放查询局部细床。两版均已删除整张细水体图。

同一工具链、同一机器，串行各运行一次已有的 `atlas_canonical_current_probe`：

| --- | ---: | ---: | --- |
| 模型 3，逐边串行 | 18.148 s | 5.732 s | `389f8a02…fc1bd58` |
| 模型 3，仅调整气候边求值 | 13.465 s | 1.000 s | 与上一行完整指纹相同 |
| 模型 4，最终构建 | 13.313 s | 0.997 s | `aed59d63…74d28ed` |

模型 4 最终构建的 C2 为 9.753 s。原生 1280×720 实际窗口冷生成请求至首帧提交
14.131 s，Atlas 阶段 13.300 s，首视图 LOD 烘焙 0.505 s，GPU 安装 0.070 s。
进程首帧时观测到的峰值工作集 590,376,960 字节（约 0.550 GiB）。同版本另一次原生测得
14.312 s、0.585 GiB，后端对照得 13.401 s、完整指纹相同。两次均为窗口发起正常启动重建，
阶段缓存未命中。计时止于应用提交首帧，结果限于该规范场景。

对同一种子、同一组 Atlas 参数，在已发布 Draft 的窗口中选择 Standard，点击「按当前参数重建」。
首帧提交 **14.179 s**，Atlas 阶段 13.366 s，C2 求解 9.819 s。阶段缓存未命中，界面读回
「34031 个球面单元｜标准 · C2 面分辨率 20｜单位球呈现」。两档按 `NaturalQualityProfile::climate_face_resolution`
共用气候工作分辨率。Standard 测量保留上一张有效世界直至发布，不与 Draft 启动时的内存直接比较。

## 月度与界面

模型 3 和模型 4 在该场景的十二个月，陆地产生的径流、湖面直接降水、入海、湖泊滞留、
干洼地滞留及路由残差逐项相同。发布校验从分量重算残差并汇总各湖账目。逐湖来水、湖面降水和
出水给出已解析的净滞留流率。在这个场景中各湖净滞留为零，干洼地有滞留流量。

用 Windows 无障碍接口在真实应用中打开「全球逐月汇流（m³/s）」并切换月份。
1 月与 12 月的五项显示值均与当月生成器结果按显示精度一致。地形和水系的最终视觉验收归用户。
从主目录启动 `cargo run --release --bin sekai`，新建 Civ Atlas 世界，使用 Draft、种子 42，
重建后在左侧已发布世界摘要查看月账。

月度量为 m³/s。初态库存以 m³ 记录，本轮没有按时长积分库存或推进湖面。当前模型保留逐湖账本及
全球干洼地合计。13 个上游湖中有 3 个小于当前面积求积可解析的尺度，其面积、库存为零。
Draft 的气候接缝风速与半球气温季节相位两项建议仍未满足。浏览器交互未由本轮验收。

## 复核入口

后端使用 `cargo test --release --lib atlas_canonical_current_probe -- --ignored --nocapture --test-threads=1`。
应用首帧取 `SEKAI_BUILD_METRICS` 的 `request_elapsed_s`，用 `SEKAI_BUILD_STAGE` 核对缓存状态，
用 `SEKAI_BUILD_SPAN` 分解 LOD 与 GPU。原生日志及界面一、十二月读回保留在本机
`D:/hemifuture-probes/sekai-water-20261118-010420/`。用户可直接从界面复核相同场景。

格式、严格全目标 Clippy、WASM lib 检查、原生 Release 与 Trunk Release 均通过。
Release 全量包含库、两个二进制、146 个集成套件及文档测试，合计 1,473 项通过、78 项默认忽略。
最初有 20 个配方读写用例在系统临时目录创建文件时收到 Windows 错误 5。用同一测试二进制将
此次进程的 `TEMP` 和 `TMP` 指向工作区内的独立目录，原 20 项均通过。默认忽略的 Atlas
生产探针另作上述计时。Trunk 使用本机已缓存的匹配版本 wasm-bindgen 离线重建。
