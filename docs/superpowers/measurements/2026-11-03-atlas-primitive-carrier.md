# Atlas 图元载体对照：源 Voronoi 扇形 vs Goldberg 扇形

记录时间：2026-11-03 UTC。离线测量，不设门禁，不改变生产代码或身份。
探针：`src/generators/natural/formation/atlas_terrain/carrier_probe.rs`
（`carrier_geometry_probe`、`carrier_fidelity_probe`，均 `#[ignore]`，Release）。

## 问题

在保留 Sekai 层级图元（T1 v2：L0 格元 → L1 扇形 → L2+ 四分）的前提下，
把图元载体从 Atlas 源 Voronoi 换成 Goldberg，是否会损失与 Atlas 地形的一致性。

## 范围与参照

- 单场景：seed 42、默认 Atlas 参数、Draft 气候；Atlas 实际 34,031 格，
  Goldberg 取同目标格数得 33,642 格，平均格距均约 123 km。
- 两种载体使用同一扇形定义（格心 + 相邻边界顶点）和同一定位规则。
- 参照为已封存的 Atlas 产品表面 `AtlasTerrainSnapshot::sample_surface`
  （规范 S4 细床 + 初始化水体）。它已含 A3/A3b 湖床初始化，不是上游原始栅格；
  本测量只隔离“载体”这一变量。
- 65,536 个 Fibonacci 等面积探针，计数即面积比例。L7–L8 失配探针仅约 10–20 个，
  这两层差异在统计噪声内。

## 结论（限于上述单场景范围）

1. 同图元数下，Goldberg 载体的海陆与高程保真不劣于 Atlas 源载体；L1–L6 高程
   误差一致略低，干湿失配多数层略低但单层差异接近统计噪声。
2. 失配随层级近似减半，保真由图元尺度决定，而非载体形态。保留 Sekai 图元、
   以 Atlas 规范细场为值来源，不会因载体损失与 Atlas 地形的一致性。
3. 面积均值在粗层降低误差（L0 RMSE 约 −13%），L4 起与中心取值无差别；它同时是
   满足父子聚合一致的取值方式。
4. 重建成本不是选型因素；冷生成瓶颈是规范水体几何。Goldberg 扇形的面数代理
   少约 26%，可能有帮助，但不能单独达到时延目标。

未覆盖：多种子与非默认作者参数、上游原始栅格直接对照、切换载体后的水体支持
归属与气候/水账重建、实际显示效果与用户视觉确认。
