# Atlas 水体拓扑权威层取层测量：Goldberg L1/L2/L3 vs 现行规范支持

记录时间：2026-11-03 UTC。离线测量，只报数字，不设门禁，不调参，不挑种子；
不改变生产代码、schema 或身份。
探针：`src/generators/natural/formation/atlas_terrain/authority_probe.rs`
（`authority_layer_probe`，`#[ignore]`，Release）。
复用 `carrier_probe.rs` 的 Goldberg 载体、扇形定位与面积取样（仅放宽为 `pub(super)`）。

## 1. 问题

候选方案：水体拓扑（海洋连通/海盆、湖泊/溢口/库存、每个 L0 格元的海湖陆
比例与水量）只在某个权威层 Lk 求一次，更细层只继承拓扑。本测量回答：
k 取 1、2、3 时，与现行生产输出相比会改变哪些上游可见地物，代价是多少。

## 2. 范围、基准与候选

- 单场景：seed 42、默认 Atlas 作者参数、Draft。Atlas 34,031 格；Goldberg
  取同目标格数得 33,642 格。规范细场步长 4,886.5 m（`ATLAS_FINE_SCALE`）。
- **基准**：同进程生成的现行 `AtlasTerrainSnapshot`（`ATLAS_SUPPORT_DEPTH`
  基础扇形 + 岸线/湖区 red 细化到规范间距），5,701,224 节点、11,402,444 面。
- **候选 Lk**：Goldberg 扇形层级（T1 v2：格心 + 相邻边界顶点为 L1，之后四分），
  在整层均匀三角网上：节点床高 = Atlas 规范细场在节点处的点值（与生产
  `build_geometry` 相同的串行 4096 批求值）；水体 = 生产 `initialize_water`
  （A5b 来源锚点 + 负高程连通、湖先验 + Priority-Flood 真实溢口、未连通负洼地
  为干地）；面积/水量 = 生产 `integrate_positive_linear_triangle` 的 P1 积分。

| 层 | 节点 | 面 | 图元尺度 |
|---|---|---|---|
| L1 | 100,922 | 201,840 | 约 50 km |
| L2 | 403,682 | 807,360 | 约 25 km |
| L3 | 1,614,722 | 3,229,440 | 约 12.5 km（面均约 158 km²）|

### 2.1 生产算子复用与适配

| 环节 | 做法 |
|---|---|
| 网格 | `geometry::source_fans` 生成扇形后把前 n 个节点（格元站点）替换为 Goldberg 格心，以符合冻结的 T1 v2 扇形定义；再用 `refine_triangles`（即 `subdivision_children_from_midpoints` + `geometric_midpoint`）逐层四分。均匀整层，未用 `red_refinement`（它只服务自适应细化）。|
| 图与洪泛 | 直接调用 `SupportGraph::from_edges` 与 `initialize_water`。|
| 海洋锚点 | 生产把节点 i 当作 Atlas 站点 i，Lk 节点不是 Atlas 站点。**适配**：有效性沿用生产 A5b 判据（Atlas 站点处的规范细床 < 0，与生产基准中该站点节点的床高同值）；位置改为“包含该站点的 Lk 面的三个角点”作为种子候选，由 `initialize_water` 自身的 `seed && B<0` 过滤。|
| 湖先验 | 同理：包含先验站点的 Lk 面三个角点各压入一次（同一先验水位），由 `initialize_water` 的 `min(先验, 溢口)` 与 `水位 > 床` 规则过滤。|
| 面积分 | `assemble_geometry` 是 `geometry` 私有函数，且按 Atlas 站点下标读锚点，不能直接用于 Goldberg。探针逐字复制其每面规则（`face_water`）。**校验**：在基准最终网格上用同一 `initialize_water` 重跑并逐面比较：11,402,444 面 0 处不同（海/湖比例、水位、湖编号、面积逐位相等），17 个湖库容相对差 0。|
| 床高取值 | 只测节点点值，没有测图元面积均值变体。|

### 2.2 两种 L0 读数

- **发布值（published_p1）**：Lk 自身 P1 积分得到的每个 L0 格元海/湖/陆比例
  与水量，也就是权威层会交给 C2 与汇流的格元量。
- **继承读数（inherited）**：在细点上读规范细床，再与所在 Lk 父面的水位比较
  （海面为 0，湖面取父面水位；规则与 `bind_surface_sample` 相同）。这是
  “细层只继承拓扑、按需取细床”的最简推导。
- 基准的 L0 值：在每个 Goldberg 格元内取 L4 等分子三角形（六边形 384 个）的
  形心，读封存产品 `sample_surface`，按球面面积加权。共 12,917,760 个样点；
  继承读数用同一组样点，抽样噪声在差值中相消。
- **抽样噪声底**：每隔 8 个 Atlas 格元取一个（共 4,254 个），用同样的抽样读数
  与生产 P1 格元场比较。633 个非零格元的海比例差：均值 0.35%，
  p90 0.76%，p99 1.66%，最大 3.25%。

### 6.3 锚点适配的敏感性（第一次运行）

若改用“包含面任一角点 B<0 即有效”（不检查站点本身），有效海洋锚点从
21,649 增至约 22,100；候选会多出 L1 18 个、L2 25 个、L3 12 个“新海盆”。
它们与基准的大型干负洼地一一对应，例如 −8.45°, −86.34°（34,051 km²）、
45.73°, 70.76°（23,634 km²）、24.52°, −115.08°（10,368 km²）。
这些洼地附近有约 1,062 个上游标为海洋、但站点处规范细床 B≥0 的站点。
§6.4 用上游自身的像素网格复核后，这些洼地即使在上游网格上也不连通任何有海洋
锚点的海；站点有效性按生产规则判定是对的，“新海盆”是 corner 规则的人为结果。

### 6.4 上游自身如何分类这些干负洼地

探针：Sekai 侧 `anchor_rule_probe`（导出基准中“干且 B<0”的 2²⁴ 个 Fibonacci
等面积点中的 32,797 个，约 997,101 km²，并附洼地编号）；上游侧
`crates/civ-atlas-terrain/src/fine/upstream_class_probe.rs`
（`upstream_class_at_dry_depressions`、`upstream_pixel_connectivity_at_dry_depressions`，
均 `#[ignore]`）。上游侧在 `fine` 模块内调用私有 `raw()`，即原版 zoom 求值
（含河口改写），不新增 API。

上游原版的绘制规则（`shoreline.rs::sample`）：湖掩膜内为湖，否则高程 < 0 即画为
海，不判连通；离岸（`cw == 0`）处高程下限为 2 m，所以负高程只出现在岸带。
上游粗网格另有 `connect_inland_seas`：封闭海要么挖海峡接入主洋，要么超过主洋
2.5% 保留为独立海，否则填为陆；不在湖池中的负高程陆站点被抬到 0。

| 对 Sekai 干负点的分类 | 结果 |
|---|---|
| 上游规范尺度 S4 绘制类 | 海 99.5%，陆 0.5%，湖 0 |
| 上游 scale-1 整图绘制类 | 海 41.3%，陆 58.6% |
| 上游粗网格最近站点类 | 陆 79.1%，海 20.7% |
| S4 像素 4 连通：连到主洋 / 其他有锚海 / 无锚封闭 / 像素中心非海 | 3,192 / 14,107 / 886,620 / 93,183 km² |
| S4 像素 8 连通：同上 | 23,197 / 24,869 / 855,853 / 93,183 km² |

S4 像素网格上，无海洋锚点的封闭海像素占球面 2.04×10⁻³（约 104 万 km²），
与 Sekai 干负洼地总量同量级。前 15 个最大洼地在 4 连通下全部是无锚封闭片
（−24.83°, 74.86° 一处在 8 连通下才接上有锚海）。

结论：

1. 上游自身三种表示互相矛盾：粗模型多判为陆，S4 绘制只按符号判为海，
   像素连通显示这些负片是封闭的。上游把它们画成海，是因为其绘制规则不判连通，
   并不是因为它们连着海。
2. Sekai 现行 A5b（来源锚点 + 实际连通）在上游自身像素网格上给出同样的“封闭、
   无锚”结论，因此现行干地判定不是 Sekai 支持网格的重采样缺陷。
3. 只有约 1.7%（4 连通，17,299 km²）到 4.8%（8 连通）在像素级连到有锚海，而在
   Sekai 4.9 km 支持网格上未接通；这部分是单像素通道漏采，属于重采样缺陷。
4. 按格元判锚（规则 B：格元内最低节点；规则 C：格元内全部节点）分别把
   338,857 / 485,499 km² 的洼地变成海，但这些区域在上游像素级同样封闭，规则 B/C
   没有上游依据；规则 C 下仍有 442,443 km² 不在任何海洋源格元内。

L3 成本约为现行规范水体几何的十分之一，其中约 80% 是床高求值。
L4 均匀整层（约 6.5M 节点、12.9M 面）规模已超过现行自适应网格，
**k ≤ 3 是均匀整层能节省成本的上限**；L4 只能以自适应形式出现，而这正是现行做法。

## 8. 结论（限于本单场景）

1. L1、L2 会丢失海盆，湖泊大面积丢失或失真（L1 湖面积 +115%，L2 湖库容 −47%），
   不能作为权威层。
2. L3 是三者中唯一不丢海盆的层：全球海洋面积/水量偏差在 0.05% 以内。
   但它与现行拓扑并不等价：
   - 5 组海盆连通关系改变；
   - 约 29 万 km² 的海、陆、湖分类翻转，单个 L0 格元最多翻转 59%；
   - 3 个湖丢失，湖总库容 −20%，保持的湖库容偏差中位数 45%。
3. 拓扑翻转不随层级减半，主要来源有三：窄海峡/内湾未被节点采到、粗边跨过窄坎
   造成误接通、锚点落位。单靠加密均匀层级，在 L3 之前无法收敛；L4 又失去成本优势。

## 8b. 湖先验落位：最陡下降规则（第三次运行）

§6.2 的湖先验落位是“包含面三个角点各压入一次”。三个角点都高于湖面时先验落空，
湖 5 因此在 L2/L3 丢失。本节在同一场景下另测一种规则，其余条件（锚点按生产有效性、
床高、洪泛、面积分、抽样）与第二次运行相同。

**规则（`SEKAI_AUTHORITY_PRIOR=descent`）**：
- 有效性：先验站点处规范细床低于先验水位才有效。这是 A5b 站点判据在湖上的对应，
  与网格无关。30 个先验全部有效。
- 落位：从包含站点的 Lk 面中最低的角点出发，沿支持图最陡下降（每步取单位弧长落差
  最大的较低邻点，即 O'Callaghan & Mark 1984 的 D8 规则用在不规则三角网上），
  到没有更低邻点的节点为止，在该节点按原水位压入一次。之后仍由 `initialize_water`
  的 `min(先验, 溢口)` 与 `水位 > 床` 过滤。不引入参数。
- **在生产支持上的自检**：生产支持上的先验站点本身就是节点，从站点直接下降后重跑
  生产洪泛，5,701,224 个节点的水位与湖编号逐个比较，不同处为 0；被溢口压低的
  先验数 7，与生产相同。所以在规范支持上，此规则与生产逐位等价。

### 8b.2 逐项观察

- **湖 5**：L3 的下降终点床高 617.19 m，溢口 667.72 m，高于先验水位 665.91 m，
  所以水位保持 665.9 m。但同一水位下湖面积是基准的 2.2 倍（10,328 vs 4,623 km²）。
  继承读数里，L3 共有 6,695 km² 的基准干地（细床低于湖面）变成了湖，与这部分
  多出的面积量级一致。推断（未逐点核对）：基准支持上，湖 5 与相邻低地之间隔着
  一道高于湖面的窄坎，L3 节点没有采到这道坎。
- **湖 11（L1 误配）**：下降离开了未解析的洼地，终点是床高 −20.89 m 的负洼地，
  它的溢口只有 1.0 m。先验因此被压低到 1.0 m，在别处形成一个 6,349 km² 的湖。
  在粗层上，下降规则会把先验带过未解析的分水岭，送进另一个汇。L2/L3 的终点
  （450.33 / 444.74 m）高于湖面，湖 11 落空，没有误配。
- **湖 9、11 在 L3 仍丢失**：下降终点床高 2,860.98 / 444.74 m，高于各自水位
  2,854.82 / 433.82 m。它们在 L3 节点上没有任何低于水位的点，换落位规则救不回来。
- **湖 1 的分裂、湖 4/14/15 的水位下降**：与落位无关，两种规则结果相同，
  来自 §8 第 3 点的窄通道、窄坎未解析。

### 8b.3 结论（限于本单场景）

1. 下降规则的定义与网格无关，在规范支持上与生产逐位等价，并找回了湖 5（L2/L3）
   与湖 8（L1）。它在 L3 上减少了湖丢失与湖库容偏差（湖总库容 −20% → −12%），
   但 L3 仍有 2 个湖丢失（51 与 117 km²）、1 个湖分裂成 4 块，湖 5 面积翻倍，
   湖拓扑与基准仍不等价。
2. L3 的剩余差异不再来自落位，而来自分辨率：小湖没有被节点采到，窄坎与窄通道
   未解析。在 L1 这样的粗层上，下降规则还会把先验带进别的汇（湖 11）。
3. 耗时：下降本身可以忽略。锚点与先验定位每层 1.9–2.1 s，与第二次运行相同；
   整次运行 310 s。
