# Sekai 球面环流双求解器比较设计

日期：2026-08-03

状态：已批准，可实施

范围：闭合球面上的大气与表层海洋环流求解器原型、性能测量和一致性决策；不在本轮替换生产世界管线

## 1. 目的

Sekai 是设计器，不接受“快速预览显示一种气候，最终生成又换成另一种气候”的长期产品形态。用户调整行星、地形或气候参数后，界面最终显示的字段必须来自今后实际采用的同一个生产求解器。

本轮先实现并公平比较两个候选求解器：

1. `BalancedSteadySolver`：直接求同一组降阶环流方程的受迫稳态，代表快速近似路线；
2. `TransientShallowWaterSolver`：按时间推进同一组方程直至周期稳态，代表实际形成路线。

两者必须使用完全相同的球面网格、行星参数、地表强迫、离散梯度/散度/Coriolis 算子、热力和水分模块，以及相同的输出协议。比较完成后只选择一个生产求解器；不得把较快者永久保留为另一个求解器的伪预览。

在既定执行效率和内存预算内，科学可信度优先。不得为了让两个结果看起来相似而复制经验曲线或对比较结果进行后处理拟合；应优先修正共同物理参数、离散算子或收敛条件。

## 2. 范围分解

“把现有平面世界迁移到闭合球体”和“比较两种环流数值路线”是两个可独立验收的大子系统。若先迁移整个世界，再发现环流网格或求解器路线不合适，返工面会覆盖板块、地质、水文、渲染和序列化。

因此本轮只建立独立、真实可运行的球面环流实验层：

- 在闭合球面网格上运行，不依赖现有 `WorldRect`；
- 使用确定性的合成行星地表夹具；
- 生成风、洋流、温度、湿度和降水字段；
- 输出真实性检查、两求解器差异和 Release 性能报告；
- 不修改当前 `PreliminaryClimateSnapshot`，不改变生产阶段图，不改变 UI。

完成比较并选定求解器后，下一份设计再负责 Goldberg 世界网格、保守重映射和生产集成。这样仍然验证了真正的球面数值算法，而不是用现有平面世界伪装球体。

## 3. 备选路线与选择

### 3.1 两套无关模型

一种做法是照 Gleba 风格实现经验压力带预览，再用浅水方程生成最终状态。它最容易得到明显的速度差，但两者因果结构不同，参数含义和局部反馈无法保持一致。这正是需要避免的割裂，故拒绝。

### 3.2 同一离散方程的稳态解和时间解

推荐并采用。两个求解器共享离散算子和强迫：稳态求解器近似解 `dx/dt = 0`，瞬态求解器计算 `dx/dt` 并推进到周期稳态。两者的差异主要来自稳态近似、季节记忆和非线性迭代，而不是来自两套手写气候规律。

这条路线既能回答“快速近似是否足够一致”，也允许将稳态结果作为瞬态求解器的初值，但不能在 UI 中把尚未收敛的稳态结果冒充最终结果。

### 3.3 只实现瞬态求解器并减少预览步数

这天然统一，但无法回答当前用户要求的“两种路线分别实现和实测”。它作为比较后的可能结论保留：如果瞬态求解已经足够快，或稳态近似不一致，最终产品只使用瞬态求解器并依靠缓存、增量重算和后台更新保证交互。

## 4. 闭合球面网格

实验层采用等角 cubed-sphere 有限体积网格。球面被分为六个逻辑矩形面，每面 `n × n` 个单元；生产尺度先测 `n = 24`，共 3,456 个环流单元，并同时测 `n = 12` 和 `n = 32` 的缩放行为。

选择 cubed sphere 的原因：

- 无经纬网格极点奇点和极区极小时间步；
- 每面是规则数组，适合 Rust 连续内存、WASM 和有限体积边通量；
- 六面接缝只存在于索引映射中，物理空间仍是闭合球面；
- 相比直接在 Goldberg 非结构网格上实现 mimetic C-grid，原型复杂度和数值风险更低。

网格几何使用 `f64`；预报状态使用 `f32`，守恒和比较统计用 `f64` 累加。速度不保存为经纬分量，而保存为三维切向向量 `[f32; 3]`。每次更新后去除径向分量，避免极点和面接缝坐标不连续。

每个球面单元预计算：

- 三维单位中心向量；
- 球面面积；
- 四条边的球面长度、中点和切向外法向；
- 相邻单元及从当前单元观察的边方向；
- 局部东、北基向量，仅供报告和投影。

网格必须满足：

- 每条边恰好有两个所有者；
- 邻接关系双向一致；
- 所有面积为正；
- 面积总和相对 `4πR²` 的误差不超过 `1e-10`；
- 常量场的离散梯度、散度和 Laplacian 在规定容差内为零；
- 原生与 WASM 使用同样的稳定单元、边 ID。

## 5. 共享物理系统

实验使用受迫、耗散的线性旋转浅水系统；它是 Navier–Stokes 的快速降阶形式，但仍有真实的质量守恒、压力梯度、Coriolis、波传播、阻力和跨单元输运。

每个活动层求解：

```text
∂η/∂t + H ∇·u = λη (ηeq - η)
∂u/∂t = -g' ∇η - f k×u - ru + F
```

其中：

- `η` 是层厚或位势高度异常；
- `H` 是参考层厚；
- `u` 是球面切向速度；
- `ηeq` 是由季节辐射、海陆热力差异和地形得到的平衡场；
- `g'` 是控制波速的有效重力；
- `f = 2Ω sin(latitude)`；
- `r` 是边界层或海底阻力；
- `F` 是地表摩擦、海气耦合和地形强迫；
- `λη` 控制层厚向辐射平衡的松弛。

大气层和表层海洋层使用相同的数值框架、不同参数。海洋只在湿单元上活动，陆海边界法向通量为零。海气动量交换使用两者相对速度的线性化风应力，因此两个求解器求的是同一个耦合系统。

温度、海表温度和比湿使用同一个守恒一阶迎风边通量模块输运，并分别受到辐射平衡、海陆热容量、蒸发和凝结松弛。降水由水汽超过饱和值以及迎风地形抬升共同形成。该模块不在两个求解器中复制。

本轮不解析：

- 云微物理和深对流；
- 三维温盐翻转环流；
- 非静力天气尺度对流；
- 湍流 DNS；
- 海冰和碳循环。

这些不是比较稳态与瞬态求解路线所必需的因素。

## 6. 两个求解器

### 6.1 `BalancedSteadySolver`

对每个气候月直接求受迫稳态：

1. 从共同热力模块得到 `ηeq`；
2. 在每个单元局部反演 `rI + fJ`，由压力梯度和外力得到平衡速度；阻力保证赤道 `f = 0` 时仍然有有限解；
3. 用共享散度算子计算质量残差；
4. 以有界、阻尼的固定点迭代修正 `η`；
5. 用共同输运模块推进温度和水汽的月平均状态；
6. 达到残差门槛或固定迭代上限后停止，并记录是否收敛。

它不是手工纬度风带模型，而是瞬态方程的稳态近似。

### 6.2 `TransientShallowWaterSolver`

使用共享有限体积算子和经典三阶 Runge–Kutta（RK3）时间推进。原拟采用的 Heun/RK2 对以虚特征值为主的离散浅水波没有非零的虚轴绝对稳定区，实测会放大机器舍入激发的波模；经典 RK3 在保持同一方程、同一空间离散和同一 CFL 上限的前提下稳定这些波模，因此这是一项数值积分修正，不是另建一套预览物理：

1. 时间步同时受网格最短边与最大波速给出的 `CFL ≤ 0.45`、以及经典 RK3 的 Coriolis 稳定界 `2 |Ω| Δt ≤ 0.9√3` 约束，取两者较小值并向下量化为确定性的整分钟；后一约束防止粗网格步长越过惯性振荡的虚轴稳定区；
2. 依次推进层厚、动量、温度和水汽；
3. 每个气候月累积月平均输出；
4. 连续循环十二个月，直到相邻两年同月状态的面积加权残差达标；
5. 达到最大形成年数仍未收敛时返回带残差的结构化失败，而不是静默输出。

瞬态求解器可选择稳态求解结果作为初值，但性能报告必须分别给出冷启动和稳态热启动，不能只报告有利数据。

## 7. 统一接口和输出

两个实现共同满足：

```rust
pub trait CirculationSolver {
    fn id(&self) -> CirculationSolverId;

    fn solve(
        &self,
        grid: &CubedSphereGrid,
        forcing: &PlanetForcing,
        spec: &CirculationSpec,
    ) -> Result<CirculationSnapshot, CirculationSolveError>;
}
```

`CirculationSnapshot` 对每个球面单元保存十二个月的：

- 切向风速；
- 表层洋流；
- 空气温度；
- 海表或陆表温度；
- 比湿；
- 降水；
- 大气层厚异常和海面高度异常。

快照同时保存求解器 ID、实际步数或迭代数、最终残差、质量误差和能量代理量。比较器拒绝网格 ID、强迫哈希或规格哈希不同的两个快照，从协议上禁止不公平比较。

### 7.1 模块边界与唯一事实源

实现按单向依赖拆分为五类模块：

1. `grid`：只负责球面几何、拓扑和预计算度量；
2. `physics`：只定义经过验证的行星参数、共享强迫和状态量；
3. `operators`：只实现基于 `grid` 的梯度、散度、边通量、Coriolis 和切向投影；
4. `solver`：只负责编排共享算子并控制稳态迭代或时间推进；
5. `comparison`：只消费不可变快照并计算指标、内存和报告。

依赖方向固定为 `solver -> operators -> {grid, physics}` 和 `comparison -> {grid, physics}`。`grid` 与 `physics` 彼此不依赖，`comparison` 不被求解器反向调用。

以下数据必须只有一个事实源：

- `CirculationSpec` 是数值参数和预算的唯一来源；
- `PlanetForcing` 是海陆、地形和十二月外部强迫的唯一来源；
- `CubedSphereGrid` 是面积、邻接、边长和局部基的唯一来源；
- `CirculationOperators` 是离散梯度、散度、通量和 Coriolis 的唯一实现；
- `CirculationSnapshot` 是两个求解器共同的唯一输出格式。

求解器模块不得保存这些对象的可变副本，不得各自实现物理公式，不得通过 solver ID 改变共享强迫。仅迭代策略、时间状态和收敛控制允许因求解器而异。公共类型通过窄接口暴露，内部数组保持私有并由构造器验证。

## 8. 确定性行星夹具

比较至少使用三个不依赖随机运行顺序的夹具：

1. **Aqua Planet**：无陆地、轴对称季节强迫，用于检查纬向对称、赤道连续性、Rossby 响应和全局守恒；
2. **Two Basins**：两块大陆、两个海盆和一条山脉，用于检查闭合海盆环流、海岸零通量、季风反转和雨影；
3. **Earth-like Harmonics**：以固定球谐和解析山脉组合成不规则海陆分布，用于防止只对轴对称或方块大陆过拟合。

额外的零强迫单元测试必须得到零速度和均匀守恒标量；固体旋转输运测试使用恰好七天一周的测试角速度，并必须在七天后恢复初始标量形状到规定误差内。

## 9. 一致性度量

所有空间统计按球面单元面积加权。对向量场 `a`、`b` 定义：

```text
vector_correlation = Σ A(a·b) / sqrt(ΣA|a|² ΣA|b|²)
normalized_rmse    = sqrt(ΣA|a-b|² / ΣA) / max(rms(b), ε)
```

方向一致率只统计两者速度都超过静风或静流门槛的单元，并计算夹角不超过 45° 的面积比例。

稳态求解器只有同时满足以下条件，才有资格被视为瞬态求解器的等价近似：

- 月风场相关系数不低于 `0.95`，归一化 RMSE 不高于 `0.20`，方向一致率不低于 `0.90`；
- 月洋流相关系数不低于 `0.90`，归一化 RMSE 不高于 `0.30`，方向一致率不低于 `0.85`；
- 月温度空间相关系数不低于 `0.98`，面积加权平均偏差绝对值不高于 `0.5 °C`；
- 年降水总量偏差不高于 `2%`，月降水空间相关系数不低于 `0.95`；
- 两者均通过各自守恒、海岸通量和有限值验证。

这些是产品决策门槛，不硬编码成所有数值单元测试的脆弱断言。比较程序必须逐夹具、逐月份输出原始指标和总计，不能只给一个平均分掩盖季节或区域失败。

## 10. 性能测量

Release、单线程、无 GPU 条件下分别测量：

- 网格和强迫构建时间；
- 求解器冷启动时间；
- 瞬态求解器使用稳态初值的时间；
- 输出验证和比较时间；
- 峰值密集数组字节数；
- 实际迭代、时间步和形成年数。

每个 `n = 12, 24, 32` 组合先预热两次，再测九次，报告中位数、最慢一次和每单元每气候月耗时。计时不得包含日志输出或 JSON 写盘。

比较程序写出机器可读 JSON 和简洁文本表。墙钟性能不进入普通 Debug 测试；Release ignored performance test 只保护确定后的宽松回归预算。本轮先实测再确定生产预算，不先编造求解耗时。

报告将当前机器上的 `n = 24` 中位数分为四个交互区间：

- 不高于 `250 ms`：即时；
- 高于 `250 ms` 且不高于 `1 s`：交互可接受；
- 高于 `1 s` 且不高于 `5 s`：阻塞式生成，只适合明确的“重新生成”动作；
- 高于 `5 s`：必须异步、缓存或继续优化。

这些区间用于解释测量结果，不作为普通测试的跨机器墙钟断言。

## 11. 选择规则

比较完成后按以下顺序决策：

1. 如果瞬态求解器在当前参考机器的 `n = 24` 冷启动中位数不高于 `1 s`，且通过基础物理验证，则建议只采用瞬态求解器；稳态实现保留为测试参考或删除，不成为 UI 模式。
2. 如果瞬态求解器较慢，但稳态求解器跨全部夹具通过一致性门槛且至少快四倍，可以选择稳态求解器作为唯一生产求解器；此时“最终生成”也使用稳态求解器，保持所见即所得。
3. 如果稳态求解器不一致，则不得将它作为预览。生产界面显示上一次已收敛结果并标记正在更新，通过缓存、局部失效和稳态热启动加速同一个瞬态求解器。
4. 如果两个求解器都未通过基础物理验证，则不进入生产集成，先修正共同离散算子或模型参数。

选择时准确性和所见即所得优先于单纯速度；速度只决定同一个求解器采用同步、异步或缓存执行方式。比较程序只给出按上述规则推导的建议，最终取舍在完整原始报告交付后由用户确认。

## 12. 错误处理和安全边界

- 所有公开规格先验证半径、自转率、层厚、阻力、时间步、迭代上限和数组预算；
- 单元数上限为 `6 × 64² = 24,576`，超限在分配前失败；
- 所有乘法和字节预算使用 checked arithmetic；
- 非有限状态、CFL 超限、质量漂移和未收敛均返回结构化错误；
- 不使用运行时随机数、系统时间、GPU 或线程调度决定数值结果；
- benchmark 计时数据不参与快照哈希。

## 13. 测试与验收

实现采用严格 Red-Green-Refactor：每个网格、算子、求解器、验证器和比较指标先有会因缺失行为而失败的测试。

验收要求：

- 球面几何和接缝不变量全部通过；
- 共享梯度、散度、Coriolis 和输运算子通过解析夹具；
- 两个求解器都能独立生成完整、有限、可验证的十二月快照；
- 相同输入原生重复运行字节一致；
- WASM 编译通过，固定小夹具与原生量化字段哈希一致；量化步长固定为速度 `1e-4 m/s`、温度 `1e-3 °C`、比湿 `1e-6 kg/kg`、降水 `1e-3 mm`、层厚或海面高度 `1e-4 m`；
- 比较器能拒绝不同网格或不同强迫，并正确计算人工已知字段的指标；
- Release 比较报告包含全部夹具、分辨率、冷/热启动、时间、内存、残差和一致性指标；
- 现有平面自然生成、显示和性能测试不回归。

## 14. 后续生产集成边界

本轮报告和用户选择完成前，不修改 `WorldSpec`、`SpatialSnapshot`、现有板块、水文或 UI。下一阶段只把胜出的一个求解器接入生产管线，并另外设计：

- Goldberg 闭合世界拓扑；
- 世界网格与 cubed-sphere 环流网格之间的保守面积映射；
- 球面板块 Euler 旋转和形成时间；
- 地图投影、跨缝绘制与拾取；
- UI 中同一求解器的缓存和更新状态。

这样本轮实现不会成为一次性伪代码，同时也不会在数值路线尚未验证前扩大迁移范围。

## 15. 实施中记录的证据偏差

本节保留原设计与实际证据之间的差异，不追溯改写最初假设：

- Heun/RK2 被经典 RK3 替换，因为前者对离散浅水波的虚特征值没有非零绝对稳定区；两次积分器都实际实现并测试后才作此修正。
- 时间步除传播 CFL 外增加 `2 |Ω| Δt ≤ 0.9√3`，因为 `n=4` 粗网格实际触发了 Coriolis 惯性振荡溢出。
- 默认形成期由 4 年增至 5 年，因为第 1 年没有上一年可比较，原预算只提供三次年际残差；Aqua Planet 实测需要第五年。
- 稳态 GMRES 与外层预算根据 `n=12 Two Basins`、`n=24 Two Basins` 和 `n=32 Earth-like Harmonics` 的结构化未收敛错误提高；所有容差保持不变，并新增回归测试。
- 原定 `n=12,24,32` 各 2 次预热、9 次测量的完整瞬态协议没有全部执行。当前提交的 `n=12` 单样本（仍保留 2 次预热）已耗时约 14 分钟，且三个夹具均以很大幅度未通过 WYSIWYG 门槛。按 `n=8→12` 实测的 `O(n³)` 缩放，原协议还需约 24.6 小时。结果文档因此把 `n=24/32` 瞬态值明确标为外推，同时对这些分辨率的稳态收敛进行了实际 Release 验证。
