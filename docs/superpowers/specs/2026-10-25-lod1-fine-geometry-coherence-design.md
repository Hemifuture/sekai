## 0. 结论先行

1. **协调者推荐的 R1(c)（同侧顶点锚 + 质心修正）不采用，证据如下**（§1.3）：在同一 Draft
   seed 42 产品上，R1(c) 让岸线 100 %（海岸）/98.3 %（湖岸）钉在 L0 格边上，跨水陆边的
   锚值跳变中位 984 m、p95 3487 m；干陆海岸格的细域海洋面积比 P5 已发布的
   `ocean_area_fraction` 平均少 0.14。它从成因上回到“岸线沿格元多边形”，并与 P5 已发布的
   亚格元水面几何不同源。
2. **审计所称“海岸干陆 18.7–22.5 % 画成水”不是派生缺陷，而是 P5 自己发布的物理量**：
   瞬变共演 §4.1 冻结的 P1 亚格元几何（质心节点 + Shepard 顶点 + 三角扇线性）就是 P5
   求海平面、发布 `ocean_area_fraction`、驱动 P4 与海岸交换的唯一事实源。当前 T1 的 L1 场
   在无噪声极限下与它逐格一致（差 < 0.005，总量比 1.0000，[实测]）。真正不同源的是点击面板
   （读整格离散类别）与河口（门户钉在 L0 格边、河床斜插向洋底）。
3. **“L1 削峰 −174 m”主要是海岸，而不是山峰**：高起伏组里近水格均值 −245 m（中位 −191），
   内陆高起伏格只有 −16 m（中位 −11）（[实测]）。高起伏组被“陆格对深海邻格”的高差主导。
4. 因此推荐（用户 2026-10-25 全部裁定采用）：
   - **D1** L1 边界顶点锚改用 P5 生产 P1 助手（SSOT，数值几乎不变）；
   - **D2** 仅对“无任何水体候选”的内陆格元做平均插值质心修正，近水格元保持 P1；
   - **D3** 河床以受水体水面为侵蚀基准面；**D4** 河线与雕刻按细域干段裁剪；
   - **D5** 点击面板与 mesh 同源；**D6** 新增 T1 派生身份版本。
   - P5 schema、水量、拓扑、海平面与 artifact 全部不变，`CausalNaturalFormationStage`
     版本不升；T1 派生结果改变，按规则升新增的 T1 派生版本（§3.6）。

### 1.3 成因重判

1. **海岸与湖岸。** Arith/Shepard 的线性极限与 P5 发布的 `ocean_area_fraction` 逐格一致，
   这不是巧合：T1 的 L1 场与瞬变共演 §4.1 的 P1 场同构（质心 = 格元值，顶点 = 邻格凸组合，
   扇内线性），只差顶点权重的算术/Shepard 之别，而该差在本网格上数值可忽略（两列几乎相同）。
   瞬变共演 §4.1 规定 `LandOceanField`（整格类别）“仅服务离散水文终端”；海岸交换、P4
   蒸发/反照率与 UI 海岸字段都消费 P1 分数。所以“干陆海岸格画成水”的参照物（整格类别）
   本身不是 P5 的亚格元事实，细域岸线与 P5 的物理岸线是同源的。L6 含噪声时细域海洋分数比
   P5 平均多 0.03–0.04，来自零均值新息在水面阈值处的不对称（无雕刻时同值），属于 §9 Q5
   的观测量。
2. **L1 削峰。** 偏差的主体是近水格：海岸陆格对深海邻格取顶点锚，P1 扇的均值随之被拉到海面
   以下——这正是 P5 用来求海平面与湿面积的同一几何。内陆偏差小（高起伏均值 −16 m），是
   “格元值作质心节点”与“格元值作格元均值”两种语义之差。P5 自身两种语义并存：地貌演化把
   格元值当有限体积均值，水面几何把它当 P1 质心节点。任何只在 T1 改近水格均值的规则
   （R1、R1c）都会让细域岸线偏离 P5 的 P1 岸线（上表第 4、5 行）。
3. **R1(c) 为何不成立。** 同侧平均使共享顶点在不同水体身份的相邻格上取不同值，跨岸格边成为
   断层（跳变中位 984 m）；陆侧锚都在水面上、水侧锚都在水面下，等值线只能落在格边上
   （100 %）。这恰好退回 T1 v2.1 R5 已放弃、T1 v2.2 R2 用户要求修掉的格元多边形水岸。要让
   共享顶点重新单值，只能回到跨岸平均，又回到 R1 的海岸过冲（中位 117 m、p95 483 m，
   与 T1 v2.2 R1 记录的 132/521 m 同形）。P1-A §2 已给出数学原因：连续、逐格精确保均值、
   不越邻域极值三者对任意阶跃不能同时成立；同一节也已指出“按根格海陆侧分别平均共享点
   会得到两个值，不能当作跨侧一致的修复”。本次实测与之一致。
4. **河口。** 两个独立成因：(a) 门户固定在 L0 共享边中点，而 P1 岸线在格内任意位置——
   线性极限下 511 条首个水点在门户前（中位 48 km）、436 条在门户后（中位 43 km）；
   (b) 受水体节点河床取 `z_水格 − 切深`（`terrain_amplification.rs:511-514`，`bed_to` 见 `:632`），海洋格
   即洋底，河段河床按全程弧长从陆格线性插向洋底（`hierarchical_rivers.rs:511`），
   门户处河床随受水格深度落到海面以下（幅度未单独测，[推测] 数百米量级），雕刻把海岸陆叶切到水面下——审计实测雕刻额外贡献
   5–13 个百分点。(a) 与 L1 锚定规则无关：R1、R1c 只是把错位的分布换了形状（R1 还出现
   47 条到水格质心仍未遇水）。
5. **点击。** `ui/spherical.rs:410` 只按方向定位 L0 格元，面板读该格的 L0 字段值，不知道
   当前视图在该处画的是哪片叶、叶片值与叶片水体类别（[代码]）。

### 1.4 候选 A 的教训

`codex/coast-consistency` 的候选 A 就是本规格的 D1（T1 顶点锚换成 P5 共享锚）。它在旧世界
上被原陆比门（L0/L6 高程 ≥ 海面，漂移 ≤ 0.01）证伪：0.013916 → 0.013855，只改善 1 个探针。
本次实测给出原因：Shepard 与算术锚在本网格上几乎等价（本世界陆比漂移 0.0049 vs 0.0050），
换权重本来就不该移动陆比；当时的丢陆来自海岸 P1 扇被拉到海面下，而那正是 P5 自己的 P1
岸线。吸取的教训：

- D1 只以**唯一事实源**为理由，不宣称改善陆比或任何质量指标；陆比门的操作数与阈值保持不变
  （§4 I5）。a9 世界上该门已绿（0.0066），D1 预期不改变结论，以实测确认。
- 不把“与整格类别不一致”当缺陷去修；参照物改用 P5 发布的 P1 量，并且只做观测，不据此
  新设门禁（§4 I4）。
- 不承诺细域水体体积守恒（P1-A §5 原则保留）。

## 3. 设计

### 3.1 D1：L1 边界顶点锚复用 P5 生产 P1 助手（推荐，已裁定采用）

规则：`vertex_value_m = reconstruct_vertex_elevations(surface, z, cancellation)`，即
`surface_water_geometry.rs:476` 的生产函数（Shepard p = 2，以格元球面质心到顶点的中心角为
距离）。质心锚仍为 `z_cell`（近水格；内陆格见 D2）。

- 出处：Shepard (1968)；本项目瞬变共演 §4.1 冻结其为亚格元水面几何 SSOT。
- 为何不是事后修形：这不是为了改指标，而是消除第二份公式。T1 v2 §2.1 的算术均值与 P5 的
  Shepard 是同一事实（共享顶点的重建高程）的两份定义，按 AGENTS“发现重复即视为缺陷”合并。
- 跨侧一致：顶点值按 canonical `SurfaceVertexId` 一次算出、全局单值，相邻格与相邻扇读同一
  数组；中点种子规则不变，故 T1 v2 §7.2 逐位一致不受影响。
- 实现要点：该助手可见性放宽到 `pub(in crate::generators::natural)`，签名与求值顺序不变；
  `HierarchicalEvaluator::from_amplifier` 改为返回 `Result`，承接 `WaterVolumeSolveError`
  （候选 A 计划 Task 1 的接口，失败不吞）。`DERIVATION_DOMAIN` 不变（保留 L2+ 种子）。
- 预期效果：显示几乎不变（§1.2 两列）；探针指纹改变，按 D6 升版本。

### 3.2 D2：内陆格元平均插值质心（推荐，已裁定采用）

规则：令 `W(cell)` 为该格在 `FineShoreline` 中的水体候选行（本格所属水体 + 边邻格水体）。

```text
若 W(cell) 为空（内陆）：c' = 3·z_cell − 2·v̄_w，
    v̄_w = Σ_i w_i·(v_i + v_{i+1})/2 / Σ_i w_i，w_i = 第 i 个扇三角的球面面积
否则（水体格或其一环）：c' = z_cell（保持 P1）
```

- 出处：平均插值细分的均值约束构造（Sweldens & Schröder 1996），与 T1 v2.2 §3.1 同式。
  适用域的划分不是新系数：它只是“P5 在哪里发布了亚格元水面几何”的事实——有水体候选的格元，
  其亚格元形状由 P5 的 P1 几何约束（§1.3.1）；无候选的格元，P5 没有发布任何亚格元量，
  格元值按地貌演化的有限体积语义取均值。没有文献直接给出这一分区，按出处纪律列为
  §9 Q1，类比依据是：每个区域采用 P5 本身为该区域发布的重建。
- 结果：内陆格扇形面积加权均值精确等于 `z_cell`；近水格扇均值精确等于 P1 扇均值；
  二者都是“与父层守恒”，父层分别是 P5 的格元值与 P5 的 P1 亚格元几何。
- 跨侧一致：质心锚只属于本格，顶点锚不变，因此不引入任何共享量的多值；L2+ 跨边中点只由
  共享边两端顶点与种子决定，与质心无关，逐位一致不变。
- 不与水岸耦合：内陆格无水体候选，其叶片在任何值下都判为干（`fine_shoreline.rs` 规则），
  故 D2 对岸线、水面积、陆比门、河口判定零影响（逐位可证，§4 I6）。
- 过冲：内陆面越出邻域区间 1369/21 016，中位 13 m、p95 86 m，无面触及高程界（[实测]）；
  T1 v2.2 R1 已论证内陆过冲与“格元值是均值”一致（峰格的峰顶本应高于均值）。按 T1 v2.2
  §9.2 裁定不 clamp。
- 为何不是事后修形：c' 由均值约束闭式解出，无系数、无目标分布。
- 可见效果：内陆高山格放大后均值不再被压低（内陆高起伏组均值 −16 m → 0，p05 约 −149 m → 0）；
  海岸格不变。是否值得（收益小于海岸部分）交用户在 UI 上判断（§9 Q1）。

### 3.3 D3：河床以受水体水面为侵蚀基准面（推荐，已裁定采用）

规则（只改 T1 `TerrainAmplifier::with_rivers` 的派生河床，P5 不变）：

```text
H_term(n) = 沿 P5 receiver 向下游的第一个水体 W 的水面（海洋：sea_level_m；
            湖泊：Lake::surface_elevation_m()）；无下游水体则无下界
水体节点：bed(n) = H_W
干陆节点：bed(n) = max(z_n − d(Q_n), H_term(n))，d 为既有切深律
其后沿拓扑序 running-min（不变）
```

- 出处：侵蚀基准面——海面是“陆地不能被侵蚀到其下”的总基准面，湖面是局地基准面
  （Powell 1875）；湖面等于其溢出口高程（P5 湖面语义；优先洪泛 Barnes, Lehman & Mulla 2014）。
- 单调：`min(max(a, H), max(b, H)) = max(min(a, b), H)`，running-min 后沿流不升仍成立；
  湖泊节点取 `H_W` 后，出湖河段从溢出口高程起算，不再继承湖底（现状会把湖底高程沿出流
  向下游传递，[代码] `terrain_amplification.rs:530-538`）。
- 雕刻仍是 `min(派生值, carve)`，只降不升；`bed ≥ H_term` 只限制切得多深，不抬高任何地形。
- 后果：入水河段中心线的雕刻值 `min(未雕刻值, bed)` 低于水面，当且仅当未雕刻值低于水面
  （严格小于），所以 D4 的终点就是未雕刻派生场的水面交点，不再被雕刻提前拉进水里——
  审计 §2.4 的 5–13 个百分点由成因消除。114 条（12 %）上游河床已低于水面的河段改为在
  基准面上平流。
- 对 T1 v2.2 §5.1“雕刻河床低于海面形成河口湾”的影响：该湾在 D3 下不再由雕刻产生，
  是否保留由 §9 Q3 裁定。

### 3.4 D4：水侧 leg 与按细域干段裁剪的河线与雕刻（推荐，已裁定采用）

规则：

1. **leg 生成。** 干陆↔水体河段除干侧 leg 外，补生成水侧 leg（门户 → 水格质心），沿用
   v2.1 §4.2 扇区约束、§5 单调路径与 A6 蜿蜒（引导仍读未雕刻场）。水体↔水体河段仍不生成。
   门户仍是 P5 共享边中点，P5 拓扑不变。
2. **干段判定。** 对深度 d 的路径顶点 p（与显示同一 `level − 1` 映射，
   `amplified_mesh.rs:1052`、`hierarchical_rivers.rs:506`），计算中心线显示值
   `h(p) = min(uncarved_sample_elevation_m(p, d + 1), bed(f(p)))`，以生产
   `FineShoreline::classify(root(p), h(p))` 判定干/水。
3. **裁剪。** 河线与雕刻支撑只保留路径上连续的干顶点段：入水河段止于首个水顶点前的最后一个
   干顶点；出湖河段始于逆流向首个水顶点后的第一个干顶点；干陆→干陆河段若穿过一环内的细域
   水面，水中部分不画、不雕刻（与 v2.1 §4.1“不把陆地河槽穿过水面”同一原则）。
4. **不循环。** 判定只用未雕刻场与河床，不读裁剪后的雕刻；裁剪只删除支撑，不改变保留段
   中心线的值（中心线最近点即自身），因此“判定 → 裁剪”一次完成。裁剪区间作为路径树的
   纯函数随 `ReachPathData` 缓存，不改变路径点本身。
5. **兜底。** 若入水河段直到水格质心仍无水顶点（审计 L6 有 16 条），终点取水格质心（P5 节点），
   计数进探针，不静默。

- 出处：河网线在水体边界断开、水体内部为人工路径（USGS EDH Topology Requirements，T1 v2.1
  已引）；终点为派生场与水面的交点，水面等值线为岸线（T1 v2.2 §5.1、R2）。
- 为何不是事后修形：裁剪是拓扑规则（河线只在干陆），用的是与填色同一个判定函数；不移动
  路径点、不改河宽或流量。
- 分辨率：终点误差不超过深度 d 路径的一个顶点间距（与第 d + 1 层叶片同阶）。
- 一致性前提：FineShoreline 必须只有一个实例。现生产在 `app.rs:1326` 另行构造；改为由
  `HierarchicalEvaluator::with_rivers` 构造并持有（输入相同：surface、`SurfaceWaterField`、
  湖泊、海面），`app` 读取同一实例，删除重复构造。

### 3.5 D5：点击面板与 mesh 同源（推荐，已裁定采用）

规则：

- 拾取保存点击方向（现只保存 `CellId`）。在高程/地形填色（唯一走细分 mesh 的字段，审计 §1）
  下，面板用当前视图已安装的 detail selection 给该格的层级 `L = cell_levels[cell]`（与 mesh、
  河线同一来源），求 `v = evaluator.sample(p, L)` 与 `k = shoreline.classify(cell, v.elevation_m)`。
- 面板并列三组行，文案经现有面板行与本地化约定提供，不在调用点写第二份：
  - “高程（派生 L{L}）”“水体（派生 L{L}）”——与屏幕叶片同值；
  - “高程（L0 权威，P5）”“海陆类别（L0，离散水文终端）”；
  - “海洋面积分数（P5 亚格元）”——`SurfaceWaterGeometry::ocean_area_fraction()`，说明海岸格

- Map 与 Globe 各有 selection，面板只用当前活动视图的已安装 selection；selection 与面板同一

- 出处：工程 SSOT（审计 §4 已注明无需科学出处）；“派生值与权威值分开标注”沿用 P1-A §4.1。

| 湖内封闭陆块面积 / 湖水面积（每湖均值） | — | 3.6 % | 3.3 % |
| 湖岸叶边落在 L0 格元边上的占比 | — | 14.6 % | 7.6 % |

成因分三层（[实测]）：

1. **溢出主要不是噪声。** 去掉全部 L2+ 新息（线性极限，即 P5 P1 几何本身）后，现生产规则下
   湖 33 仍是 4.17 倍；同一线性场只取与湖连通的部分则是 0.349 倍。溢出的主体是边缘格里低于
   湖面、但沿 P1 场坡向**其它排水方向**（鞍点外的低地）的区域——正是“湖面以下但水文上不属于
   这个湖的低地”。
2. **碎片来自新息幅度远大于湖的水文起伏。** 40 个湖的格心水深中位 13.6 m、边缘格最低处高出湖面
   中位 12.0 m，而湖格 A0 中位 90.8 m（A0/水深中位 8.0，40 湖中 39 个 A0 > 水深）。新息在湖内
   造岛、在湖外造塘，并在平坦边缘把湖与别处低地桥接。
3. **只加连通、不限范围会渗流。** 湖 33 在 L6 上按连通扩展：限一环 4.50、限两环 14.8、限三环
   31.2 倍——湖面高度上的低于湖面区域在平坦边缘近乎渗流临界，固定环宽的任何上界都会截断，
   放宽则淹没。所以连通必须同时有水文边界与尺度约束，见 R2.3。

被否决的直接修法：**把湖格内派生高程整体压到湖面以下**（湖格全湿）。L6 上湖格边界处 73.8 % 的
叶边变成恰好落在 Voronoi 边上的岸线（湖 39 为 85 %，湖 33 为 41 %）：陡岸湖的格内 P1 场在边界
附近就已高于湖面，强制全湿会让岸线退回格元多边形——即 T1 v2.1 R5 放弃、用户要求修掉的形状。

#### R2.2 父层：湖的亚格元几何取 P5 P1（与海岸同源）

P5 湖泊水量平衡规格（2026-10-08，R1，用户已裁定）§2.1 与 §4.4 规定：湖格谓词是“格心水深 ≥
`FORMATION_MINIMUM_LAKE_DEPTH_M`”，湖的亚格元湿面积 `w_i(h)` 取瞬变共演 §4.1 的统一 P1 三角扇
几何——与海洋同一个算子。本规格 §1.3 已据此把海岸的父层定为 P1。R2 对湖采用同一父层：**细域湖
的父层是 P1 场在湖面高度下、与湖连通的部分**，不是整格湖格。

后果（[实测]，均为 P1 线性极限加 R2.3(a) 边界）：P1 连通湖面 / P5 湖格面积 草稿 0.631（L6）、
标准 0.948（L5）；草稿 18/40、标准 20/80 个湖在 L1 没有任何低于湖面的扇面——这些是陡岸里的浅湖
（例：湖 12 水深 1.7 m，P1 湖面 < 0.1 % 格元）。也就是说，按 P5 自己的亚格元几何，相当一部分湖
在格元尺度上本来就小于一个格元。这是视觉上的主要变化，列为 R2.9 Q1。

#### R2.3 规则

**(a) 水文边界 `B_W`（问题 3）。** 对湖 W（湖面 H_W），只用 P5 已发布的量：

```text
D_W = W 的湖格 ∪ {c : 优先洪泛填洼面 filled(c) = H_W 且格心 z(c) < H_W，经同类格与湖格连通}
R_W = {c ∉ D_W : c 与 D_W 共边，filled(c) > H_W，c 不是海洋格，也不是其它湖的湖格}
B_W = D_W ∪ R_W
```

- `filled` 即 `HydrologySnapshot::drainage_surface_elevation_m`。`D_W` 是湖面高度上的洼地本身
  （含因水深不足 1 m 未成湖格、但格心被淹的边缘格，与 P5“格心被淹”谓词同一规则）；`R_W` 是
  把水拦在 H_W 的堤岸格（优先洪泛保证其格心高于湖面）。
- 排除：`filled < H_W` 的低地（水越过溢出口后流向的下游，水文上不属此湖）；`filled = H_W` 且
  `z ≥ H_W` 的鞍点格（溢出口所在，格心不被淹）；海洋格；其它湖的湖格。
- 能越出一环：经边缘格链可以（标准档有 6 个这样的格心被淹边缘格；草稿 0 个）；到 `R_W` 为止。
- 规模：草稿 `B_W` 合计 350 个格元成员（并集 344，占全部格元 1.7 %），标准 1132（并集 1108，1.4 %）。

**(b) 分层连通（问题 1、5）。** 叶片 t（层级 ℓ，派生面值 v(t)，根格 root(t)）属于湖 W 的水，记
`t ∈ Wet_ℓ`：

```text
ℓ = 1：从 W 湖格中 v < H_W 的扇面出发，经共边、v < H_W、根格 ∈ B_W 的扇面洪泛（Barnes 2014 意义下的连通）
ℓ ≥ 2：core(t) = v(t) < H_W ∧ root(t) ∈ B_W ∧ ( parent(t) ∈ Wet_{ℓ−1} ∨ t 以 W 某湖格的格心锚为顶点 )
       Wet_ℓ  = core ∪ { u : v(u) < H_W ∧ root(u) ∈ B_W ∧ u 与某个 core 叶片共边 }
```

- **种子（问题 1）**：L1 用湖格内低于湖面的扇面；每层另以“贴着湖格格心的叶片”补种。湖格在某层
  整体高于湖面时，该湖在该层不显示——这与 P1 一致（湖小于该层图元）；层级加深、格心叶片落到湖面
  以下时湖出现。草稿 L1 无湖 18/40，L6 面积 < 5 % 格元的 3 个（P1 线性极限为 8 个）；标准 L1 无湖
  20/80，L5 < 5 % 的 2 个。
- **尺度约束（问题 3、5）**：每层的湖只能是父层湖的子叶片加上外扩一片本层叶片（加格心补种），
  所以每层横向延伸不超过本层一个图元，累计不超过约一个 L1 扇面；L1 本身由 `B_W` 内的全局洪泛
  决定拓扑。这是本层湖与父层湖一致的构造保证：`Wet_ℓ` 落在 `children(Wet_{ℓ−1})` 外扩一片之内。
  被尺度约束挡住的“低于湖面的陆地”按陆地着色（干陆色带按高程，不暴露它低于湖面），其形状随
  上一层岸线而不是格元边（R2.4 第 3 表）。
- 与海洋组合：候选顺序不变（根格所属水体优先，其余按水面升序）；海洋候选仍按“低于海平面”判定，
  湖候选改为“`t ∈ Wet_ℓ`”。不在任何 `B_W` 中的格元分类与现生产逐位相同。
- 判定是 (湖, 图元 ID) 的纯函数，不依赖视图、批次或缓存；mesh 着色、点击读数（D5）与河口裁剪
  （D4）调用同一函数。

**(c) 湖床展平（问题 2）。** 对根格 ∈ `B_W`（边界链上两侧格元同属某 `B_W`）且该格不与海洋相邻的
L2+ 中点锚：若其两个端点锚都低于该湖湖面，则该中点不加新息，取端点均值。

```text
mid = (a + b)/2 + [max(a, b) ≥ H*] · A(ℓ) · N(seed)，  H* = 该锚适用的 B_W 湖面最大值（不适用时为 −∞）
```

- 物理读法：湖面以下的湖床是沉积汇，湖面是其局地侵蚀/沉积基准面（Powell 1875，本规格 D3 已引；
  可容空间在基准面以下，Jervey 1988），湖底被沉积抹平（Håkanson & Jansson 1983）；工业对口是
  USGS 激光雷达基础规范的“水体展平”（hydro-flattening：水体表面平、湖岸地形不低于水面，
  Heidemann 2018）。湖床起伏在显示上没有消费者，唯一的可见后果是造出 P5 不知道的岛——按 AGENTS
  “不足以影响目标尺度结果的细节不计算”不算它。展平只作用于“两端都已在水下”的边，跨越湖面的边
  照常加新息，所以岸线仍是分形的。无直接文献规定这一判据，列为 R2.9 Q2。
- 选“两端都在水下”而不是“端点均值在水下”：后者让陆侧下凹的锚一旦低于湖面就冻结，湖面随层级
  单调外扩。同一边界（含鞍点格的早期变体）下草稿总量 L1→L6：均值判据 0.720 → 0.831（+15.4 %），
  两端判据 0.720 → 0.757（+5.1 %）；按 R2.3(a) 边界为 0.612 → 0.658（+7.5 %，R2.4）。
- 不与海洋相邻的限制：`B_W` 中与海洋相邻的格草稿 18、标准 22 个（全是堤岸格；湖格与海洋相邻的
  为 0），它们保持新息，海岸细节与 I4、I5 不受影响。

**(d) 内陆划分（D2）随之扩展。** “近水”改为：原定义（本格或边邻格有水体）∪ 任一 `B_W`。由此
I6（内陆格叶片恒为干）继续成立。草稿无格元改变划分；标准 8 个堤岸格由内陆改为近水，其 L1 质心
锚由 c' 回到 z。

**(e) 不变的部分。** P5 schema、水量、拓扑、海平面与全部 artifact；海洋判定；D1 顶点锚；D3 河床
（入湖河段河床 ≥ H_W，雕刻不在湖外造出低于湖面的通道）；D4 的“画线只在细域干段”语义（判定函数
换成 (b)）；D5 面板（读数函数同上）。

边硬截断。** 小湖 B 即 P5 湖 55：单湖格 59090，格心 1789.2 m，湖面 H = 1805.56 m（水深 16.4 m）；
六个邻格中五个是堤岸格（格心高出湖面仅 +0.1…+0.8 m），一个是溢出口鞍点格 59091（+0.0 m）。

- 湖格的六个 P1 顶点（Shepard 重建，含湖底格心）全是 1800 m < H，故 P5 自己的 P1 湿面积
  `w = 1.00`：在 P5 口径下湖 55 本来就是整个湖格。
- 堤岸格只有格心在湖面以上；其顶点被湖底和外侧低地拉低（59046：1800/1793/1765/1769/1798/1800；
  L1 六个扇面值 1780–1802，全低于 H）。外侧格 59000（1781 m，填洼面 < H，在溢出侧）、59047、
  59088、59132 都更低。P1 场从湖格顶点经堤岸格一路低于湖面连到 `B_W` 外——P1 意义下这道“堤”
  处处漏水，只在格心这一点挡水。
- R2.3(b) 的 L1 洪泛在 `B_W` 内把五个堤岸格几乎整格淹没，外缘在 `B_W` 与溢出侧格元的 Voronoi 边
  上截断。湖面 / 湖格面积逐层为 L1 5.48、L2 4.49、L3 4.30、L4 4.31、L5 4.35、L6 4.39、L7 4.41；
  L5 上 59046 有 89 % 叶片低于湖面、88 % 判水，紧邻的 59000 有 97 % 低于湖面、0 % 判水。
- **派生层级之间没有 L4→L5 跳变**：整格六边形在 L1–L7 每层都存在（L4 4.31 → L5 4.35）。UI
  连续缩放图里 ×36.6 以下的“不规则小湖”来自每格 250 ms 的快速滚轮，截图时细节批次尚未重建完成；
  同镜头静止截图（`raw/base-lakeB-x*.png`，等画面稳定后截取）里六边形块从 ×26.6 起清晰可见，
  ×36.6 与 ×42.9 形状相同、只随缩放变大。
- 全局：P1 连通的“堤岸格低于湖面面积 / 湖格面积”草稿 0.386、标准 0.165，其中湖 55 为 4.31；
  80 个标准档湖中 37 个超过 0.5。P5 湖泊水量平衡规格 §2.1 的湿面积只计洼地成员 `M(D)`
  （P1 口径：草稿 0.701、标准 0.895 倍湖格面积），堤岸格不在其中——R2 的标准档细域湖面 0.983
  比 P5 口径多出 9.8 %，主要来自这类漏水堤岸格。

**缺陷 2（湖 39 的直岸）不是同一根因，是 R3 开放问题 3 的格内前沿。** 湖 39 的 L6 湖岸叶边中，
干侧在同格、且低于湖面的占 40.7 %，跨格硬截断只占 1.1 %；湖 33 为 70.8 % / 0 %。这些前沿是
“每层只外扩一片”（R2.3(b) 尺度约束）在湖面以下平地上的截断线，沿较粗层三角形边，呈直线加叶片
锯齿。全局（L6）：草稿 37.4 %、标准 35.7 % 的湖岸叶边是这种前沿。

#### R4.3 规则

对湖 W，在 P5 已发布的 P1 几何（格心 = 发布高程；边界顶点 = P5 的 Shepard 重建，与 `w_i(h)` 同一
事实源）上，从湖格格心出发求“低于 H 且连通”的部分。分段线性场的下水平集只经顶点相连：格心低于
H 的格元连通其全部低于 H 的顶点；格心不低于 H 的格元只连通环上相邻的一对低于 H 的顶点（二者之间的
扇面是平面三角形，其水下部分为一个凸块）。

```text
Reach_W = 自 W 湖格出发、在 B_W 内按上述规则可达的低于 H 的顶点
堤岸格 c ∈ R_W 泄漏 ⇔ c 有一个顶点 ∈ Reach_W，且该顶点也属于某个不在 B_W 中的格元
```

泄漏堤岸格不再是 W 的候选：不承载湖水（R2.3(b) 判定在它上面恒为否）、不参与湖床展平
（R2.3(c)）；仍属近水（R2.3(d) 不变，L1 质心锚不变）。不泄漏的堤岸格与洼地格（湖格、格心被淹的
同高格）照旧。判定只依赖 P5 发布量，是 (湖, 格元) 的纯函数，与层级、视图、批次无关，所以
跨层一致性与点击同源（I13）不受影响。

物理读法：P5 的优先洪泛（Barnes et al. 2014）说湖在 H 被堤岸“拦住”；在 P1 几何里这道堤若有一条
低于 H 的通路通到边界外，它就不在任何位置拦水——水面只能停在 P5 计入湿面积的洼地成员里
（P5 湖泊水量平衡 §2.1 的 `M(D)`）。于是细域湖面向 P5 自己的湿面积收敛，而不是把漏水堤岸整格
淹到 `B_W` 外缘再截断。

#### R4.4 取舍（偏离冻结设计，须用户裁定）

- **湖 55 这类“P1 整格湿”的湖仍是一个整格六边形**（湖格本身，P5 `w = 1.00`），岸线落在湖格与
  泄漏堤岸格之间的 Voronoi 边上，边外堤岸格的叶片仍可能低于湖面（59046 1760–1800 m 对湖 1797 m）。
  这是 P5 亚格元几何本身的结果：在“湖面 1805.56 m、堤岸格心仅高 0.1–0.8 m、顶点为 Shepard 均值”
  的输入下，不存在既保持 P5 湖面又有自然岸线的分类规则——要自然岸线只能让细域地形在堤岸格内
  升过湖面（堤岸条件化，类似 Arc Hydro 的 Build Walls，Maidment 2002），属新机制，见 R4.7 Q2。
- R2.3(a) 的“堤岸格承载湖水”被收窄；不泄漏的堤岸格（如湖 39 的 19804，L6 35 % 湿）保持不变。
  湖 39 ×72 画面右上那块水面伸入一个泄漏堤岸格的部分被移除，留下一段格元边直岸
  （`sheet-draft-lake39-lake33.png`）——同一取舍的局部体现。
- 曾试的另两种做法（[实测]，`logs/shore-VA.log`、`shore-F2.log`、`probe-src/f2-p1-seeding-rejected.patch`）：
  去掉全部堤岸格（`B_W` = 洼地）—— 格元边岸线草稿 4.0 → 12.2 %、标准 5.8 → 19.7 %，否决；
  在本修订基础上再以“P1 区域内的叶片”逐层补种（意在消除格内前沿）—— 水块草稿 80 → 190、
  标准 315 → 667，L1→L2 面积 +11 %，否决。
