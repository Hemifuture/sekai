# Atlas 显示细节按字段来源分辨率更新

## 显示契约

- **风**沿用 C2 已发布的来源格平均矢量。二维地图与球体可以逐档增加箭头，直到各自的现有格距下限。两种二维投影和球体的箭头格距均触底后，后续缩放共享同一个场数据包与 GPU 实例，仍更新镜头。按二维投影包围盒及球面面积把格距下限换算到原有参考像素，取最迟触底的一档。格内阵风属于未解析细节。
- **潜在植被带**为来源格的离散类别。每个 Voronoi 扇区的干陆子片继承扇区的来源格，直到其共边。水面仍由实际显示叶片的细床与海湖判据决定。绘制时从已生成的三角形取中心，点选时用对应的层级路径取同一中心。点选和着色共用细床及水体分类。
- **高程与海湖岸线**沿现有相机层级继续细分。Atlas 每个显示样点仍查询固定规范细床与已发布水体。显示间距与物理适用尺度分别在界面说明。

这轮复用已有字段与网格，仅改变运行时呈现。Atlas 产物由相同的生成阶段发布。数值来源和继承边界从当前世界的源格拓扑推导。

## 实施及验收

1. 用当前 Draft 环流风测量来源格距饱和后的应用动作、GPU 上传及实际叶片归属。记录相同相机下的网格内容指纹和烘焙耗时。
2. 按实际箭头格距确定最高有效缩放档。观察视角跨过该档时，使用同一个已发布图层包。各档位的矢量仍取已发布来源格。
3. 直接绑定继承到绘制用的来源格，省去已知归属叶片的邻接查找。通过已生成的三角形共用叶心；复用细床高程、细床水类和颜色路径。
4. 接入二维地图、三维球体及“来源、尺度与已解析范围”面板。用现有小世界验证正常格距档位和饱和档位的 GPU 修订，用一个 Atlas Draft 世界复核海岸与湖岸的绘制、点选和产物指纹。

## 单世界对照

Windows Release，起点 `0ad6a2a`，Atlas Draft 种子 42，二维 Equal Earth 画布 1600 × 900。已发布 34,031 个来源格，平均格距约 122 km，C2 工作格平均格距约 461 km。底层 Atlas fingerprint `644e78450b91edd9ffb16954e1adadd11d20105312b463d1303788f414daa8df` 在两次生成中一致。

- **风层交互。** 通过同一个应用动作和 wgpu 呈现器测试。首次从全图放大到 16 倍时，两版都需安装更密的实例。随后从 16 倍逐次翻倍到 512 倍，基线每步重传二维与球体风箭头，共 3,613,168 字节，动作耗时 116.6–117.6 ms。修改后五次动作都复用图层与实例，风层上传为零，动作本身耗时 0.7–3.9 μs。此处计时到动作返回，画布随后按原路径提交镜头 uniform。
- **地形与植被带。** 全图与 16,384 倍分别有 204,174 和 589,830 个显示叶片。两个视图中干陆叶片的原查询归属全部与绘制用来源格吻合。三角形方向、索引、地形颜色和干陆来源格编码在修改前后逐位一致。每视图三次空批次缓存，烘焙加二维投影的中位数分别为 279.0 → 275.8 ms、334.6 → 329.1 ms，前后样本范围重叠。同步构建世界与基础呈现候选为 18.88 s 与 18.75 s，各测一次。冷生成到原生首帧的收益仍需同口径重复测量。

原始记录在 `target/atlas-lod-before.log` 和 `target/atlas-lod-after.log`，临时 Release 探针保存在 `target/atlas-lod-probe.rs`。风层采用真实绘制资源，测量为离屏运行。常规回归沿用视图、GPU 与来源格验收测试。

Release 通过 52 项相关库测试、48 项球面视图与 GPU 集成测试，另行通过真实 Atlas 的海岸与湖岸植被点选探针。`cargo fmt --all -- --check`、严格 Clippy、wasm32 全特性检查、原生 Release 构建和 Trunk 离线 Web Release 构建均通过。

原生复核入口为 `cargo run --release --bin sekai`。生成 Civ Atlas，在“叠加”选“盛行风（环流）”，放大并回缩。切换“填色”的“潜在自然植被带”和“高程”，对照附近海岸或湖岸的两侧读数。可在二维和球体上分别展开“来源、尺度与已解析范围”，核对工作格与来源格的说明。最终操作验收由用户完成。

## 自审修订（2026-11-19）

尺度面板与地形 LOD 共用的来源格平均格距在 `AtlasFieldDocument` 创建时由同一个面积总和计算。面板展开后的绘制直接读取该值。临时探针对已发布文档连续读取两次，修订前触发两次面积扫描，修订后触发零次。原生面板实读仍为来源格约 122 km、C2 工作格约 461 km。

在 RTX 4080 SUPER、Vulkan、1280 × 720 原生窗口中，用同一个脚本和固定镜头串行对照 `0ad6a2a` 与当前版本。读取地图回调的 944 × 637 像素范围，排除菜单与测量叠字。

- **二维 Draft、种子 42。** 两次实际滚轮事件将 Equal Earth 从 16 倍放大到约 43.5 倍、118.2 倍。包括地形与风箭头的画布在每档逐像素相同。每个呈现器的风层累计上传旧版为 1、2、3，新版为 1、1、1。两次滚轮所在的应用主线程更新分别从 117.47、135.40 ms 变为 0.259、0.244 ms。地形细节仍在后台装配，两段时间仅计应用处理该输入帧。两版箭头在深色海面上的对比度均较低。
- **球体 Standard、种子 27276201。** 在 96 倍海湾点选干陆和海面，两版画布逐像素相同。原生检查器在 L7 显示干陆叶片高程 28 m、来源格 11711 的亚热带荒漠和温雨依据。在另一个混合来源格上点选海洋叶片显示床高 −471 m、海水深 471 m，并报告水面无陆地植被带。海岸、湖岸的同源读数另由单世界 Release 探针核对。
- **冷首帧。** 相同的应用记录口径下，Draft 二维为 21.51 s 与 22.10 s，Standard 球体为 21.00 s 与 20.89 s。每个版本各测一次，首帧提速仍缺少证据。

截图、逐帧计数与原始日志在 `target/atlas-lod-native-review/`。`compare.py` 对照相机、字段设置和画布像素。

## 每项承重技术的出处

- 视图缩放和底层采样分辨率可各自管理，参见 [Losasso 与 Hoppe，Geometry Clipmaps（2004）](https://hhoppe.com/proj/geomclipmap/)。本轮只复用已有的二倍档位和来源格距下限。
- 风分量的来源格诊断取样及 C2 工作域见 [C2 海上季节热源与来源格风场重建](2026-11-18-c2-climate-advisories.md)。
- 分类可通过所属格继承，参见 [CGAL 的球面 Delaunay 与 Voronoi 对偶](https://doc.cgal.org/6.2/Triangulation_on_sphere_2/index.html)和 [GDAL 的最近邻重采样](https://gdal.org/en/stable/programs/gdal_raster_overview_add.html)。Sekai 已有来源格的 Voronoi 多边形，扇区细分保留父格边界。
- 细床、水体和未解析拓扑的适用域见[世界真值的尺度边界](2026-11-03-world-truth-scope-design.md)的 R3，以及[潜在植被带的来源与分类](2026-11-18-biome-v1.md)。
