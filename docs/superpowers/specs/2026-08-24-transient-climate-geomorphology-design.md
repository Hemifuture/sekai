## 1. 冻结结论

P5 不再寻找“从 P3 重启 100 ka 地貌历史”的气候—地形终态不动点。生产语义
改为：P3 只初始化一次，P4 在当前地形上完成快时间尺度平衡，P5 从当前完整
地貌状态向前推进一个慢时间窗，再在新状态上重求水面与气候，直到累计
`SURFACE_FORMATION_HORIZON_YEARS`。

本设计冻结四个不可拆开的因果边界：

1. 一个统一的亚格元水面几何算子同时产生水体积、陆海面积分数、共享边湿润
   比例和离散海陆拓扑；P3、P4、P5 与 UI 不再各自解释海岸。
2. P5 保留并推进同一份高程组成、沉积、陆面水库与水文状态，不在耦合窗之间
   回到 P3。
3. 地貌时间窗以整步/两个半步的生产算子比较控制时间离散误差；经验地球统计
   只做诊断，不能替代数值误差门禁。
4. `water_inventory_ratio` 的产品语义升级为**可迁移全水圈库存**；海洋、湖泊、
   土壤水、地下水、雪冰和大气水共同守恒，实际海洋体积另行发布。

本次偏离的是旧实现，不是物理方程。玩家仍可选择非地球水量；机制必须满足
守恒、非负和因果前向演化。

## 2. 废止终态不动点的实测证据

旧映射为：

```text
C(x) = 在地形 x 上求完整 P4
G(c) = 使用气候 c、每次从同一个 P3 重跑完整 100 ka P5
F(x) = G(C(x))
目标：F(x*) = x*
```

Draft/seed 7 的原始 Picard 轨迹稳定进入二周期：相邻轮
`normalized_max` 为
`14.2779 -> 2.5166 -> 2.5473 -> 2.5502 -> ...`，隔一轮比较则为
`0.891808 -> 0.087302 -> 0.013872 -> 0.001884 -> ...`。这不是少算几轮，
而是 `A -> B -> A -> B`。

未提交动态 Aitken 原型进一步给出：

```text
omega: 1.0 -> 0.986785 -> 0.493519 -> 0.327098 -> 0.140482 -> 0.404956
raw-candidate residual: 0.0535
同一时刻真实接口残差 F(x)-x: 3.681727 m RMS
强制未松弛复核: 2.5438 normalized_max
```

因此低 raw-candidate 残差没有证明松弛接口是根；Aitken 只松弛连续高程，也
不能同步表示半条河、半个湖泊出口或半份沉积来源。更强 Anderson/IQN/SNES
仍只能寻找已定义方程的根，不能把抹除历史的终态方程变成真实地理过程。

这些失败轨迹保留为设计证据；对应原型代码、V2 Aitken wire 和求解器 UI
不得进入生产。

## 3. 权威状态与时间因果

时刻 `t` 的生产状态 `S(t)` 至少拥有：

- `FormationElevationComponents` 的全部累计组成和最终高程；
- 沉积厚度、来源比例、在途质量与累计质量账本；
- 陆面雪水、根区土壤水和慢地下水库；
- 当前海洋、湖泊和大气水量；
- 由当前水面几何派生的海陆分数、湿边与离散水文拓扑；
- 当前地形/水库条件下的完整 P4 快平衡气候。

唯一生产流程为：

```text
S(0) <- P3 初始化一次
while t < horizon:
    水圈库存分配 + 统一水面几何
    C(t) <- 当前 S(t) 上的 P4 快平衡
    月尺度陆面水量与 C(t) 交换 P / ET / runoff
    S_trial <- 从 S(t) 前向推进地貌 dt
    以整步/两半步比较决定接受或缩短 dt
    S(t + dt) <- 接受的两半步状态
```

接受后只保留时间更细的两半步结果。拒绝步不改变已发布/已接受状态，不产生
artifact。取消也必须保持原子性。

## 4. 统一亚格元水面几何 SSOT

### 4.1 连续地形重建

权威球面格元已有共享顶点和共享边。水面算子采用确定性的 P1 分片线性模型：

1. 每个共享顶点从所有相邻格元中心高程作 Shepard 距离权重凸组合；权重只由
   权威球面几何决定，不引入地学系数。
2. 每个格元以其球面质心和有序边界顶点组成三角扇；每个扇三角上的高程按
   重心坐标线性变化。
3. 给定海平面后，在参考三角形上按零水深线裁剪；湿面积和线性水深积分解析
   计算。球面三角面积用于物理缩放，并按格元存储面积归一，保证所有扇面积
   严格回收到该格元面积。
4. 共享边湿润比例只由同一对共享顶点高程与海平面求得，因而两侧格元逐位
   一致。

一个生产调用同时派生：

- `ocean_area_fraction` 与 `land_area_fraction = 1 - ocean_area_fraction`；
- `wet_edge_fraction`；
- 每格湿面积、水体积和平均湿区水深；
- 总水体积；
- 以格元中心是否被淹没定义的 `LandOceanField`，仅服务离散水文终端。

面积分数和湿边连续变化；海峡开闭、分水岭改变等真实拓扑事件仍允许离散
发生，但不再让一个格元的全部通量因厘米级水线变化同时翻转。

### 4.2 海平面求解

`water_volume_at_sea_level_m3` 和海平面求解必须调用同一亚格元积分，旧的
“平顶格元水柱”公式不再作为第二份事实源。体积函数连续、单调；求解区间由
生产高程物理域和库存给出，停止条件只来自既有水量闭合与浮点可分辨性。

P4 单元陆海分数由权威源分数保守重映射；P4 工作网格共享边通透性由工作网格
上的同一 P1 湿边几何生成，不再使用两格 water fraction 的 `min`。P5 海岸
交换、P4 蒸发/反照率和 UI 海岸字段消费同一结果。

## 5. 多速率前向共演与时间误差

气候平衡相对地貌演化快多个数量级，因此 P4 是每个慢耦合窗的快组件，P5
是保留历史的慢组件。既有 `SURFACE_FORMATION_MACRO_STEP_YEARS` 只作为首次
试探步，不是保证精度的常量。

对每个试探 `dt`：

- 分支 A：在起点气候强迫下推进一个整步；
- 分支 B：推进半步，在中点重求水面/P4/陆面水量，再推进第二个半步；
- 用生产字段和生产面积计算高程组成、沉积质量、水库和水文拓扑的时间误差；
- 若误差不满足冻结精度，丢弃两个分支并缩步；满足时接受分支 B；
- `dt/2`、`dt/4` 语料必须证明误差随缩步下降，不能用输出重映射伪造收敛。

误差归一尺度和最小时间窗在 Task 4 先用生产种子测量，再依据方法阶数、已有
量化语义和文献钉入本规格修订；本版不先拍数值。资源预算只限制工作量，不能
让未达时间精度的状态发布。

## 6. 守恒陆面水量

在尚无生物群系的阶段，最小陆面模型只表示可辨识的物理水库，不伪造植被：

- 雪水当量 `S_snow`；
- 单层根区/活动层土壤水 `S_soil`；
- 慢地下水库 `S_groundwater`。

每格每月满足：

```text
P_rain + melt
  = ET + Q_fast + recharge + delta(S_soil)
P_snow - melt = delta(S_snow)
recharge = Q_base + delta(S_groundwater)
Q_total = Q_fast + Q_base
```

实际 ET 由 P4 的辐射、温度、湿度和风给出潜在需求，并受可用土壤水限制；
入渗/补给受基质渗透性与饱和度限制；地下水连续释放基流。具体相变、容量、
排泄时间尺度和陆面空气动力参数必须先跑生产探针，再从同行评审陆面模型或
数据集取值并以修订条目冻结。所有数值常量进入 `src/world/`，测试复用生产
helper。

`Q_total` 驱动汇流和侵蚀；ET 作为潜热和水汽源回到 P4。不得继续使用
`precipitation * [0.15 + 0.70 * (1 - permeability)]` 作为最终径流机制，也
不得用提高河流阈值掩盖缺失水量过程。

## 7. 全水圈库存语义

用户裁定 `water_inventory_ratio` 代表相对地球参考的可迁移总库存。任一接受
状态必须满足：

```text
V_total = V_ocean + V_lake + V_soil + V_groundwater
          + V_snow_ice + V_atmosphere
```

所有项非负；大气、陆面和海洋之间的通量成对记账。海平面只使用当时的
`V_ocean`，不再把总库存每次全部灌回海洋。P3 初始分配、P4 大气初始化与陆面
空/平衡启动策略必须在生产探针后冻结，且默认世界的总库存仍严格等于
`water_inventory_ratio` 对应值。

UI 将原“海水量”更名为“可迁移水库存”，并独立显示实际海洋体积及各水库
占比。合法范围与建议带仍属于世界参数事实源；不因这次语义升级复制数值。

## 8. Schema、身份与模块边界

- `world` 拥有水面几何 payload、水库状态、守恒报告和有出处常量；
  `generators` 拥有重建、裁剪、求根、月水量和时间推进算法。
- P4 只通过验证后的连续地表 forcing 读取地形/水库，不读取 P5 内部累计器。
- P5 snapshot 升版只在第一个真实新 wire 提交发生；废止的 Aitken V2 从未提交，
  不占用 schema 版本。
- model/stage/fingerprint 在方程实际改变的任务中刷新；P0–P2 不因下游改变而
  刷新。P3 水面事实、P4 forcing、P5/T1 和呈现金样按实测因果链登记。
- checkpoint 必须保存前向状态、累计时间和库存，不能再用 outer fixed-point
  iteration 表示工作量。

## 9. UI 交付

地图与球面字段注册表至少增加：连续海洋面积分数、土壤水、地下水、雪水、

## 10. 验收边界

硬结构门禁：

- 总水、沉积质量及成对能量通量闭合；
- 全部水库非负、面积分数有界且逐格和为 1；
- 海平面体积函数单调并达到声明闭合；共享湿边两侧逐位相同；
- receiver 邻接、无环、排水面不逆坡；
- 整步/半步时间误差达到冻结精度；拒绝步与取消不污染状态；
- 确定性、schema、checkpoint、artifact 与字段身份一致。

只检测、不拒绝生成：全球降水、陆地比例、平均海深、各水库地球占比、河网
密度、Strahler 分布、侵蚀率、海岸迁移速度、耗时和迭代/重试次数。

## 12. R1 修订：统一亚格元水面几何实测冻结（2026-08-24）

Task 3 的生产实现冻结如下；本修订细化 §4，不改变 §1 的批准结论：

1. 顶点重建采用 Shepard (1968) 的 `p = 2` 反距离权重。球面半径对同一顶点的
   所有样本相同，故实现直接使用中心角 `theta_i` 的
   `w_i = 1 / theta_i^2`。为让常数场逐位保持常数，求和写成与原式代数等价的
   锚点差值形式
   `z_v = z_a + sum(w_i * (z_i - z_a)) / sum(w_i)`；这不是新系数或平滑器。
2. 每格球面三角扇先按权威共享顶点计算球面三角面积，再以格元权威面积归一；
   前 `n - 1` 个扇面按比例赋值，最后一个扇面接收精确剩余面积，使每格扇面积
   之和回到唯一的格元面积事实。
3. 每个扇三角使用 P1 线性水深。零水深线与边的交点由端点水深比例解析得到；
   一湿顶点、两湿顶点和全湿三种情形分别直接计算湿面积及
   `integral(max(depth, 0))`，不作采样积分或结果重映射。共享边湿润比例只计算
   一次并按 `EdgeId` 发布。该低阶解析积分与 Dunavant (1985) 的三角形线性
   单元积分事实一致。
4. 海平面在 `f64` 包络内二分，直到中点与某一端点相同，即区间已无可表示的
   内部浮点数；随后量化为 `f32`，并在该值及相邻两个 `f32` 中用同一体积算子
   选择绝对残差最小者，等残差时取数值较小者。不存在经验迭代上限。
5. `physical-land-area-fraction` 从旧格元中心面积统计改为连续 P1 湿区的互补
   面积。按 §10，它是 detection-only observation：保留实测，不以旧
   `0.20..=0.55` 地球经验带拒绝生成，也不另钉一个更低阈值。
6. 旧平顶格元体积公式、排序求根以及 P5 forcing 中的第二份格元中心水深复算
   已删除；体积查询、海平面求根、P3 质量评估和 P5 输入校验消费同一生产算子。

## 13. R2 修订：连续海岸贯通 P3、P4 与 P5（2026-08-24）

Task 4 的生产实现冻结如下；本修订细化 §4、§8 和 §10，不改变 §1 的批准
结论：

1. P3 以 `PRIMARY_RELIEF_SCHEMA_V2` 只持有一份权威

   重建水面几何。

### 14.3 最佳实践支持的求解语义

在没有玩家指定地质年代和非平稳外部强迫的情况下，唯一可辨识的当前态语义是
**固定外部强迫下的准稳态/动态平衡**，不是任取一个演化年数后的截帧。生产
流程改为：

```text
S0 <- P3 当前构造地形、当前水库存和当前强迫
repeat:
    在候选地形/水库上求 P4 快平衡和陆面水量季节周期平衡
    计算当前抬升、侵蚀、输运、沉积、海岸和水量通量
    用 pseudo-transient continuation 产生下一个候选
    检查守恒、状态漂移和当前通量平衡
until 所有终端残差同时收敛
在 S* 上重求一次 P4、水面、水量和水文并原子发布
```

伪时间步只用于稳态方程的数值 continuation，不代表世界年龄，不进入 schema、
指纹语义、报告或 UI。生产不再承担瞬态时间精度；它必须证明不同合法伪时间
调度收敛到同一终端状态。资源上限只能返回携带最佳终端残差的 typed failure，
不能发布未平衡状态。

动态平衡不是要求每格逐位静止。Paik & Kim (2021) 明确指出纯逐格稳态可能
达不到，且 relief、平均高程、降雨和沉积产出的收敛时间不同。因此终端报告
至少逐项记录并同时门禁：

1. 当前固体通量平衡：构造物质源与侵蚀输出、沉积库存变化和深海输出闭合；
2. 面积加权地表净变化率，以及 relief 与平均高程的连续迭代漂移；
3. 当前年降水、总径流和沉积产出的连续迭代漂移；
4. 季节周期首尾的土壤水、地下水、雪冰、湖泊和大气水库漂移；
5. 当前 receiver 邻接、无环、排水面单调和最终 P4/P5 forcing 一致性。

每个残差的归一尺度、连续通过次数和最大工作量仍遵守“先测后钉”：Task 5
先以生产算子输出原始物理单位数据，再从下列文献的方程、数值误差或公开数据
不确定度取值。找不到直接阈值的项目必须以开放问题提交用户，不得从希望得到
的地貌反推容差。

### 14.6 坡面显式算子的稳定性修订

seed `3` 的当前态探针确认，旧坡面算子在大伪步中静默丢失了未消费的伪时间。
固定的“每步最多改变局地起伏 `25%`”没有直接文献出处，而且不是时间积分：

| 内部候选步 | 活动干陆边 | 单元限制边 | 实际/请求质量 |
| ---: | ---: | ---: | ---: |
| `12,500 yr` | 8,967 | 214 | 0.986769 |
| `1,061,713 yr` | 8,538 | 6,338 | 0.549959 |
| `1,797,292 yr` | 8,502 | 7,675 | 0.367679 |

同一探针的旧相邻状态 `normalized_max` 最终为 `0.8082`，但当前净地表变化
RMS 仍为 `1.84040e-4 m/yr`；最高格元以 `4.78278e-4 m/yr` 上升并逼近
`ELEVATION_MAX_M`。因此旧门禁和 `25%` 裁剪均被否决，不能通过忽略该格元、
钳制高程或放宽容差处理。

显式非线性坡面有限体积算子改用离散单调 CFL 上界。对干陆边 `e=(i,j)`：

```text
T_e = D_eff,e * L_e
    / (d_e * max(1 - (s_e / S_c)^2, denominator_min))

lambda_i = sum(e incident to i)
    T_e / A_i * max(rho_i, rho_j) / rho_alluvium

dt_CFL = 1 / max_i(lambda_i)
```

`T_e` 是生产 Roering 型通量的同一 transmissibility；密度比取边两端基岩
密度最大值与 `FORMATION_ALLUVIAL_BULK_DENSITY_KG_M3` 之比，覆盖疏松沉积物
移除和接收端堆积导致的最大高程响应。该上界使一次 forward-Euler 更新保持
非负权重和离散最大值原理。候选步超过上界时必须缩到上界或回滚重试，不得
裁剪通量；初始候选也从当前离散算子和高程物理域推导，不再读取固定地貌窗口。

这里的 `dt_CFL` 只有内部数值单位；它不代表世界年龄，不进入 snapshot、
checkpoint、artifact、指纹、报告或 UI。每次构建成功后全部中间候选丢弃，
取消、失败或未达到终端物理残差时不发布任何 P5 状态。

旧 P5 规格 §5 的“到达安全边界时缩小所属过程并保留截断增量”同样被本修订
替代。构造位移必须完整计算 `z_forced = z + (uplift - subsidence) * dt`，局部
Airy 响应必须完整计算 `delta_z = (removed_mass - deposited_mass) /
(rho_mantle * area)`；两者的完整结果超出可表示数据域时返回携带格元和未裁剪
结果的 typed failure。上层只能回滚整个私有候选并按数值稳定条件重试，不能
裁剪过程、修改质量账本或发布边界值。对应 RED/GREEN 契约分别位于
`formation_stream_power` 与 `formation_coast_isostasy`；两套 Release 测试共
`13` 项通过。

**2026-08-24 数值身份补充修订。** 上述“完整结果”是
`f64(primary_relief_m) + equilibrium_adjustment_m` 的唯一内部累计状态，不是
已经量化为 `f32` 的工作高程再加某一个过程增量。各过程仍按自己的物理方程
计算位移；编排层先把位移加入完整累计状态，再统一校验数据域，最后才生成
`f32` 工作/发布高程。这样既不能让真实的亚 ULP 越界借舍入混入数据域，也不能
把先前亚 ULP 侵蚀已经保留在累计状态中的格元误报成 Airy 越界。对应契约以
`9000 m` 附近一个 `f32` ULP 内的卸载—回弹组合为解析夹具，分别验证“完整态
域内”和“完整态真实越界”两个方向。浮点舍入与中间精度的数值依据为 Goldberg
(1991), *What Every Computer Scientist Should Know About Floating-Point
Arithmetic*, ACM Computing Surveys 23(1), DOI `10.1145/103162.103163`；该文只
支持先定义精确运算语义再选择舍入边界，不为 `9000 m` 本身提供科学出处。

删除两处裁剪后的 Draft seed `3` 探针在 `71.70 s` 后明确失败且没有 artifact：
`CellId(4394)` 的完整 Airy 候选高程为 `9000.000172653947 m`。追溯表明
`ELEVATION_MAX_M = 9000 m` 由提交 `ee40e4c` 首次引入，当时只标注为“safe
final elevation”，没有数据集、公式或取值过程。因此该值目前只能作为待审定的
旧数据契约，不能解释为地球物理上界，也不能直接扩大。Task 5 必须继续判断
终态是否需要高于该域，或是否缺少有出处的物质出口；在完成该归因前保持此项
为**开放问题**。

同一格元在失败前一次完整当前态评价中的关键量为：高程 `8980.891 m`，
receiver 高程 `7547.028 m`，排水面落差 `1433.860 m`，年径流
`442.444 mm/year`，汇水面积 `28121.732 km2`；当前构造抬升、河流侵蚀、

### 14.7 沉积连续方程修订与参数开放问题

旧路由使用

```text
capacity = C0 * discharge * dt * slope_response
floodplain_accommodation <= 50 m per macro step
```

其中 `C0 = FORMATION_SEDIMENT_CAPACITY_KG_M3`、坡度响应和
`FORMATION_FLOODPLAIN_ACCOMMODATION_M` 都来自已被 R3 否决的固定 `100 ka`
实现，没有直接一手数据、取值过程或可复核尺度映射。它们不得继续承担当前态
固体通量平衡，也不得通过修改 `C0`、调小沉积或扩大高程域来追 seed 输出。

**2026-08-25 继承边界澄清。**
`FORMATION_SEDIMENT_CAPACITY_KG_M3` 已不再存在于生产 P5；
`FORMATION_FLOODPLAIN_ACCOMMODATION_M` 只由既有 T1 呈现链按其冻结规格消费，
不参与 P5 科学路由。恢复 `SURFACE_FORMATION_HORIZON_YEARS` 不重新证明该 T1
数值；其直接出处仍是所属 T1 规格的独立开放问题。本修订不以替换机制、补拍
系数或扩大范围来关闭该问题。

替代候选采用 Davy & Lague (2009) 的 `xi-q` 侵蚀—沉积质量平衡，以及
Landlab `ErosionDeposition` 的逐格解析递推。对按上游到下游排序的单元 `i`：

```text
Q_s,out[i] =
    (Q_s,in[i] + (1 - F_f) * E[i] * A[i])
    / (1 + V_eff[i] * A[i] / Q[i])

D[i] = Q_s,out[i] * V_eff[i] / Q[i]
```

`E` 与 `D` 是固体体积通量密度，`Q_s` 是固体体积流量，`Q` 是水体积流量，
`A` 是权威球面单元面积。全部量统一到 `m` 与 `year` 后，分母中的
`V_eff * A / Q` 无量纲；质量来源比例随同一 `Q_s` 线性递推，不能另写第二套
路由。Sekai 跟踪全部五类被侵蚀物质，不能像部分实现那样静默丢弃 wash load，
所以当前闭合语义要求 `F_f = 0`；若以后区分永久悬移质，必须把它显式记入深海
出口而不是从账本消失。

Landlab 明确说明 `V_eff` 是 Davy--Lague `d* V` 合并后的**有效**沉降速度，
并非可直接使用的单颗粒静水沉速。Terrainbento v2.0.1 `BasicHy` 的可复核默认
为 `settling_velocity = 0.001`、`fraction_fines = 0.5`，但其框架单位无关，且
该默认没有证明可原样迁移到 Sekai 的全球粗球面格网。因此本修订只冻结方程和
单位映射，不冻结 `V_eff` 数值；在找到直接标定、公开数据处理或经用户裁定的
类比论证前，`V_eff` 是**开放问题**。Task 5 可以先实现参数显式注入的解析算子
和质量闭合测试，但不得把未经审定的默认值写进生产模型指纹。

Task 5 的生产实现因此不声称一个未经观测约束的混合侵蚀--沉积制度，而选择
Davy--Lague 方程明确包含的 detachment-limited 端元：
`V_eff = 0 m/year`，即 `xi -> infinity`。该值不是从目标地貌反推的经验默认值；
它是当前缺少粒径、Rouse 数和河道水力几何时唯一不虚构内陆沉积的精确模型
边界。所有河流侵蚀物质仍逐来源守恒路由到湖泊、闭流盆地、陆架或深海终端，
不得从账本消失；流经格元不凭容量曲线沉积。非零 `V_eff` 的生产启用继续作为
开放问题，必须等待这些可辨识状态或公开标定进入事实源。

解析契约以三格路径逐格设置 `V_eff * A / Q = 1`，实测出流/沉积依次为输入的
`1/2`、`1/4`、`1/8`，并同时验证五类来源与全球质量账本。生产端元契约验证
`V_eff = 0` 时所有河流物质到达显式终端。旧 `C0`、坡度响应、每步泛滥平原
容置裁剪和海洋容量曲线已从 P5 方程与模型指纹删除；`delta_potential` 改为同一
当前输沙批次的实际陆架保留比例，不再使用第二套容量公式。

方程出处：Davy & Lague (2009), DOI `10.1029/2008JF001146`；同行评审软件
说明：Barnhart et al. (2019), DOI `10.5194/gmd-12-1267-2019`，式 (37) 与
附录 BasicHy；可复核离散实现：Landlab commit
`4c932692bc716eec84007310e7d33e2470946eb0` 的
`erosion_deposition/cfuncs.pyx`。Terrainbento 默认值仅作为参数调查证据，代码
版本为 v2.0.1 commit `e64a095e098515949ce7e2dce6c756409e49506c`，不构成
Sekai 常量授权。

## 15. R4 修订：发布原子性与平衡证据边界（2026-08-24）

本修订只收紧 §14 的发布契约、可解性假设和出处边界，不改写既有历史结论，
也不新增算法、常量或验收门禁。§14 的表述若可能把数值中间态、旧数据域或
软件默认值解释为已获科学审定的平衡条件，以本修订为准。

### 15.1 只发布当前终态

P5 唯一可发布的 artifact 是所有既定发布条件均通过后原子构造的当前终态
`S*`。pseudo-transient continuation 的全部伪时间、候选状态和步长日程只是
一次构建内部的私有求根中间态；它们没有世界年龄语义，不进入 artifact、
checkpoint、schema、指纹、报告或 UI，也不能作为“最佳可用状态”降级发布。

求解失败、用户取消或在资源上限内未收敛，都必须结束为无 P5 artifact 的
typed outcome。任何越出当前可表示数据域的完整候选都不得发布；上层先按
§14.6 回滚整个私有候选，并只依有出处的数值稳定性条件重试。只有在按 §14.6
回滚重试并耗尽既定资源上限后仍无法得到域内完整候选，或当前态边界格元的
物理净率持续指向域外且问题没有可解的域内根时，才返回无 P5 artifact 的
typed outcome。错误诊断可以携带格元、未裁剪值和终端残差，但该诊断不是
artifact。`ELEVATION_MIN_M` 与 `ELEVATION_MAX_M` 当前只参与数据域校验；
到达边界本身不构成动态平衡。

### 15.2 项目探针与可解性开放问题

**项目探针。** 本轮 Task 5 当前态生产算子探针中，trench `CellId(19366)`
已经位于 `-11000 m`，净地表速率仍为 `-0.001016063 m/year`。这只证明当前
候选在当前数据域下仍指向更低高程，不证明 `-11000 m` 是平衡点，也不单独
判定成因。`ELEVATION_MIN_M` 由项目历史 commit
`ee40e4cbd2363cadb3adf4e926498b5fed0a191d` 以“minimum safe final
elevation”引入，没有直接数据集、公式或科学审定过程，因此目前是旧数据契约，
不是有直接科学出处的平衡边界。

**2026-08-24 完整状态复测。** 修正上述数值身份后，Draft/seed `42` 的同一
格元在五次气候求解后的高程依次为 `-6629.223`、`-7877.823`、`-9351.201`、
`-10735.578`、`-10998.580 m`，随后完整候选到达
`-11000.000274626422 m`。该格元始终是无 receiver 的海洋终端，沉积厚度和
局地 runoff 为零；`uplift = 0.024603449 mm/year`、
`subsidence = 1.040666938 mm/year`，所以构造净率为
`-0.001016063 m/year`。河流侵蚀、坡面侵蚀/沉积、路由/海岸沉积、海岸侵蚀和
Airy 响应均为零。因此这次下界失败已经归因到“恒定构造净沉降是该格元唯一
非零项”：在当前绝对高程稳态方程和当前过程集合下，该格元没有域内根。测量
仍不能裁定正确修复是改变构造强迫的时间/状态语义、补齐有出处的深海过程，
还是改变产品所求的状态量；这些选择会改变科学模型，必须先经设计裁定。

**开放问题。** 该 trench 现象可能暴露数据域不足，也可能暴露构造、沉积、
压实、化学变化或深部物质出口缺项；当前证据不能区分这些解释。在局地项和
系统边界完成归因并由用户裁定前，禁止先修改 `ELEVATION_MIN_M`，也禁止钳制、
忽略该格元或放宽残差来制造 artifact。

**项目探针。** §14.4 的 Draft/seed `42` 测量使用权威球面单元面积加权，量为
当前 P2/P3 构造强迫
`uplift_rate_mm_per_year - subsidence_rate_mm_per_year`；其全球均值约为
`-0.043126 mm/year`。这是一个 seed 在当前生产算子和当前参数下的观测，不是
世界常量、跨 seed 包络或总地表响应率。

**开放问题。** 当构造强迫本身具有非零全球均值且固体系统边界尚未闭合时，
“面积加权全球平均高程速率严格等于零”可能没有根。必须复核垂直参考系、构造
源汇、沉积库存和深部边界后，才能决定该量应是求根方程、诊断还是另一个守恒
量的派生结果；本修订既不新增也不放宽相关门禁，更不把 seed `42` 的数值钉成
常量。

### 15.3 PTC 方法与残差门禁的出处边界

Kelley & Keyes (1998) 直接支持以 pseudo-transient continuation 求稳态及其
收敛分析；它不直接定义 Sekai 的地貌系统边界、三个残差标量或任何数值阈值。
PETSc 的 `TSPseudoTimeStepDefault` 仅作为残差驱动伪步日程的工业实现类比。

PETSc 同一实现中的单精度默认 `frtol = 1e-5` 是通用函数二范数相对初始函数
二范数的停止设置，不是 Sekai 的 `mean_elevation_flux_balance_ratio`、
`rms_relief_flux_balance_ratio` 和 `sediment_stock_change_ratio` 三个门禁的
直接出处，也不能证明将三个不同物理聚合量共用 `1e-5`。这三个门禁的量纲映射、
可解性和阈值仍属待复核项；在直接依据补齐前不得把 PETSc 默认值写成科学验收
背书。

### 15.4 逐格平衡与 generalized Exner 系统边界

上述三个门禁都是全局聚合标量。它们即使同时很小，也可能隐藏不同格元之间
的正负抵消、边界格元仍持续运动，或局地物质源汇未记账；因此它们不足以认证
逐格局地平衡。它们可以保留为全局诊断，但在逐格守恒残差和系统边界被明确定义
之前，不能被解释为充分的局地物理平衡证书。本修订不为此临时发明第四个门禁
或阈值。

Paola & Voller (2005) 的 generalized Exner 质量守恒直接表明，删减方程前必须
显式盘点构造抬升/沉降、基岩成土与蠕变、压实、化学沉淀/溶解，以及可独立
演化的“基岩—沉积物/土壤”和“沉积物—流体”两个界面。Sekai 当前 P5 边界尚未
说明这些项中哪些被建模、哪些经尺度分析可忽略，也未把 `burial`、
`lithification` 或 `subduction` 定义为库存间转移或离开活动地表系统的显式
sink。因而构造、双界面、压实、化学项与深部 sink 的系统边界仍未闭合，这是
阻止局地平衡认证的开放问题，不授权新增过程或经验系数。
