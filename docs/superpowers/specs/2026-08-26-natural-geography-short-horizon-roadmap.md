# 自然地理短期路线图（2026-08-26）

状态：**执行顺序与机制已批准**（2026-08-26）。本文件冻结短期目标、队列和已确认
做法。未实测的常量、包络、每预设大陆板块数、老盆初始年龄在 G0 之后由该里程碑
规格钉死。G0 实测见 `2026-08-26-g0-geography-baseline-design.md` §4。每个里程碑
仍须有独立规格、逐任务计划、UI 接入、证据和提交。

取代：`2026-08-23-natural-world-scientific-remediation-roadmap.md`（已废止）。

上位：`AGENTS.md`；形成链
`2026-08-24-geologic-pipeline-contract-restoration-design.md`；预设语义
`2026-08-02-world-formation-presets-design.md`。P2 运动学参考 Cortial et al.
2019，不是大陆几何或洋龄场的字面方程。

## 1. 目标

在形成链上生成可在 UI 上认出的自然地理。预设决定陆地怎么切；陆地占比始终可调；
洋盆有中脊–深海平原结构；测高和水线由过程决定。

生产链维持现状，不为地理加密耦合：

```text
P2 128 × 2 Myr → P3 一次投影并解海面 → P4 快平衡 → P5 100 kyr → 终点 P4
```

病征在 P2 开局（陆壳、洋龄）和 P3 投影。P5 几乎不改陆海分类（T0 §2.3：约
0.15%）。短期只动地理成因，不动河网显示、气候水热、水文 v2。

### 已确认的产品规则

1. 五种预设是形态原型（Azgaar 式），不是“唯一地球”。Continents = 数块主要大陆，
   只是其中一种。
2. 陆地占比在所有预设上可调，不得删除或锁死。拖动它只移动海平面
   （`SeaLevelPolicy::TargetLandFraction`），不改陆壳形状、不做高程重映射。
   地球水量是摘要中的 `r` 和建议带（T0b 0.5–2.0），不是锁。新世界滑块初值用
   当前 `recommended_land_fraction`；用户改过之后切换预设不得覆盖。
3. G1 让陆壳骑在已有板块上，再用现有 256 Myr 裂谷/扩张/俯冲/碰撞做张开与局部
   碰撞。不新写威尔逊旋回求解器，不加地幔对流，不延长 P2 时域。陆壳是连通块、
   种子落在板块上，允许一块陆地跨相邻多板；板块可同时含陆壳与洋壳。不开局
   把选定板涂满（R6，用户裁定要地球机制）。
4. 不改 GDH1、Airy、浴缸恒等式、CRUST1.0 台地厚度分位。

## 2. 现状（代码事实）

`initial_crust_samples` 仍用与板块无关的 FBM 分位涂陆壳；洋龄是另一张 FBM
（8–180 Myr）。板块分区已经存在，陆壳不骑在上面。生成器未改。

G0 已测（见 `2026-08-26-g0-geography-baseline-design.md` §4.5）：陆壳**可以**
连成 1–4 块，Supercontinent 经常就是一块；病征不是“噪声群岛连不上”，而是
块不骑整板。洋龄近脊已有浅梯度，缺的是 >140 Myr 老盆，不是无结构平底。

现有质量门有 `physical-land-area-fraction` 和
`old-young-ocean-depth-separation-m`（≥ 600 m），没有陆块连通、陆壳–板块重合、
洋龄空间结构或扩张新生份额。

陆地占比滑块在 `WaterInventory` 默认下被禁用，与规则 2 冲突；G3 一并改正。

## 3. 队列

| 顺位 | 里程碑 | 做什么 |
| --- | --- | --- |
| G0 | 基线实测 | 用生产 P2+P3 量化病征，给 G1/G2 钉数 |
| G1 | 陆壳跟板块走 | 按预设把陆壳填进选定板块（或板块内部连贯域） |
| G2 | 洋龄跟扩张走 | 去掉 FBM 洋龄；年龄由扩张/俯冲史决定 |
| G3 | 测高、水线、滑块 | 复测测高；陆地占比滑块始终可调；只刷新真实变化的指纹 |

G2 诊断可与 G1 规格并行起草；合并先 G1 再 G2。

### G0 — 基线实测

草稿档，默认半径。预设：Continents、Supercontinent、Archipelago。种子：`42`
加能区分形态的最小对照，不得默认 17 粒全链。停在 P2+P3。

复用生产场，禁止重写 Airy/GDH1/浴缸。必测：

- 陆壳连通块数、最大块面积份额、与板块的重合；
- 陆地连通块数、陆壳淹没份额；
- 洋龄空间结构、分位、距扩张/板块边界；
- 演化期内新生洋壳 / 终态洋壳面积；
- 年轻/年老洋底深度差、浅于 1000 m 的湿面积；
- T0 测高七项与陆地占比。

交付：ignored Release 探针报告。不改生成器，除非形成链 UI 看不到地壳类型、
洋龄、高程——那时只接字段。不在 G0 钉合格带。

### G1 — 陆壳跟板块走

陆壳不再用独立 FBM 分位。按预设在已有板块上放置大陆核，生长连通陆壳块，
直到 `continental_crust_fraction`。R6 起机制以地球为准，详见
`2026-08-26-g1-continental-crust-on-plates-design.md`：

- Continents：少数主要大陆（Mortimer et al. 2017 的 6 块地质大陆为核数锚）；
- Supercontinent：一块主导，跨相邻多板；
- Archipelago：许多陆壳碎块（Cogley 1984 的 14 块大陆为核数锚）；
- VolcanicIslands：少数微陆块（Cogley 的 4 个具名微陆块）+ 已有地幔热点；
- GreatIsland：一块大、其余卫星（微陆块）。

一块陆地可以骑在若干相邻板块上；一块板块通常陆洋混生，不在开局涂满整板。
选核、生长与面积命中由 G1 规格钉死。不要用连通块数当失败；默认不改碎裂帽；
不要把 FBM 碰巧涂到的 2–3 块大板认成已骑板。厚度仍走 CRUST1.0 台地分位 +
已有碰撞增厚/裂谷减薄。板块欧拉运动、时域、机械碎裂帽默认不动。G0 **未**
证明碎裂切开大陆，G1 不单列改预算。

验收：同一 seed、同一陆地占比下五种预设在地壳类型图上可辨；再拖陆地占比，
块体形状不变、只改淹没。未进 UI 不得称交付。

### G2 — 洋龄跟扩张走

停止 FBM 洋龄。视界前的洋壳用有出处的老盆先验（Seton et al. 2020：地球洋壳
最老约 180–200 Myr；钉值先测），演化中扩张铺零龄、俯冲销毁。G0 显示 256 Myr
内累计新生是终态洋壳的 8–10 倍，缺的是老盆与脊轴梯度长度，不是新生过少；
G2 修已有扩张在权威面上的零龄铺设与老盆先验，不加时域、不改 GDH1。

禁止：无归属洋底噪声、把 `UNKNOWN_MIXED_OCEAN_AGE_MYR` 当形态旋钮。G0 浅于
1000 m 湿面积高于 ETOPO1，**不**预加被动陆缘楔。

验收：洋龄图有沿脊/边界的年轻条带；高程上允许大面积深海平原，但须有更浅的
脊或陆架过渡。

### G3 — 测高、水线、滑块

新几何上复测 T0 测高与水量记账。`recommended_land_fraction` 只是滑块初值，
可按实测重钉建议，不得写成不可调常数。作者默认走 `TargetLandFraction`，摘要
显示 `r` 与越带/露洋底提示。目标高于约 `0.9 × 演化后陆壳份额` 时允许露出洋底，
只提示不禁止。低地若仍缺，归因薄缘或陆缘过程，另开后续项。

## 4. 短期不做

河网显示与 T1 v3；P4 水热校正；P5 水文 v2；生物群系；地幔对流；Ga 尺度威尔逊
旋回；用色板掩盖深海平原；为测试新增生产 API 或历史 schema；用板片拉力重算
欧拉极（Forsyth & Uyeda 1975——仅当 G0 证明运动与边界类型矛盾再另开）。

地质管线契约恢复若未收口，先收口再改 P2 核。G0 可跑当前生产算子。

G0–G2 高成本探针：`#[ignore]` + Release。草稿档作者循环；标准档在 G3 收口。
门禁与 UI 验收纪律见 `AGENTS.md`。

## 6. 修订

- R0–R2（2026-08-26）：草案、用户确认队列与产品规则、G1 改为陆壳跟板块走。
- R3（2026-08-26）：删掉旧 R0–R5 辩论、撤回的涂法、重复释义；冻结已确认机制。
- R4（2026-08-26）：G0 实测入档 `2026-08-26-g0-geography-baseline-design.md`。
  陆壳可连成 1–4 块但不骑整板；洋龄近脊偏年轻、无 >140 Myr 老盆；累计扩张
  生成约为终态洋壳 8–10 倍；Archipelago/42 在 P3 Airy 上界越 1 ULP。
- R5（2026-08-26）：写入 G0 结论（§2 与 G1 段）：修归属不修连通；碎裂帽不单列；
  G2 不发明条带、不预加被动陆缘楔。完整表述见 G0 规格 §4.5。
- R6（2026-08-26）：用户裁定 G1 用地球机制，不用“整板涂满”产品卡通。
  陆壳为连通块、核落在板块上、可跨相邻板；板块陆洋混生。G1 段与规则 3
  同步改写。核数改绑 Cogley 1984 / Mortimer et al. 2017，不再用 Azgaar 核数
  当科学常数。
