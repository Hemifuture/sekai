# Sekai 世界形成预设与有限地图海洋边框设计

日期：2026-08-02

状态：已确认方向，待实现

## 1. 背景与问题

当前自然世界主链已经把板块分区与地壳类型作为两个独立随机场生成，但默认地壳算法会优先从距离矩形边界最远的一小组单元中选择大陆核。在 2:1 的封闭平面上，这些候选集中于地图中央，因此多个大陆核实际聚成一个大陆。现有质量门只限制“最大大陆地壳分量不得超过全图 50%”，一块占全图约 38% 的单一大陆仍会通过。

与此同时，`BoundaryCondition::Closed` 没有东西周期接缝。地壳和地形也没有有限地图边缘必须为海洋的契约，所以大陆或火山隆升可能直接接触画面边缘。这会把“完整世界地图”表现成被裁切的局部地图。

Azgaar Fantasy Map Generator 使用 Volcano、High Island、Continents、Archipelago、Atoll 等具名高度图模板，并把 Random 实现为对模板的加权选择。Sekai 借鉴“先选宏观原型，再运行受约束生成”的思路，但不复制直接绘制最终高度的操作脚本：Sekai 的预设只提供当前切片的形成先验，正式地壳、地幔、地形与水文字段仍由各自单一写入者生成。

参考：

- <https://github.com/Azgaar/Fantasy-Map-Generator>
- <https://gist.github.com/Azgaar/b845ce22ea68090d43a4ecfb914f51bd/77a6076e5a7c6788bc66b5b8f8d0e664a888b782>

## 2. 目标

第一阶段交付以下能力：

1. 提供具名、可复现、可审计的世界形成预设，避免宏观海陆格局完全依赖无约束随机结果。
2. 默认 `Continents` 在典型 20,000 单元世界上形成多个彼此由海洋隔开的主要大陆，而不是一个中央大陆。
3. 在仍使用 `BoundaryCondition::Closed` 时，最终构造地形和侵蚀后当前地表的地图边缘保持海洋，并在画面四周形成可见海域；东西边缘是硬要求。
4. 以类型和阶段依赖保证预设不改变板块数量、板块分区、板块速度或板块随机子流。
5. UI 能选择预设；选择 `Random` 时显示实际解析出的具名预设。
6. 保持当前切片模型，不生成历史事件、年代或时间线。

## 3. 非目标

- 本阶段不实现球面、经度周期或跨接缝 Voronoi 拓扑。
- 本阶段不模拟形成预设对应的历史过程。
- 本阶段不复制 Azgaar 的高度图笔刷 DSL，也不让预设直接写最终海拔。
- 本阶段不把“板块数量”解释成“大陆数量”，不为每块板块指定单一大陆/海洋类型。
- 本阶段不删除旧 `src/terrain` 代码；生产自然世界主链继续禁止调用它。
- 本阶段不增加城市、国家、历史事件或城镇布局生成。

## 4. 核心架构决定

### 4.1 世界形成预设是独立上游配置

新增独立、版本化的 `WorldFormationSpec`。它不属于板块配置，也不由板块规则解析器修改。

```text
WorldFormationSpec
        │
        ▼
ResolvedWorldFormation
   ├───────────────┐
   ▼               ▼
地壳形成投影      地幔形成投影
   │               │
   ▼               ▼
Crust field       Mantle field
   │               │
   └──────┬────────┘
          ▼
板块场 + 地壳场 → 边界分类 → Relief → Hydro/Erosion

PlateFormationSpec ─────────→ Plate field / velocities
```

板块生成支路只接收已解析的板块规格和 `plate-*` 随机子流。地壳支路接收世界形成预设的地壳投影和 `crust-*` 随机子流。地幔支路接收地质规格及预设的地幔投影。三者只在已有的显式下游接口汇合。

`TectonicSnapshot` 仍可作为板块、地壳和边界的聚合快照，但聚合不意味着上游互相控制。

### 4.2 独立解析阶段

新增：

- 外部 artifact：`natural.world-formation-spec`
- 解析 artifact：`natural.resolved-world-formation`
- 解析 stage：`natural.resolve-world-formation`

解析阶段只读取 `WorldFormationSpec`，使用自己的阶段随机流把 `Random` 解析为一个具体预设。具体结果进入 artifact 哈希、缓存依赖和应用文档，因此可复现、可显示、可审计。

`TectonicStage` 和 `MantleStage` 读取解析 artifact。`generate_plates` 的函数签名不得接收它；`generate_crust` 只能接收窄化后的地壳形成投影。这样以编译期接口阻止预设意外侵入板块生成。

### 4.3 预设目录

公开选择与解析结果分为两个闭合枚举：

```rust
pub enum WorldFormationPreset {
    Random,
    Continents,
    Archipelago,
    Supercontinent,
    GreatIsland,
    VolcanicIslands,
}

pub enum ResolvedWorldFormationPreset {
    Continents,
    Archipelago,
    Supercontinent,
    GreatIsland,
    VolcanicIslands,
}
```

第一版语义如下：

| 预设 | 大陆地壳宏观结构 | 地幔倾向 | 典型用途 |
| --- | --- | --- | --- |
| `Continents` | 4 个充分分离的主要大陆核，允许少量沿岸岛屿 | 中性 | 默认完整世界地图 |
| `Archipelago` | 10–14 个小型、隔海分离的地壳核 | 中性 | 多岛海与破碎陆块 |
| `Supercontinent` | 1 个主要大陆核，噪声只改变岸线 | 中性 | 单一超大陆 |
| `GreatIsland` | 1 个主岛核和 2–3 个受抑制卫星核 | 中性 | 大岛及附属岛链 |
| `VolcanicIslands` | 8–12 个小型地壳核；海洋占主导 | 活跃热点偏置 | 火山群岛世界 |

这些是有范围约束的原型，不是固定图片。种子仍会改变核位置、相对尺度、岸线与局部地质，但不会改变预设的宏观类别。

`Random` 使用固定权重选择具体预设：

- Continents：40%
- Archipelago：25%
- Supercontinent：10%
- GreatIsland：15%
- VolcanicIslands：10%

权重和映射属于 V1 序列化语义；改变它们需要提升解析 stage 版本。

### 4.4 作者参数与预设的关系

已有 `continental_crust_fraction` 继续是作者/规则系统拥有的定量目标；预设拥有空间形态，不偷偷覆盖该目标。应用 UI 在用户主动切换具名预设时可以填入推荐比例，但该动作是可见的表单修改，生成器仍只读取最终明确规格。

推荐比例：

- Continents：38%
- Archipelago：26%
- Supercontinent：42%
- GreatIsland：28%
- VolcanicIslands：16%

选择 `Random` 不改写当前比例，因为实际预设只能由带种子的解析阶段确定。实际解析结果会在构建摘要中显示。

`VolcanicIslands` 不改变板块活动。它只向独立地幔生成器提供热点数量下限与活跃度偏置；规则解析后的地质规格仍是基准，预设投影只做有界组合。其它预设的地幔投影为中性。

## 5. 地壳形成算法

### 5.1 边缘距离与候选域

从所有空间边界单元执行稳定的多源图距离。按世界短边的固定比例建立两层区域：

- 硬海洋框：最靠近外边界的约 4% 短边距离，不允许大陆地壳核或大陆地壳单元进入。
- 软海洋过渡：从硬框外继续延伸到约 8% 短边距离，对大陆评分施加逐渐减弱的惩罚。

若极小测试图无法容纳目标核数，则按稳定顺序缩窄框宽；不得越界、死循环或随机丢核。对所有支持的 `continental_crust_fraction`，实现必须验证可用面积足够，否则返回明确生成错误，而不是破坏目标比例。

### 5.2 分散大陆核

大陆核不再按“边界距离最高的前 N 个”选取。新算法在硬框内部候选域使用稳定的最远点采样：

1. 用 `CRUST_SEEDS_LABEL` 确定第一个候选的轮转位置。
2. 每次选择与既有核最小距离最大的候选。
3. 相等时依次按种子轮转顺序、`CellId` 决胜。

距离采用量化拓扑/空间度量，不使用未量化浮点比较。输出核数由具体预设决定。

### 5.3 海洋走廊

对两个及以上大陆核，先计算每个单元所属的最近大陆核。不同所有者相邻处构成宏观分水边界；边界单元及预设规定宽度内的单元是海洋走廊保留区。大陆候选评分包含：

- 到所属大陆核的距离；
- 稳定平滑形状噪声；
- 世界边缘惩罚；
- 大陆间走廊惩罚；
- 各核的确定性尺度权重。

按评分选择最接近目标面积的前缀。硬海洋框和硬走廊永不进入候选前缀。大陆核本身获得稳定最低评分，保证每个预设核至少产生一个大陆地壳单元。

`Supercontinent` 只有一个核，不创建内部海洋走廊。`GreatIsland` 的主核权重为基准，卫星核使用更高距离权重，因此主岛占绝大多数大陆面积。其它多核预设只允许小幅尺度变化。

### 5.4 不与板块绑定

大陆核不吸附板块中心，不读取 `PlateIdField`，也不按板块边界切割。大陆地壳可以跨越多个板块，一块板块也可以同时覆盖海洋与大陆地壳。边界分类阶段随后读取两个独立字段，产生碰撞、俯冲、裂谷、洋脊或转换边界。

以下是硬契约：

- 改变世界形成预设不得改变板块种子、单元归属、板块速度。
- 改变板块数量或活动不得改变地壳种类和厚度。
- 允许二者组合后改变边界分类与下游地形；这是显式数据流，不是上游耦合。

## 6. 有限地图海洋边框

海洋边框是 `Closed` 平面投影的通用约束，不属于某个预设。

### 6.1 地壳阶段

硬海洋框内强制为海洋地壳，确保大陆形态不会从边缘开始。该约束由地壳生成器拥有，不由显示层修补。

### 6.2 Relief 阶段

仅有海洋地壳仍不足以保证海洋，因为洋脊、火山和区域偏移可能把它抬到海平面以上。Relief 生成器在四个正式分量求和前应用可解释的边框包络：

- 外边界的地壳基准向深海基准平滑过渡；
- 正向构造、火山和区域隆升在边框内逐步衰减；
- 负向地形效应保留；
- 最外层边界单元最终严格低于正式海平面。

所有调整仍记录在现有正式 relief 分量中，继续满足：

```text
elevation = crust_base + tectonic_offset + volcanic_offset + regional_offset
```

显示层、水文层和侵蚀层不得重新分类或遮罩边缘。现有侵蚀模型不在海洋单元侵蚀或沉积，因此构造地形的边缘海洋保证会传递到当前地表。

未来引入东西周期拓扑时，将由新的边界条件替换这一策略；预设、板块和地壳接口无需改变。

## 7. 地幔投影

`MantleGenerator` 保持不读取板块或地壳字段。它新增一个窄的 `MantleFormationBias` 参数：

- `Neutral`：完全使用规则解析后的 `GeologicSpec`。
- `VolcanicIslands`：把有效热点数量提升到有界下限，并把有效活动至少提升为 `Active`。

组合结果仍受 `MAX_HOTSPOT_COUNT` 和现有物理范围验证。该偏置只影响热点、热流和火山影响字段，不改变板块。

## 8. 应用与显示

应用持久化 `WorldFormationSpec`，默认 `Continents`。左侧控制面板新增预设下拉框：

- 随机
- 多大陆
- 群岛
- 超大陆
- 大岛
- 火山群岛

选择一个具名预设时，应用把大陆地壳比例更新为该预设的推荐值；用户之后仍可手工调整。预设、比例、板块数和构造活动继续在点击“按当前参数重建”后原子生效。

构建成功后，文档保存 `ResolvedWorldFormationArtifact`，摘要显示“形成预设：多大陆”等实际结果。若请求是随机，可显示“随机 → 群岛”。构建失败时，旧文档、已解析预设、显示包、选择字段和修订时钟全部保持不变。

预设不是字段，不进入 `FieldRegistry`，也不由 GPU 渲染器解释。

## 9. 错误与验证

新增精确错误：

- 不支持的形成规格 schema；
- 解析结果非法地包含 `Random`；
- 预设需要的大陆核数超过可用内部单元；
- 硬海洋框后剩余面积不足以满足明确大陆比例；
- 地幔偏置组合超过现有热点预算；
- 生成后边界单元不是海洋地壳或最终海拔不低于海平面。

公开序列化类型在反序列化时重新验证。生成失败通过既有 stage diagnostic/error 边界返回，不能发布部分世界。

## 10. 测试策略

### 10.1 类型与解析契约

- 默认是 `Continents`。
- 所有枚举稳定 JSON 往返。
- 非法 schema 与非法“已解析 Random”失败。
- 相同根种子和规格产生相同解析结果。
- 固定种子覆盖 Random 权重映射边界。

### 10.2 正交性契约

- 相同根种子下逐一切换五个具体预设，`plates`、`cell_plates` 和所有速度逐字节相同。
- 改变板块数和活动，地壳种类与厚度不变。
- 改变火山预设可以改变地幔字段，但仍不改变板块字段。
- 地壳分量继续能够跨越板块，板块继续允许包含两种地壳。

### 10.3 形态质量门

在至少 8 个固定种子的 20,000 单元 release fixture 上检查：

- Continents：3–6 个主要大陆地壳分量，最大分量不超过大陆总面积的 55%。
- Archipelago：至少 8 个大陆地壳分量，最大分量不超过大陆总面积的 30%。
- Supercontinent：恰好 1 个主要大陆分量，至少占大陆总面积的 85%。
- GreatIsland：1 个主分量占大陆总面积的 60%–90%，并有至少 1 个卫星分量。
- VolcanicIslands：至少 6 个分量；海洋地壳上的火山影响或露出陆地高于中性群岛基线。
- 每个预设的实际大陆面积在目标面积一个最大单元误差内。
- 所有空间边界单元为海洋地壳，正式 land/ocean 为海洋，当前地表低于海平面。
- 东西两侧的可见边框带不含陆地；南北两侧至少最外层不含陆地。

“主要分量”按占全图面积至少 1.5% 定义；岛群预设的分量总数另按最小单元面积阈值计算，避免把单个噪点计为岛。

### 10.4 显示与人工验收

- 更新 `crust.png`、`elevation.png`、`current-surface.png` 等受影响 goldens。
- 以原始分辨率检查多大陆、群岛、超大陆、大岛和火山群岛截图。
- 启动 release 桌面程序，检查默认多大陆、随机实际预设标签、换种子重建和字段选择保持。
- 不接受椭圆笔刷、蜂窝噪点、边缘裁断大陆或显示层遮罩。

### 10.5 性能

保持当前 20,000 单元 release 自然主链预算。大陆核选择最多进行 O(cells × nuclei) 的量化距离更新；不得为每个候选重复执行全图 Dijkstra。新增稠密临时数组在阶段结束后释放，不进入长期快照。

## 11. 兼容与版本

- 新 `WorldFormationSpec` 和 `ResolvedWorldFormation` 从 schema V1 开始。
- 新解析 stage 版本为 1。
- `TectonicStage`、`MantleStage` 和 `ReliefStage` 的输入/语义改变，必须提升各自 stage 版本以避免旧缓存命中。
- 地壳与 relief 正式字段结构不变，不因算法调整提升 snapshot schema；其生成 stage 版本负责缓存失效。
- 应用旧存档缺少形成规格时通过 `#[serde(default)]` 得到 `Continents`。

## 12. 验收条件

实现完成必须同时满足：

1. 默认程序截图明显呈现多块大陆漂浮于海洋，而不是一个中央大陆。
2. 东西边缘没有陆地，四周不存在被裁断的大陆。
3. 五个具名预设产生可区分且符合表中语义的宏观形态。
4. Random 对同一种子稳定，并显示实际预设。
5. 预设切换的板块字段不变；相关契约测试在 release 下通过。
6. Relief 和当前地表的边界海洋由正式生成数据保证，不依赖显示遮罩。
7. 全量 debug/release 测试、clippy、fmt、WASM/Trunk（环境可用时）、性能和人工桌面验收通过。
8. 不引入历史时间线、旧 terrain 主链调用或跨层依赖。
