### 1.2 成因（代码事实）

代码在 `src/generators/natural/hydrology.rs`（诊断里写的
`formation/surface_formation/hydrology.rs` 只是 P5 的类型边界包装）：

1. **每个填洼深度 ≥ 1 m 的洼地都发布成满到溢出点的湖。**
   `identify_and_route_lakes`（642–766）以 `filled − original ≥ minimum_depth`
   （654–659）选湖格，湖面一律等于 Priority-Flood 的填洼高程（744–745）；
   `build_surface_water`（818–835）、`build_lake_depth`（837–854）按此发布。
2. **开/闭判定不计湖面蒸发。** `close_unfillable_lakes`（890–949）只比较溢出体积与
   `FORMATION_ENDORHEIC_RESIDENCE_YEARS`（1000 年，`src/world/natural/surface_formation.rs:151`）
   内的流域径流，能填满就算外流；湖面只有进项没有出项。
3. **湖格自己还在产流。** `local_runoff`（856–888）对湖格同陆地一样给 `r·P`
   （`r = formation_runoff_fraction(κ)`），湖面降水全额入湖、湖面蒸发均缺席。
4. **分类先于判定。** 水面分类（235）在封闭判定（249–259）之前完成，闭合与否改不了
   湖的范围——即便判为闭合，湖仍然满到溢出点。
5. P5 设计 §7（文件 205–221 行）明确写着这是“explicit P5 formation proxy, not a
   claim to model lake evaporation. P6 replaces the proxy with the final water balance”。

所以问题不是阈值，而是**湖的范围不由水量决定**。诊断已证伪“调高 1 m 门槛”（湖深中位
34 m，调阈值几乎无效）。

**成因。**

2. **被动陆缘项。** `synthesize_passive_margin`（`formation/primary_relief.rs:387-450`）在陆侧

   偏移中位数 −87 至 −125 m，离洋壳 6–7 格（约 500 km）。推断：该场向内陆抬升，把原本向另一侧
   缓排的低地闭合成洼地（逐湖几何未验证）。
3. **P3 区域细节**（`conditioned_regional_detail`）是 19–30 % 湖的唯一来源。
4. **P5 几乎不制造也不消除洼地**，只通过出口处的沉积筑坝（剔除沉积后 25–32 % 的湖深减半）和局部

5. **湖在构造上无定位。** 湖不集中在裂谷、前陆盆地或造山带（在造山带反而偏少），空间上近于随机
   （最近邻比 0.81–1.01），是随机散布在稳定大陆内部的单格减薄点。P5 没有冰川过程，也就没有冰川湖
   的机制。

**后果（R1 决定）。**

- 当前“虚假湖”的数量主要由两件事决定：上游 P2 的数值厚度凹坑（正在上游修复），加上被动陆缘项。
  两者都不是湖泊规则的问题；本规格**不**以湖规则去消除它们，也不以过滤单格湖凑数。
- B1 的稳态水量平衡仍然是物理上必需的湖规则：无论洼地从哪里来，“湖面范围由水量决定、湖面要蒸发”
  这一点今天是缺的（§1.2），修好 P2 后它依旧缺。本规格的设计内容因此不变。
- 但 B1 的效果只有在洼地成因修正后才可测：在含数值凹坑的地形上做干跑，测到的是“B1 对数值噪声的
  反应”。所以 **§9.0 Stage 0 干跑必须在上游 P2 凹坑修复落地之后运行**，并以修复后的地形重测本节
  的“P3 继承 / 来源”表作为干跑的基线。
- 被动陆缘项造成闭合洼地这一点，若在 P2 修复后仍占显著份额，归诊断 B4（海岸陡坎与陆架）一路的
  被动陆缘物理处理，另立修订，不在本规格内。

## 2. 物理：闭合与半闭合湖的稳态水量平衡

### 2.1 方程

对一个水体 `D`（一个洼地或若干洼地合并后的复合洼地），水位为 `h` 时：

```text
dV_D/dt = F_D(h)
F_D(h) = Q_up(D)
       + Σ_{i∈C(D)} R_i A_i                                  （流域陆面径流）
       − Σ_{i∈M(D)} (E_i − P_i + R_i) · w_i(h) · A_i         （湖面替换陆面后的净变化）
```

- `A_i`：格面积；`C(D)`：经原始地表最陡下降汇入 `D` 的全部格（含 `D` 自身成员）；
  `M(D)`：`D` 的成员格；`Q_up(D)`：上游满溢水体流入 `D` 的出流。
- `P_i`：P5 已有的有界成形降水年总量（`formation_monthly_precipitation_mm`，m/yr）。
- `R_i = r(κ_i) · P_i`：P5 已有的陆面径流（`formation_runoff_fraction`）；其补集
  `P_i − R_i` 正是 A3 §3 中 P4 按 Manabe (1969) 稳态桶模式蒸散回大气的 `E_land`。
- `E_i`：开阔水面年蒸发（§3）。
- `w_i(h) ∈ [0, 1]`：水位 `h` 下格 `i` 的湿面积分数，取自瞬变共演 §4.1 的统一 P1
  亚格元三角扇几何（海平面、海陆面积分数已在用的同一算子）。

展开验证：湖内格的陆面部分 `(1 − w)` 仍产 `R`，水面部分收全额降水 `P`、失去蒸发 `E`，
`R(1−w) + (P − E)w = R − (E − P + R)w`。式中没有任何新系数。

### 2.2 稳态的三种结局

对每个水体，以其水位下界 `h_low`（叶洼地为最低格心 `z_pit`；复合洼地为子洼地的合并
鞍点）与溢出高程 `h_spill` 为区间：

1. **满溢（外流湖）**：`F_D(h_spill) ≥ 0`。湖满到溢出点，出流
   `Q_out = F_D(h_spill) ≥ 0` 经溢出点进入下游（兄弟洼地、父洼地或海洋）。
2. **部分充水（内流湖）**：`F_D(h_low) ≥ 0 > F_D(h_spill)`。水位取区间内**最低**的稳定根
   `h*`（`F` 由正变负的第一个零点，即从空湖开始注水时最先达到的平衡），出流为零，
   流域全部入流由湖面蒸发带走。
3. **干盆地（playa）**：`h*` 使所有成员格心水深都小于 `FORMATION_MINIMUM_LAKE_DEPTH_M`，
   即水面只占亚格元面积（或流域零径流）。该终端沿用现有 `BasinOutletKind::ClosedSink`
   词汇：一个不发布湖格的闭合终端，其入流在稳态下即终端蒸发。

`F_D(h_low) ≥ 0` 对叶洼地恒成立（`w(z_pit) = 0`，`F = Q_up + ΣRA ≥ 0`）；对复合洼地，
它等于两个子洼地在合并鞍点的出流之和（两者皆 ≥ 0 才会合并），因此区间总是有根可夹。

### 2.3 解析检验：水文指数

均匀气候、无上游来水时，闭合湖的湖面—流域面积比由 2.1 直接得出：

```text
A_L / A_B = R / (E_L − P + R) = R / (E_L − E_land)
```

这正是 Mifflin & Wheat (1979) 的水文指数关系（其形式为 `A_L/(A_B − A_L) = R/(E_L − P)`，
两式代数等价），也是 Matsubara & Howard (2009) 空间显式湖泊范围模型与 Street-Perrott &
Harrison (1985) 古湖泊水位—气候反演所用的平衡式。它给出两个可验证的结论：
`E_L ≤ E_land` 的湿冷区湖必满溢；`E_L` 越大于 `E_land` 湖越小。单元测试用它校验求解器
（§9.1）。

### 2.4 为什么取稳态而不是时间积分

线性化 `dV/dt = F(h)`、`dV/dh = A_L`，湖水位对气候的响应时间
`τ = A_L / (−dF/dh)`。Mason et al. (1994) 汇编的地球湖泊响应时间为年到数百年量级，
远短于 P5 的 `SURFACE_FORMATION_HORIZON_YEARS`（10⁵ 年），而 P5 在每个慢窗内持有固定的
P4 气候态。按 AGENTS“产品边界”，产品只发布终态：在冻结的气候态下，终态湖水位就是
稳态根，不需要湖水位轨迹。`FORMATION_ENDORHEIC_RESIDENCE_YEARS` 这个无出处的“填满时限”
随之删除（“修复的第一候选是删代码”）。

## 3. 开阔水面蒸发 `E_i`：P4 能支持哪一种公式

### 3.1 P4 实际发布了什么（`GlobalCirculationFields`，均已投影到 P5 权威面）

| 场 | 访问器 | 语义 |
| --- | --- | --- |
| 近地面风（月） | `near_surface_wind_m_s` | 两层重建的地面风，P4 体块蒸发用的同一风（`atmospheric_surface_wind`） |
| 低层气温（月） | `monthly_air_temperature_c` | 陆格上 P4 的“地表温度”权重全在此层（`tendency.rs` 1958–1998：`weights = [1 − water, water]`） |
| 近地面比湿（月） | `monthly_specific_humidity` | A5 起即近地面湿度 |
| 混合层温度（月） | `monthly_sea_surface_temperature_c` | 纯陆格上权重为 0，不是物理水温，**不可用** |
| 吸收短波、外逸长波（月） | `monthly_absorbed_shortwave_w_m2`、`monthly_outgoing_longwave_w_m2` | **大气顶**柱能量（灰体 + 线性化 OLR），没有地表净辐射 |
| 蒸发（月） | `monthly_evaporation_mm_day` | 海面体块蒸发 + 陆面 `E_land = (1−r)P`；湖格在 P4 中是陆地，**不是湖面蒸发** |

### 3.2 选择：体块（Dalton/质量传输）公式，单位水活度，水面温度取 P4 的地表温度

```text
e_{i,m} = ρ_a · C_E · |U_{i,m}| · max(q_sat(T_{i,m}; a_w = 1) − q_{i,m}, 0) / ρ_w
E_i     = Σ_m e_{i,m} · Δt_m                 （Δt_m：气候月时长，与 P5 降水同一换算）
```

- 正是 P4 海面蒸发 `bulk_surface_evaporation_kg_m2_s`
  （`src/world/natural/global_circulation.rs:1003`）的同一定律与常量：
  `P4_REFERENCE_AIR_DENSITY_KG_M3`、`BULK_MOISTURE_TRANSFER_COEFFICIENT`（Large & Pond
  1982）、Bolton (1980) 饱和比湿。唯一差别是淡水：海水的 COARE 水活度 0.98 换成 1，
  该函数的文档已写明“freshwater saturation retain unit activity”。实施时把水活度改为
  该函数的参数（海面传 `SEAWATER_SATURATION_VAPOR_PRESSURE_FRACTION`，湖面传 1），
  不复制第二份公式（SSOT）。
- 质量传输法是湖泊蒸发的标准方法之一（Dalton 1802；Harbeck 1962；Brutsaert 1982；
  Finch & Calver 2008 的 WMO 方法综述）。
- 水面温度 `T_s` 取 `monthly_air_temperature_c`：这是 P4 对该格解析出的地表温度
  （陆格权重全在低层大气），也就是 P4 自己若在该格计算体块蒸发会用的值。月尺度湖面
  水温与气温高度相关（Livingstone & Lotter 1998）。
- 年值由十二个气候月累加，与 P5 降水的月→年换算同源。

### 3.3 被否决的公式（及其归属）

- **Penman (1948) 组合式 / Priestley & Taylor (1972)**：需要地表净辐射 `R_n`。P4 只有
  大气顶柱能量平衡，没有地表短波、向下长波和云（C3 云与地表能量交换按 P5 §14 属 P6）。
  在 P5 里拼一个地表辐射等于提前做 P6 的另一半，且会引入未经 P4 闭合的第二套能量账。
  P6 落地地表能量后，`E_i` 应升级为 Penman 类组合式（§12.6 已定为 P6 项）。Zhao et al.
  (2022) 对 142 万个 HydroLAKES 湖泊的全球蒸发估算即用组合式并计入冰期。
- **直接读 `monthly_evaporation_mm_day`**：陆格上那是 `E_land`，正是本设计要替换的东西。
- **用混合层温度做 `T_s`**：纯陆格上无物理意义（见 3.1）。

### 3.4 已知偏差（写入风险，§10）

`T_s = T_a` 忽略了湖面辐射增温：湿热区（辐射主导）低估、干热区大湖（湖面常比气温低）
可能高估；P4 风为月末态、无阵风项（P4 的既定选择）；未计盐度（Salhotra et al. 1985：
咸水降低蒸发）与冰盖（Zhao et al. 2022 按冰期扣除）。这些都按“参数偏差、机制不变”处理，
先测（§9.2 报告 `E_i` 分布）再定是否需要提前的修正。

## 4. 算法：填—溢—并（Fill–Spill–Merge）加蒸发汇项

### 4.1 洼地层级

用 Barnes, Callaghan & Wickert (2020) 的洼地层级：以海洋格与全部局地极小格为种子做一次
Priority-Flood（Barnes, Lehman & Mulla 2014，P5 已在用），两股洪水首次相遇处即鞍点，
按鞍点高程由低到高合并成二叉树。每个节点记录：最低格、溢出鞍点（格对）、溢出高程、
成员格、子节点；树根挂在海洋（外流方向）。复杂度 O(N log N)，与现有 `priority_flood`
同阶。现有 `closed_local_minimum_terminals` 已能识别平底极小区，复用其平台处理。

### 4.2 自下而上求解（后序遍历）

沿用 Barnes, Callaghan & Wickert (2021) Fill–Spill–Merge 的“满了就溢、两邻都满就并”
的拓扑规则，把 FSM 中“分配一份给定水量”的体积约束换成 §2 的**通量**稳态约束——后者
正是 Matsubara & Howard (2009) 在 DEM 上求湖泊范围并把溢流转入下游盆地的做法。

1. 叶节点：用 `F_D` 判 §2.2 三种结局。满溢则 `Q_out` 记入其溢出目标（兄弟节点的
   `Q_up`；兄弟是海洋时进入大洋）。
2. 兄弟节点在收到溢流后再判。两者在合并鞍点都满溢时，父节点激活：成员为两子之并，
   `h_low` 为合并鞍点，`F_parent(h_low)` 即两子出流之和；按同样三种结局求解。
3. 一侧满溢、另一侧部分充水时，满溢侧是以鞍点为出口的外流湖，其出流终止在部分充水侧
   的内流湖。
4. 根节点挂海洋时，满溢出流即外流水量。

### 4.3 终端集与二次路由

求解完成后的终端集 = 海洋格 ∪ 每个未满溢水体的最低格。以这一终端集再跑一次现有的
`priority_flood` + `select_receivers`：满溢洼地内无种子，被自然填到溢出点并跨溢出点外流；
未满溢洼地内的格从各自湖终端被洪水先到达，排向湖。这样单受水者 DAG、无环证明与
`(filled_height_cm, CellId)` 平局规则都不变。

### 4.4 湖泊发布规则

- **湖格**：属于某水体、且格心水深 `h − z_i ≥ FORMATION_MINIMUM_LAKE_DEPTH_M` 并与该水体
  终端连通的格；与海洋“以格心是否被淹没定义 `LandOceanField`”（瞬变共演 §4.1）同一规则。
  满溢湖 `h = h_spill`，结果与现状一致；内流湖 `h = h*`，湖缩到平衡范围。
- 湖内路由沿用 `identify_and_route_lakes` 的 BFS（外流湖从出口、内流湖从终端），但
  “湖面高程”由 `filled_height_cm` 改为该水体的 `h`。
- **干盆地**：§2.2 第 3 种，终端为 `DryLand`、`BasinOutletKind::ClosedSink`。
- `lake_depth_m = h − z_i`（湖格），`drainage_surface_elevation_m` 在湖格取 `h`、其余取
  二次路由的填洼面，因此现有“湖格排水面 = 湖面”的校验（`world/natural/hydrology.rs`
  1205–1290）保持成立。
- 现有“分类先于判定”的顺序问题（§1.2 第 4 点）随之消失：分类发生在水量求解之后。

### 4.5 径流与流量恒等式

- 陆面局地径流：`R_i · (1 − w_i(h))`（属于某水体的格）或 `R_i`（其余陆格）；湖面部分的
  降水与蒸发记入湖的水量平衡，不进局地径流。局地径流因此仍 ≥ 0，现有字段范围校验不变。
- 汇流：沿 DAG 累加不变，唯一例外是外流湖的路由根（出口）——它向下游传递的是 §2 的
  `Q_out`，不是湖内累加的总入流。内流湖终端仍累加全部入流（其值即终端蒸发）。
- 月分配：`Q_out` 是年稳态量。默认把每月出流取为“该月入流 × 年出流/年入流”，年量精确
  守恒、月形状跟随入流。湖泊对季节流量的调蓄属于湖泊储量演算（如 WaterGAP 的湖泊
  出流方程，Döll, Kaspar & Lehner 2003），§12.2 已定：不做，属 P6。
- `HydrologySnapshot` 的流量累加校验相应加入湖出口这一项（§7）。

### 4.6 数值求解

- `w_i(h)` 只调用生产侧的三角扇积分（`integrate_positive_linear_triangle` 与
  `SurfaceWaterReconstruction` 的顶点重建），不写第二份几何。需要把“给定水位求单格湿
  面积”开放为 `pub(in crate::generators::natural)`，消费者即本求解器。
- 根的求法：当所有成员格 `E_i − P_i + R_i ≥ 0`（`E_L ≥ E_land`，预期的绝大多数情形），
  `F` 单调，二分夹逼至 f64 区间不可再分（与海平面求解 `solve_level_interval` 同一停止
  语义，不新增容差常量）；否则按成员顶点高程升序扫描找第一个变号区间再二分，保证
  “最低稳定根”的语义。
- 终端蒸发记为 `Σ E_i w_i(h*) A_i`，与入流之差即求解残差，进入 §6 账本并设硬门。
- 确定性：所有遍历按 `CellId` / 层级节点序，结果与线程数无关。

### 5.2 与 P5 时间推进的关系

P5 在每个慢窗（`advance_surface_window`，`surface_formation/generation.rs` 856 起，869 调
水文）和终点诊断（`recompute_surface_diagnostics`，用终点 P4）都调用同一水文核。新规则在
两处都生效：窗内用起点气候（与降水同一来源），发布用终点气候。这保证发布的湖与侵蚀、
沉积、坡面过程“看到”的湖是同一机制，而不是只在出图时换一套规则。

对过程算子的影响（均为现有逻辑，不改代码）：

- 河流功率只在 `DryLand` 格下切（`stream_power.rs` 127）：缩小的湖把原湖格还给陆地，
  闭合盆地的侵蚀基准面变成湖面 `h*` 而不是溢出点。
- 坡面只在两侧都是 `DryLand` 的边上起作用（`hillslope.rs` 376–377）：干出的盆底开始
  接受坡面充填，这是 playa 充填的物理过程。
- 沉积：无受水者的终端照旧全部沉积为内流储存（`sediment.rs` “endorheic storage”）；
  P5 §7“湖与闭合盆地的容纳空间来自溢出体积”不变。

### 5.3 与 P4 的耦合：单向，残差实测入账

P4 把湖格当陆地，按 `E_land = (1 − r)P` 回馈水汽（`forcing.rs` 481–492、617）。新规则下
湖面实际蒸发 `E_L`，闭合盆地的入流也经湖面回到大气。本设计**不**把湖面回馈给 P4：

- 理由：(1) P4 现状本来就不认识湖，这不是新引入的不一致，而 P5 侧从“湖面零蒸发”变为
  有蒸发，是严格改进；(2) 地球湖面蒸发约 1500 km³/yr（Zhao et al. 2022），量级为全球
  蒸发的千分之几；(3) 双向耦合要求终点 P4 先知道湖，而湖又取决于终点 P4，需新增一次
  终点不动点或 Picard 迭代，增加延迟与身份复杂度。
- 代价必须实测入账（AGENTS“近似导致不守恒须实测”）：报告
  `ε_lake = |Σ_i (E_i − E_land,i) w_i A_i + Σ_playa 终端蒸发| / Σ_global E_P4`，
  与 P4 自身水循环闭合门 `GLOBAL_CIRCULATION_WATER_CYCLE_RELATIVE_IMBALANCE_MAX` 对比。
  §12.1 已定：单向，`ε_lake` 实测报告；不做 A3 式“一次 Picard”双向。

## 6. 守恒与账本

每次成形水文求解产出一份陆面水账（私有报告 + 发布摘要，§7）：

```text
Σ_陆格 R_i A_i (1 − w_i)          陆面产流
+ Σ_水体 Σ P_i w_i A_i             湖面降水
= Σ_水体 Σ E_i w_i A_i             湖面蒸发（含内流终端与 playa 亚格元水面）
+ Σ_入海出口 Q                      入海水量
+ 求解残差
```

- 硬门：每个水体 `|入流 + 湖面降水 − 湖面蒸发 − 出流| / max(入流, 湖面降水)` 与全局账的
  相对残差均 ≤ `WATER_VOLUME_RELATIVE_TOLERANCE`（沿用既有水量闭合常量，不新造容差）；
  外流湖 `Q_out ≥ 0`；内流湖 `h* < h_spill`；满溢湖 `F(h_spill) ≥ 0`。
- 湖水体积**不**计入 `water_inventory_m3`（与现状一致）。瞬变共演 §7 的全水圈库存
  （`V_total = V_ocean + V_lake + …`）尚未实现，本设计不推进；湖水体积在报告中单列，
  以便以后接入（§12.5 已定：维持不计）。新规则只会让湖水体积变小。

- 记录数据版本、处理方法与校验和（AGENTS 出处纪律）。

辅助的湖数），写入修订条目。按
AGENTS“过程守物理，结果归玩家”，这些是**诊断包络**而非硬门：不达标时找成因

改动碰到 schema 与身份（共享基础设施），按测试范围纪律跑 Release 全量；fmt、clippy、
wasm lib check。时延用 `stage_timing_probe` 同机成对测 Draft seed 42 与 Standard 用户种子

## 10. 风险与时延

| 风险 | 说明 | 处置 |
| --- | --- | --- |
| 湿润区洼地不受影响 | `E_L ≤ E_land` 时湖必满溢；若 300 个洼地多在湿润区，湖数降不下来 | Stage 0 在 P2 凹坑修复后先测；剩余洼地按 §1.3 归因 |
| 在数值凹坑上评估 B1 | P2 凹坑未修时，干跑和语料测到的是 B1 对数值噪声的反应（§1.3：80–87 % 的湖继承自 P3，湖底集中在单格厚度凹坑） | Stage 0 与 §9.2 语料都在上游修复之后测；修复前的数字只作对照 |
| `T_s = T_a` 偏差 | 湿热区低估、干热大湖可能高估（3.4） | 报告 `E_i` 分布；Penman 升级随 P6 |
| 月末风、无阵风、无盐度、无冰 | 均为参数级偏差 | 记录为已知偏差（§12.3 不计冰），不加无出处修正 |
| 拓扑翻转增多 | 湖水位随地形每窗移动，可能增加 P5 窗误差拒步 | 9.2 报告拒步与慢窗数；seed sweep 硬门 |
| 单向耦合残差 | P4 不知湖面蒸发 | `ε_lake` 实测入账并报告（5.3，§12.1 已定单向） |
| 下游 T1 | 湖缩小后河道终止于内流湖、河—湖边界改变 | 现有 T1 河流规则已处理 `DryLand/Lake` 边；层级金样重钉 |
| 单格湖仍存在 | P5 §13.3 “no isolated one-cell lake” 现已被违反（153 个） | 报告单格湖数；不以过滤凑数 |

**时延估计**（待 9.4 实测）：新增一次带极小格种子的 Priority-Flood 与一次终端集二次
路由（均 O(N log N)，与现有 flood 同阶），加上每个水体的根求解（成员格 × 扇三角 × 二分
步数，标准档预计远小于一次 flood），`E_i` 每个气候快照算一次。预计成形水文耗时约翻倍，
它在全链中的份额需实测；若显著，可把洼地层级在窗内地形未变拓扑时复用（求解策略，
须另测）。

## 12. 裁定（R1，原开放问题）

用户 2026-10-08 授权“按你的建议来，必须走物理路线”。各条按此落定：

1. **P4 耦合**：单向。湖面蒸发不回馈 P4；`ε_lake` 每次实测并在发布摘要与修订里报告，与
   `GLOBAL_CIRCULATION_WATER_CYCLE_RELATIVE_IMBALANCE_MAX` 对照（§5.3）。理由见 §5.3：P4 本来就不
   识湖，P5 侧从零蒸发变为有蒸发是严格改进；双向需要终点不动点迭代。
2. **外流湖月出流**：按入流的月形状分配、年量守恒（§4.5 默认）。湖泊储量演算需要储量状态，属 P6。
3. **湖冰**：不计。P4 没有陆面冰与湖冰判据场，加一个冰期判据需要无出处的阈值。
4. **亚格元终端水面**：干盆地的亚格元湿面积只进摘要与账本；在放大视图里按水位画出这些小湖，留给
   T1 v2.2 阶段 2 细域水岸落地之后。
5. **湖水计入全水圈库存**：维持现状，不计入 `water_inventory_m3`；湖水体积在报告中单列（§6）。
6. **Penman 升级**：作为 P6 的一项（P6 有地表净辐射后，把 `E_i` 换成组合式，§3.3）。
7. **地球参考的主诊断量**：亚格元湿面积 / 陆地，对照同网格栅格化的 HydroLAKES；格心湖格数作辅助
   诊断（§9.3）。理由：格心计数受 80 km 网格分辨率支配，湿面积才是与 HydroLAKES 面积同口径的量。
