## 2. 机制

### 2.1 携带对象：起点的受限大气 FAS 校正 δ_s

起点求解在 `generation.rs:639-644` 已经构造出这个向量：

  δ_s = J_atm · P(y_s − R·x_s0)

它在细工作网格上，每格是 f64 `[V, Px, Py, Pz]`，只覆盖 `LowerAtmosphere`、`UpperAtmosphere` 两个角色（V = A·H_actual，P = ρ·V·u）。今天它在 `:651` 用完即丢，A8 改为在起点试探被接受（`:675-677` 的 `Ok(trial)` 分支）时把它留下。

它为什么能对接终点的冷第 0 轮：
- 粗映射每个慢步都用背景场覆盖四层温度、两层比湿和深层温度（`advance_mechanical_cycle`，`:751-803`）。
- 背景场取自第 0 轮的 `WorkClimatology`（`:412-441`）。
- 所以 δ_s 是在第 0 轮冷热力背景下平衡出来的机械校正，热力状态恰好是终点自己的冷第 0 轮会复现的那一个。
- δ_s 只通过两处依赖起点：起点地形下的粗算子与地形底，以及起点第 0 轮的背景。这两处与终点的差别都只来自 P5 的地形变化。

把它写成代数：
- 今天的终点注入：x_e1 = x_e0 + δ_e
- A8 的终点注入：x_e1′ = x_e0 + δ_s
- 初猜差：δ_s − δ_e = J_atm·P[(y_s − y_e) − R(x_s0 − x_e0)]

注意 x_s0、x_e0 不是静止初态：FAS 在第 0 轮 12 个耦合月之后调用（`:268`），`:572-573` 打包的是第 0 轮推进一个模型年后的状态。因此 A8 注入后粗层为 R·x_e1′ ≈ y_s + R(x_e0 − x_s0)：起点与终点第 0 轮轨迹的粗尺度差（风、η、对海岸与海平面变化的响应）原样保留，而今天的 FAS 会把粗层重新锚定到终点自己的 y_e。为此 §9.2 同时实测两种注入：
- **U（差分形式）**：x_e1′ = x_e0 + δ_s；
- **U′（地形底校正的绝对形式）**：携带粗网格 y_s，把下层 V 按终点地形底改写 y_s′ = y_s − R[A·(floor_e − floor_s)]，再注入 x_e0 + J_atm·P(y_s′ − R·x_e0)。它与今天 FAS 同样把粗层锚定到一个 FAS 解，体积严格中性，额外成本只是一次限制/延拓（约 0.04 s）。
两者按 §9.2 的同一门择优；都过门时取误差更小者。（R1：两者都过门，误差持平，按 §9.2.1 的平局规则取 U；U′ 的代码已删除。）

按数值延拓的读法，这是对误差估计 e ≈ x* − x 的零阶（平凡）预测子。校正子不变：至少 3 个真实细网格耦合轮，加冻结的全部门。这对应 Bryan (1984) 的"加速初猜 + 同步复核"（A5 §7.50）。

### 2.2 终点注入

注入点与今天的 FAS 调用点相同：`generation.rs:268-283`，条件是 C2、`cycle == 0`、`cycle + 1 < max`。终点收到载体 `c` 时按以下步骤执行。

**a) 校验载体身份。** 除下列各项外，还须 `carrier.start_forcing_fingerprint == inputs.initial_climate` 检查点的强迫指纹，保证载体正是 P5 消费的那次起点求解；配错载体是类型化错误。检查：
- 网格指纹等于 `grid.fingerprint()`；
- 气候档位（profile）一致；
- 格数一致；
- 角色恰为两层大气；
- 载体记录的 `global_circulation_model_fingerprint(profile)` 等于当前值。

任一不符就是编程错误，返回类型化错误，不重试。

**b) 应用校正：** `apply_atmosphere_amount_correction(&grid, &state, &terrain_floor_m, &c.amounts, cancellation)`（R1 按实现补上取消参数）。其中 `terrain_floor_m` 是终点自己的地形底（`:161-164`）。这个函数就是今天 FAS 尾段（`:645-672`）原样抽出，运算顺序如下：
1. 按 `floor` 打包 x；
2. `fine_volume` = 前两角色的 ΣV；
3. 执行 `add_scaled(+1, correction)`；
4. clone 状态；
5. 只解包两层大气；
6. 做 `GLOBAL_CIRCULATION_BUDGET_RELATIVE_ERROR_MAX`（1e-6）体积检查。

**c) 按结果分派：**
- `Ok(trial)`：令 `state = trial`，结果记为 `Reused`。
- `Cancelled`：传播。
- 其它任何 `Err`：调用今天的 `initialize_atmosphere_mechanics`，与今天的终点 FAS 逐位一致，结果记为 `InjectionRejected`（该求解此后即今天的冷终点）。

**d)** `previous_cycle = clone`，然后 `continue`，与 `:279-282` 相同。

之后的循环一行不改：
- 湿度预处理（`:284-301`）；
- 停止规则（`:305`）；
- 守卫（`:309`）；
- 未收敛门（`:317`）；
- 投影与定稿（`:324-382`）。

### 2.3 求解级回退

新入口 `generate_endpoint(surface, domain, forcing, start: &GlobalCirculationSnapshot, start_correction: Option<&StartAtmosphereFasCorrection>, cancellation) -> (GlobalCirculationSnapshot, MechanicalGuessOutcome)` 的行为（R1 按实现更正：档位取自 `start.profile()`，`start` 同时供 §2.2a 核对起点强迫指纹）：

1. 载体为 `None`（起点 FAS 试探被拒）时，直接走今天的冷终点。
2. 否则先跑复用路径。它返回的错误按**拒绝名单**处理：除第 3 条所列以外的**任何**错误（包括 `Report`、`Checkpoint`、`ClimateField`、`Validation`、`Projection` 等发布域与报告类变体），都以 `OwnFas` 冷重解一次，产物与今天的终点逐位一致。重解前先查 `cancellation.is_cancelled()`，已取消就返回 `Cancelled`，不启动第二次求解。
3. **只有以下与初猜无关的输入类错误**照常传播，不重试，因为冷路径同样会失败：
   - `Cancelled`、`InvalidSurfaceIdentity`、`InputFingerprint`、`GridReconstructionMismatch`；
   - `InvalidLayout`、`InvalidForcing`、`AllocationOverflow`；
   - `WorkDomain`、`Grid`、`Forcing`，以及载体身份错误。

这层回退是安全网，不是常态。§9.3 要求扫描中两类回退次数都为零。

边界情形：注入被拒后，该求解已经就是今天的冷终点；它若再以与初猜相关的错误失败，第 2 条的冷重解会逐位重复它并返回同一错误，只多付一次求解。

## 4. 地形协调

**地形底。** P5 改变高程、陆地比例和海平面，从而改变下层大气地形底（`tendency.rs:1131-1142`）。δ_s 是实际厚度体积 V = A·H_actual 中的增量，不是 η。它加在按**终点**地形底打包的 x_e0 上，再按 η = V/A − ref + floor_e 解包（`:1015`）。结果是：
- 终点冷第 0 轮对新地形的响应完整保留；
- 借来的只是粗尺度机械误差估计。

**净体积。** τ 与粗周期都守恒体积，所以 Σ_atm(y_s − R·x_s0) ≈ 0（A5 §7.56 实测相对变化 4.86e-8 / 3.29e-8）。注入后，现有 1e-6 检查对终点自己的 `fine_volume` 重新验证。

**为什么必须用差分形式。** 冷大气体积是 Σ A(ref − floor)，随地形变化。绝对形式 x_e0 + P(y_s − R·x_e0) 会带来两个后果：
- 注入净体积 Σ A(floor_e − floor_s)，地形一变就过不了体积门；
- 覆盖掉终点自己的粗尺度地形响应。

**正性与可表示性。** 求和后的状态逐格经过三项检查：
- `validated_fluid_layer_thickness_m`（深度 > 0，`tendency.rs:1064-1080`）；
- V 为有限正数；
- f32 可表示界（`:1004-1048`）。

任一不过，整个候选被拒（§2.2c），终点回到自己的 FAS。不夹值、不缩放 δ、不部分应用。量级参照：下层大气参考厚 6000 m、最小 1000 m；P5 只改变数米。

**海陆掩码。** 只写大气角色，海洋 H/u 与冷路径逐位一致，`enforce_full_land_ocean_velocity` 不受影响。摩擦、反照率、水汽的海陆差异通过真实的终点强迫，在其后至少 3 个耦合轮中起作用。

**动量。** u = (P_e0 + δP)/(ρ·V_new)，然后切向化（`:1021-1034`）。与今天是同一个算子。

## 5. 守卫与门

**全部不放宽：**
- `FORMATION_RESIDUAL_TARGET` 0.24（`:40`）；
- 至少 4 轮（`cycle >= 3`，`:305`）；
- 硬闭合门（水 5 %、TOA）；
- `FormationResidualIncreased`（`:309`）；
- `FormationNotConverged`（`:317`）；
- 档位最大轮数（Draft / Standard 10，High 12）；
- 1e-6 FAS 体积门；
- 检查点与快照校验。

**守卫参照仍是冷第 0 轮残差**（seed 42：Draft 0.385，Standard 0.425）。这消除了 A1 噪声级失败的根源，即参照变成了很小的热残差。守卫要触发，终残差须超过约 0.38，而此时 `FormationNotConverged` 必然也触发。

**湿度预处理仍按原门控**（`continuation_needs_moisture_preconditioning`，`:1122-1139`：残差 ≤ 0.24 且闭合未过）。第 0 轮走 `continue`，残差约 0.39，所以预处理不可能在注入那一轮触发。seed 42 两档轨迹中它从未触发。

**注入之后至少还有 3 个真实细网格耦合轮。** 注入位置、`continue` 语义和轮次计数都与今天相同。

## 7. 被否决的变体

**整态慢变量延续（ESC，评审设计 1）。** 做法是携带四层 η/u 与温度增量，湿度冷启动，跳过 FAS 与预处理，最少轮数降为 2。否决理由：
- 这就是 A1 整态热启动去掉湿度；海洋与温度的携带正是 A1 §6.4 的路径依赖通道。
- 它放宽了冻结的 4 轮下限，改变了守卫参照。
- 它的逐轮单调放弃规则与冷轨迹形状冲突：注入后残差本来就从 0.385 升到 0.466。
- 冷湿度与暖温度相遇会产生过饱和冲击，量级未测。
- 每次回退 Draft 要多付 1.2–4.7 s。

**起点演化差分 x_start_final − x_start_after_cycle0（杠杆 4 原案）。** 否决理由：这个差分携带了 4–5 个耦合轮的演化，与演化后的温度平衡，等于大气版热启动。δ_s 则与冷第 0 轮背景平衡，见 §2.1。

**未校正地形底的绝对形式 x_e0 + P(y_s − R·x_e0)。** 否决：注入净体积 Σ A(floor_e − floor_s)。地形底校正后的版本 U′ 体积中性，保留为 §9.2 的并列候选（§2.1）；R1 实测与 U 持平，按平局规则落选并删除（§9.2.1）。

**载体放粗网格 e_s（4 层 y_s − R·x_s，Draft 28 KB），在终点重做延拓。** 否决作为主方案的理由：
- 终点要重建粗网格与延拓算子；
- 内存收益无关紧要（≤ 885 KB）。

它保留为降级方案的载体，见 §9.6。

**复用记入模型指纹。** 否决理由：

- 记入输入指纹时，回退产物与今天完全同一。

**在线漂移门（如按 ‖R(x_e0 − x_s0)‖/‖δ_s‖ 设阈值）。** 否决理由：没有实测依据的新可调常量。δ 漂移改由离线实测（§9.2）判定。

1. **主方案：设计 0（本规格），不选设计 2。**

## 9. 验证（最小充分证据）

### 9.1 单元（crate 私有，小夹具）

1. **同强迫逐位**（只证明重构与注入算术精确；同强迫下 x_e0 ≡ x_s0，测不到 §2.1 的轨迹差，那由 §9.2 承担）。 先 `generate_capturing_start_correction(F)`，再 `generate_endpoint(F, Some(c))`，与 `generate(F)` 比较：发布场与 `state_fingerprint` 必须逐位相等，只有 `input_fingerprint` 按设计不同。理由是同强迫下 δ_e ≡ δ_s，所以这个测试同时证明重构与注入路径都是精确的。
