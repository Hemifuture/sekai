# P4 水循环量级与热带雨带设计（里程碑 A5）

日期：2026-09-03
状态：**Task 0 已实测，设计随测量修订中**

上位：`AGENTS.md`；A4 `2026-09-03-p4-water-heat-correction-design.md` §6.5、§6.6。
实施计划：`../plans/2026-09-03-p4-water-cycle-and-tropics.md`。

A4 收尾时给用户排的三件事是：一、蒸发用错了风（判为最高优先，因为它可能连带
解开压缩比上限）；二、赤道辐合带；三、辐射先验的纬度结构。用户批准全做。
Task 0 的实测**推翻了第一件的前提**，本设计据实测重排。

## 1. Task 0 实测（2026-09-03）

探针加了蒸发闭合的分解打印（`[evap]` 行），语料写入器加了每个种子的陆地占比。

### 1.1 风偏弱，不是偏强

| 量 | 模型 | 地球 |
| --- | ---: | ---: |
| 海面平均风速（探针，因果成形管线） | 5.11 m/s | 6.6 m/s（10 m 洋面风） |
| 海面平均风速（语料，17 seed 均值） | 5.76 m/s | 同上 |
| 海气比湿差（探针） | 5.5 g/kg | — |
| 海面蒸发（探针） | 3.42 mm/day | ≈ 3.4 mm/day |

原判断是"蒸发用的是 6 km 板平均风，比近地面风强，所以偏湿"。实测相反：发布的
`near_surface_wind_m_s` 就是低层板速度本身，其海面均值 **低于** 地球的 10 m 洋面
风。偏大的是饱和差。两个偏差方向相反、量级相近，乘起来给出接近地球的海面蒸发
——**又一个补偿误差**，与 A4 反复遇到的同类。

因此"改用近地面风"这条单点修改是错的：它会把偏弱的风再调弱，让蒸发塌掉。

### 1.2 湿偏差不是海陆比造成的

| 量（17 seed） | 值 |
| --- | ---: |
| 陆地占比均值 | 0.286（地球 0.29） |
| 陆地占比范围 | 0.273 – 0.305 |
| `corr(陆地占比, 降水)` | +0.16 |
| 全球降水均值 | 3.009 mm/day（GPCP 2.81，+7 %） |

海陆比与地球一致且与降水几乎不相关，所以 +7 % 是真实偏差，不是"不同星球的海陆
比不同"。但它仍在 ±7 % 包络内，潜热 93 W/m² 也在 Stephens et al. (2012) 的
78–98 内（高出 Wild 的 70–85）。

### 1.3 语料与探针是两条不同的管线

同一个 seed 42：

| 管线 | 陆地占比 | 全球降水 |
| --- | ---: | ---: |
| 探针（`causal_formation_fixture`，完整因果成形） | 0.256 | 2.852 |
| 语料写入器（初级地形 + 气候，无因果成形） | 0.305 | 3.112 |

地形不同，气候自然不同。**A4 的记述里把两组数当同一件事比较过**，例如"seed 42
降水 2.85 而语料 3.01"被读作种子间离散，实际上其中还混着管线差异。今后引用
必须写明管线。

## 2. 结论与重排

1. **第一件（蒸发的风）取消**，前提被实测推翻。真正的成因是"单层湿度既要当
   近地面比湿供体块蒸发用、又要当柱平均湿度供凝结用"，这两个角色互相矛盾。
   修它就是给湿度加垂直结构，而那正是第二件的前置。于是**第一件并入第二件**。
2. **第二件（赤道辐合带）** 的两个前置在 A4 §6.5 已经钉死：缺经向翻转环流；
   湿度无垂直结构。后者同时是 §1.1 那对补偿误差的根源。
3. **第三件（辐射先验的纬度结构）** 不变，代价是 17 seed 语料重标定。

湿偏差 +7 % 落在包络内，且它的两个成因彼此抵消，单独动任何一个都会变差。
因此本里程碑**不单独修湿偏差**，它会随湿度垂直结构一起解决或一起暴露。

## 3. Task 1 —— 水汽柱质量与凝结阈值（2026-09-03）

### 3.1 症结：比湿是近地面值，却按干空气柱质量换算成水量

模型低层大气的比湿是一个**近地面值**：体块蒸发把它当作与海面交换的空气，凝结
阈值拿它与同一温度下的饱和值比，发布的气温也是拿去和地球 2 m 场对照的。但把
它换算成水量时用的是这一层的**干空气柱质量** `ρ × 6000 m = 7350 kg/m²`。水汽
不像干空气那样分布：在均匀相对湿度假设下（Manabe & Wetherald 1967）比湿随
`q_sat(T(z))` 衰减，标准直减率把它集中在最低约两公里。

实测（探针，Draft seed 42）：

| 量 | 修前 | 地球 |
| --- | ---: | ---: |
| 可降水量 | 65.6 kg/m² | 25 |
| 水汽滞留时间 | 23.0 天 | 8–9 |

两者**同为 2.6 倍**，正是干空气柱质量与水汽柱质量之比。

### 3.2 修法：水汽柱质量

`ClimateLayerLayout::moisture_column_mass_per_area` 对模型**自己的**饱和曲线沿
标准大气廓线积分：

```text
M_q = ρ ∫ q_sat(T_ref − Γ z) / q_sat(T_ref) dz
```

`Γ` 是已声明的 U.S. Standard Atmosphere 1976 直减率，`T_ref` 是同一标准的海平面
温度。**不引入任何新系数**。低层得 2520 kg/m²，上层（6–10 km）只有很少。参考
廓线是固定的而非逐格的：输运搬的是强度量比湿，逐格变化的换算会破坏水量守恒。

每一处比湿到水量的换算都改用它：`apply_moisture`、上层凝结、层间水汽交换、
可用量限幅，以及守恒门的 `moisture_total` 与 `moisture_change_total`。热量与动量
仍用干空气质量。

### 3.3 单改一半会塌：阈值 0.9 是靠偏大的水量撑着的

只改质量，降水从 2.85 塌到 1.02、相对湿度升到 83%、蒸发跟着塌到 1.05。原因是
凝结率正比于柱质量，质量小 2.8 倍则同样的过饱和只下三分之一的雨，湿度堆积、
饱和差缩小、蒸发被扼住。**又一对补偿误差：偏大的水量在补偿偏严的凝结阈值。**

阈值 0.9 出自 SPEEDY（Molteni 2003），但那是 SPEEDY 的**层状云**闭合，它另有
一套对流方案产生热带大部分降水。P4 没有对流方案，这一条闭合要同时承担两条
路径，因此不能沿用 0.9。

### 3.4 锚：水汽滞留时间

改锚在一个 P4 可被检验的观测量上：Trenberth et al. (2007) 给出地球全球水汽
滞留时间约九天。柱质量修正之后扫阈值（强制 5 轮以排除早停干扰）：

| 阈值 | 可降水量 | 滞留时间 | 全球降水 |
| ---: | ---: | ---: | ---: |
| 0.90 | 28.0 | 19.1 d | 1.46 |
| 0.75 | 26.4 | 12.3 d | 2.15 |
| 0.70 | 25.8 | 10.1 d | 2.56 |
| 0.65 | 25.3 | 8.8 d | 2.88 |

可降水量由廓线独立定出，滞留时间是唯一的锚，降水因此是**检验而非拟合**。
这一轮扫描在湿焓修正（§3.6）之前，最终取值见 §3.8。

### 3.5 实测（发布态，Draft seed 42）

| 量 | 修前 | 修后 | 参考 |
| --- | ---: | ---: | --- |
| 可降水量 kg/m² | 65.6 | **25.6** | 25 |
| 滞留时间 | 23.0 d | **9.5 d** | 8–10 |
| 全球降水 mm/day | 2.852 | 2.685 | GPCP 2.81 |
| 全球蒸发 mm/day | 2.927 | 2.797 | ≈ 2.8 |
| TOA W/m² | −1.64 | −1.92 | 门 ±10 |
| Draft 时延 | 18.4 s | 19.0 s | 目标 10–20 s |
| Standard 时延 | 56.1 s | 57.5 s | 目标 ≤ 60 s |

降水结构也变好：北纬 32.5 度出现**副热带干带**（1.24 mm/day，修前 2.15），中纬
次极大与极区干燥都成形。热带雨带仍在 ±20 度而非赤道，那是 Task 2 的目标。

### 3.6 第三处耦合：湿焓守恒也要跟着改

凝结函数内部做的是**湿焓守恒**的饱和调整：凝结 Δq 放出的热按 `L Δq / c_p` 加热
同一份空气。质量拆开之后这个假设不再成立——水量是 `M_q Δq`，而它加热的是干空气
柱 `c_p M_dry`，所以升温只有原来的 `M_q / M_dry ≈ 0.34` 倍。模型**实际施加**的
潜热一直是对的（`apply_phase_change_latent_heat` 用的是已经按 `M_q` 算好的速率
除以干空气热容），错的是求解器内部那条焓曲线。

`large_scale_condensation_kg_m2_s` 因此多收一个干空气柱质量参数，内部按
`M_q / M_dry` 缩放焓曲线与其导数；传相同质量即回到单柱形式。修正之后阈值 0.70
给出的滞留时间从 10.1 天变为 **9.5 天**、降水 2.563 → **2.685**，两项都更好。

### 3.7 第四处耦合：配对水汽的相对门同样病态

上层的水汽柱质量只有干空气质量的约 4 %，层间水汽交换量随之缩小，而失衡的分子
是同一 f32 数组的量化地板（该数组还承载大 70 倍的蒸发与降水项）。实测失衡
641 kg/s、配对量 5.75e8、比值 1.11e-6 刚破 1e-6 门，而外部水汽通量是 4.0e10。

这与 A4 §6.4 的热量情形同型，按同一原则处理：分母改为"配对量 + 外部水汽通量"，
即该倾向数组承载的全部水量。比值降到 1.6e-8。报表与单元测试同步。

### 3.8 工作点：阈值取 0.70 而非 0.65

0.65 与 0.70 的滞留时间都落在观测区间（8–10 天）。取 0.70 的理由是产品级时延：
0.65 在 Standard 上多花一轮（6 轮对 5 轮），实测 62 秒破 60 秒线；0.70 两档都过
（Draft 19.0 s、Standard 57.5 s）。**在观测区间内用工程约束做取舍**，并在此写明。

顺带一提，轮数对阈值不单调（0.65 给 Draft 4 轮 / Standard 6 轮，0.70 给 6 / 5），
因为它取决于残差何时跨过 0.24，与 §3.9 是同一个判据问题。

### 3.9 顺带发现：残差判据看不见水循环

扫阈值时多次出现只跑 2 轮就满足残差目标而停的情况，此时环流尚未起转（海面风
3.45 对收敛后的 5.36）。`relative_state_residual` 由温度主导，对水汽与风不敏感。
A4 §4.4 的海冰复测撞的是同一个问题。发布态（阈值 0.65）跑满 4 轮不受影响，但
这条判据本身需要在后续里程碑修。
