# Sekai 球面自然过程迁移设计（S0B）

日期：2026-08-04

状态：已批准 S0 路线的实现细化；依据《可演进分层气候架构设计》、球面地表基础计划及用户对科学性、执行效率、模块正交与唯一事实源的确认

范围：把当前板块、地幔、地形、地质、初步气候强迫、水文与侵蚀从平面坐标依赖迁移到闭合球面的权威拓扑和度量；不包含球体渲染、气候网格重映射或分层气候核心

## 1. 决策摘要

S0B 采用“一个权威地表、一个最小只读度量契约、两种经过验证的几何适配器、共享自然过程语义”的路线：

- `SphericalSurfaceSnapshot` 继续是新行星唯一的地表几何和拓扑事实源；自然过程不得复制单元、边、顶点或邻接表成为第二事实源。
- 现有 `SpatialSnapshot` 只服务旧平面世界和局部测试，不会被拼接、包裹或重新解释成球面。
- 在 `world::spatial` 定义面向自然过程的最小只读表面契约。平面与球面各有一个真实实现，因此此处使用 trait 有明确的双实现依据。
- 共享图算法只读取单元面积、邻接、边长、中心距离、边所有者和稳定端点身份；需要方向的物理过程读取边局部切向框架，不读取地图投影坐标。
- 平面 V1 的随机流、输出与金图保持不变；球面使用相同语义但不伪装成平面数值的逐位延伸。
- 球面板块采用 Euler 极刚性旋转，而不是在经纬图上使用恒定二维速度。
- 新自然快照携带权威地表身份；相同单元数但拓扑或几何不同的地表不能错误复用自然字段。
- 流水线只在完整球面自然快照通过验证后原子发布。适配器、索引、投影和工作缓存均可删除重建。

## 2. 为什么不能只做类型替换

当前实现包含四类平面假设：

1. `PlateVelocity` 是一个全局二维平移。闭合球面不存在覆盖全行星且无奇点的统一二维切向基。
2. 板块边界按量化二维端点和二维方向聚合。球面已经有权威 `SurfaceVertexId`，继续量化投影端点会制造接缝。
3. 大陆和热点布置使用矩形短边、对角线与外边界距离。闭合球面没有外边界。
4. 初步气候在有边界矩形栅格上输送水汽；水文又允许通过外边界排水。闭合行星必须使用全球连通输送、海洋出口或内流盆地。

因此，简单实现一个返回平面字段形状的 trait 会让程序通过类型检查，却在极区、接缝和全球守恒上产生错误。本设计只共享真正与几何无关的算法，把必须依赖流形几何的物理明确放在局部度量接口之后。

## 3. 权威表面与只读契约

### 3.1 `NaturalSurface`

`NaturalSurface` 是借用权威快照的只读视图，不拥有或序列化几何。它只暴露自然过程实际需要的事实：

- 表面种类、schema、内容指纹和闭合性；
- 连续稳定的单元、边和端点身份；
- 单元面积、物理中心和特征尺度；
- 每条边的一或两个所有者、弧长／线段长、中心间大地距离；
- 单元到邻居的稳定有序弧；
- 边中点处从第一所有者指向第二所有者的单位切向法线；
- 边自身的局部切向方向；
- 单元间的大地最短距离与表面的最大有用距离。

契约不暴露 `WorldRect`、经纬投影、cubed-sphere 面编号、GPU 顶点或渲染三角形。

### 3.2 两个适配器

- `PlanarNaturalSurface<'a>` 借用 `SpatialSnapshot`，复现当前欧氏距离、边界和端点语义。
- `SphericalNaturalSurface<'a>` 借用 `SphericalSurfaceSnapshot`，使用存储的球面面积、弧长、中心距离、规范顶点 ID 与切向法线。

适配器只计算轻量查询，不复制完整拓扑。需要重复图遍历时，由生成器侧构造一次可丢弃的 `NaturalTopologyIndex`。

### 3.3 `NaturalTopologyIndex`

索引把权威契约规范化为确定性、缓存友好的图数据：

- 按 `CellId` 排列的邻接弧和量化遍历代价；
- 按 `EdgeId` 排列的所有者和稳定端点身份；
- 面积权重、边界标记、代表性单元间距和最大大地距离；
- 只供噪声、排序和远点采样使用的规范三维嵌入。

它不被序列化，不进入世界哈希，也不能被下游当作地表快照。平面构造必须通过现有无漂移测试；球面构造必须验证每边双所有者、无边界单元和总面积一致。

## 4. 地表身份与自然快照

定义稳定的 `SurfaceRef`：

```text
SurfaceRef
├── geometry_kind       PlanarV1 | SphericalV1
├── geometry_schema
├── cell_count
├── edge_count
└── content_fingerprint [u8; 32]
```

- 球面指纹直接引用 `SphericalSurfaceSnapshot::fingerprint()`。
- 平面指纹按当前快照规范字段确定性计算；不使用内存地址、哈希表顺序或显示数据。
- 新版自然快照必须存储 `SurfaceRef` 并在交叉验证时逐项匹配。
- 旧平面 V1 快照继续按原 schema 加载和验证，不静默补写或假造指纹。
- 从旧 V1 升级到带身份的新版本属于显式重新生成；应用升级本身不改变已保存世界。

`CellId`、`EdgeId` 只有在匹配同一 `SurfaceRef` 时才有跨快照含义。这可以阻止“单元数恰好相同但地表不同”的错误缓存命中。

## 5. 球面板块运动

### 5.1 运动表示

球面板块使用离散、版本化的 Euler 极旋转：

```text
SphericalPlateRotation
├── pole: UnitVector3
└── angular_rate: fixed-point radians / year
```

半径为 `R`、位置单位向量为 `r` 时，局部线速度为：

```text
v(r) = angular_rate × R × (pole × r)
```

该速度天然位于球面切平面；同一板块的所有点共享一个刚体角速度。速度候选使用确定性球面方向集合和有限速率档位，最大局部速度遵守现有约 `120 mm/year` 的产品上限。

平面 V1 继续使用 `PlateVelocity`。公共语义层发布速度大小和边局部相对运动；内部运动参数通过有版本的和类型区分，不能把缺失的球面旋转写成零二维速度。

### 5.2 边界分类

在每条权威边的中点：

1. 计算两块板的局部切向速度；
2. 求第二板相对第一板的速度；
3. 投影到边的跨界法线与沿边切线；
4. 按法向符号、法向／切向占比、地壳类型和厚度分类碰撞、俯冲、裂谷、洋中脊或走滑；
5. 用局部相对速度而不是全局二维分量计算强度。

球面边界段直接通过共享 `SurfaceVertexId` 连通，不经过地图接缝。全段不保存一个虚假的统一二维方向；需要显示或地形响应时，按成员边读取局部切向方向。

## 6. 大陆、地幔、地形与地质

### 6.1 大陆与板块分区

- 板块种子继续使用按大地距离的最远点采样和多源最短路。
- 球面大陆核在全球候选中按面积目标、图距离、低频球面噪声和形成预设组合；不使用“离矩形边界多远”。
- 多大陆、超级大陆、大岛和火山群岛仍是作者语义，但其几何实现只依赖闭合表面距离与连通性。
- 球面噪声以单位向量的低阶确定性基函数或图扩散产生，不采样二维纹理接缝。

### 6.2 地幔

- 热点候选按全球远点采样和地壳／形成偏置选择。
- 支持半径以大地距离解释；上限使用半周长 `πR`，不使用矩形对角线。
- 影响扩散继续复用量化图距离，但量化基准来自球面代表尺度。

### 6.3 地形与地质

- 构造抬升、裂谷、海沟、火山和区域起伏只消费边局部运动、图距离与大地距离。
- 球面没有“暴露的世界边界”地形修补。
- 地质字段保持单元对齐和唯一写入阶段；抗侵蚀性、渗透率、裂隙、矿产与地热只引用已验证的上游语义字段。

## 7. 初步气候强迫、水文与侵蚀

### 7.1 S0B 的初步气候边界

S0B 需要降水和温度来驱动水文，但不抢先实现 C0–C4。为此保留“初步气候强迫”这一明确能力：

- 球面纬度由权威单位向量与行星自转轴计算；不存在投影 `y` 到纬度的换算。
- 初步盛行风以三维切向向量表示，并按局部东西／南北基生成。
- 水汽在权威单元图上做有界、非负的迎风输送，使用共享边通量和地形抬升；不先投影到有接缝矩形栅格。
- 该阶段继续标记为 preliminary，只为 S0B 水文和当前产品兼容服务；它不是最终分层气候，也不与未来正式气候同时写同一字段。

S0D 完成后，正式气候从 cubed-sphere 经守恒重映射写入稳定语义字段，并显式替换 preliminary 能力版本。

### 7.2 闭合球面水文

- 海洋单元是主要排水出口，河流终止于海洋或封闭湖盆，不存在世界外部出口。
- priority-flood 以海洋／海岸作为开放水位种子；无海洋行星使用显式的内流盆地模式，而不是选择一个隐藏的地图边界。
- 流向必须指向同一权威拓扑中的相邻 `CellId`；坡度使用中心间大地距离。
- 汇水面积和湖泊面积使用真实球面单元面积；河流长度使用大地距离。
- 对封闭洼地，填洼、溢流口和湖量预算保持确定性，并明确记录终端盆地语义。

### 7.3 侵蚀

- 河流功率、坡度和沉积输送使用球面中心距离、真实面积与正式水文流量。
- 每次侵蚀更新后重新验证有限值、海陆语义、湖盆关系和高程范围。
- 当前两遍“水文 → 侵蚀 → 最终水文”仍作为原子阶段；未来时间演化侵蚀可替换内部推进器，但不改变输出所有权。

## 8. 流水线与模块边界

保持两条显式产品路径：

```text
旧平面世界：PlanarSpaceArtifact → SpatialArtifact → 平面自然阶段 V1
新球面世界：SphericalSpaceArtifact → SphericalSurfaceArtifact → 球面自然阶段 V2
```

两条路径共享：

- 自然字段语义与验证规则；
- 几何无关的图算法；
- 规则解析、形成预设、确定性随机子流；
- 地质和水文的局部物理公式；
- 字段注册与下游只读接口。

两条路径不共享：

- 平面平移与球面 Euler 旋转的运动参数；
- 平面外边界与闭合流形的出口规则；
- 二维矩形气候栅格与球面图输送；
- 渲染投影或选取缓存。

阶段适配器可以各自声明 `SpatialArtifact` 或 `SphericalSurfaceArtifact` 依赖，但必须调用同一被测科学核心或明确的几何策略。禁止复制整套 `spherical_tectonics.rs`、`spherical_hydrology.rs` 后独立演化。

## 9. 实施顺序

1. **S0B.1 契约与索引：** `SurfaceRef`、`NaturalSurface`、两个适配器、统一拓扑索引和适配器一致性测试。
2. **S0B.2 板块与地幔：** 版本化运动和快照身份、Euler 极运动、球面大陆／板块／热点生成。
3. **S0B.3 地形与地质：** 局部边界运动驱动的地形、球面噪声、地质字段迁移。
4. **S0B.4 初步气候强迫：** 单元图上的球面纬度、切向风、非负水汽输送。
5. **S0B.5 水文与侵蚀：** 海洋出口、内流盆地、球面距离／面积和原子两遍更新。
6. **S0B.6 产品接入：** 新球面自然图、缓存身份、字段文档、兼容加载和整体验收。

每一子阶段都必须保持 `main` 可构建、平面金图无漂移，并有独立的球面科学验收；不得先让 UI 消费半迁移字段。

## 10. 验收门槛

### 10.1 契约与确定性

- 平面适配器查询与当前 `SpatialSnapshot` 在严格容差内一致。
- 球面适配器的每条边恰有两个所有者，邻接成对，总面积为 `4πR²`。
- 同一输入、种子、模型版本和平台协议产生相同量化字段哈希。
- 更改投影、调色板、球体网格或 GPU 缓冲不改变任何自然字段哈希。
- 不同地表指纹即使单元数相同也不能通过交叉验证或命中缓存。

### 10.2 科学性质

- 球面板块任一点速度与径向点积在浮点容差内为零；同板块运动满足一个共同 Euler 角速度。
- 边两侧相对法向速度的符号与聚合边界分类一致。
- 球面旋转、经线接缝和极点附近不出现特殊分支或统计异常。
- 热点影响随大地距离单调衰减；支持半径不超过 `πR`。
- 球面气候风严格切向，水汽非负，共享边输送成对守恒。
- 水文接收者必为邻居；全球汇水面积、湖面积和河长使用真实球面度量。
- 闭合行星不存在 `ExternalBoundary` 出口；全陆地夹具明确形成内流盆地。

### 10.3 兼容与性能

- 当前全套平面测试、字段哈希和自然显示金图保持通过。
- 旧平面 V1 序列化往返保持可读，应用升级不触发静默重算。
- 典型约 20,000 单元的 S0B 全自然生成在 Release 桌面目标上不超过当前平面基线的 `2.5×`，峰值额外工作内存不超过 `256 MiB`。
- 构建循环内不得发生与单元数或边数成比例的重复堆分配；拓扑索引每次阶段构建最多一次，并在可能时由同一联合阶段复用。

## 11. 非目标

- 不在 S0B 增加三维球体或二维投影视图；这是 S0C。
- 不在 S0B 把权威地表插值到 cubed-sphere；这是 S0D。
- 不在 S0B 发布最终洋流、大气环流、ENSO 或台风能力；这是 C0–C4。
- 不把板块编年史或侵蚀时间轴保存为历史内容；后续时间演化仍输出当前状态和稳定统计。
- 不为“将来也许会有”而引入万能上下文、任意坐标系或任意层数抽象。

## 12. 完成定义

S0B 只有在以下条件全部满足后才完成：

1. 新球面世界从 `SphericalSurfaceSnapshot` 生成板块、地幔、地形、地质、初步气候强迫、水文和侵蚀；
2. 所有新自然快照与准确的 `SurfaceRef` 绑定；
3. 自然科学代码不读取投影坐标、cubed-sphere 面或渲染几何；
4. 球面板块使用 Euler 极运动，闭合水文没有外边界出口；
5. 旧平面 V1 路径、存档与显示结果保持兼容；
6. 科学、确定性、缓存、序列化、性能与全仓库回归门槛全部自动化通过；
7. S0C 可以只消费同一权威地表和这些自然字段来显示球体，无需重新生成或复制自然事实。
