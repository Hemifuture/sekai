## 2. 支持域与目标

- 档位：Draft、Standard（High 不在本轮，沿 a9 §1）。
- 层级：每档从 L0 格元到梯底叶片（`MIN_PRIMITIVE_EDGE_M`，Draft 约 L15、
  Standard 约 L14，审计 §1）。
- 物理尺度：全球气候只在粗工作域求解；L0 与更细层级的气温由“粗工作域气候场 +
  派生高程”经直减率降尺度获得。**降尺度只依赖粗场与高程，不读 P4 动力模型的
  内部量**（用户 2026-10-25 补充：P4 很可能换成降阶诊断模型）。所需的唯一契约是
  “粗场气温定义在声明的工作格参考高度上”（§3.2）。
- 字段消费者：L0 发布气温 → 显示、质量报告、点击；细层气温 → 只有显示与点击。
- 目标（可见）：任一层级上，气温随屏幕上的地形高程以 Γ 变化；邻格不再出现大
  高差零温差；点击读数与屏幕同源；Standard 不再因共同工作域呈 460 km 色块。
- 非目标：逆温、坡向日照、湿绝热或随湿度变化的直减率、海温降尺度、细层回写
  科学字段（§3.5）。

## 3. 设计：温度

### 3.1 公式

记参考高度函数（已有事实源，不新增）

```text
h(z, f_land) = max(z − sea_level, 0) · f_land          // atmospheric_reference_surface_height_m
```

对权威格元 c 取 `h_c = h(z_c, 1 − ocean_area_fraction_c)`（P5 终态高程与水面
几何，正是终点气候强迫所用的地形，`forcing.rs:419-445`）。对工作格 j 取参考高度
`H_j`（定义见 §3.2）。降尺度是 P4 自身海平面归约的逆运算：

```text
θ_j      = T_j + Γ·H_j                       // 工作格海平面归约气温（P4 已在用的坐标）
T_c[m]   = (W θ[m])_c − Γ·h_c                // 投影后按格元高度重新抬升
         = T_proj,c[m] − Γ·(h_c − (W H)_c)   // 等价写法：投影值 + 逐格常量订正
```

`W` 是既有的工作域→权威格元重叠平均算子（`climate_to_source`）。因 `W` 线性，
两种写法逐项等价；订正量与月份无关。实现只需多投影一个标量 `H`，再逐格做一次
乘加。

细层（§3.5）用同一函数：

```text
T_leaf = T_c − Γ·(h_leaf − h_c)
h_leaf = 干陆叶：max(z_leaf − sea, 0)；海洋叶：0；湖叶：湖面 − sea（取 max(·,0)）
```

逐级级联 `T(k+1) = T(k) − Γ(h(k+1) − h(k))`（t1v3 F1 的形式）沿路径伸缩求和后
恰为上式，所以 F1 不需要“状态帧”，O(1) 直接求值即可。

函数唯一实现放在 `generators/natural`（算法），常量与 `h` 仍归 `src/world/`；
P4 投影、细层派生、点击面板、测试全部调用它（SSOT）。

### 3.2 工作格参考高度 H_j（实测改变了推荐）

协调者推荐“z̄_work 用工作格面积加权平均高程，与 P4 强迫口径一致”。实测表明
**这两个要求在当前代码里互相矛盾**：P4 的 `z_ref,j = max(z̄_j − sea, 0)·f_land,j`
先对含海底的高程取平均再截断，海岸工作格的深海底会把陆上山地抵消掉；它不等于
格元参考高度的重叠平均 `(M h)_j`（`M` 为既有的权威格元→工作域重叠平均算子 `source_to_climate`；下称 `H̄_j`）。

[实测] `D_j = H̄_j − z_ref,j`：

| --- | --- | --- |
| 含陆工作格 D_j 中位 / p75 / p95 / p99 / 均值（m） | 1.8 / 63.9 / 360 / 625 / 66（919 格） | 0.4 / 38.0 / 252 / 453 / 45（868 格） |
| 混合工作格（0.05 < f_land < 0.95）中 z_ref = 0 而 H̄ > 50 m | 136 / 369 | 106 / 310 |

逐格订正量（K，p01/p50/p99）：A 干陆 Draft −8.1/−0.25/+2.1、Standard
−6.0/−0.20/+2.0，海洋几乎为 0；B 干陆 Draft −5.8/−0.15/+2.6、Standard
−4.0/−0.13/+2.4，海洋 p99 Draft +2.7、Standard +2.0。年均跨 0 °C 的干陆格：
A 60 / 4916（Draft）、197 / 18636（Standard）；B 45、152。OLS 绝对值略大于 Γ，
是工作格间被解析的大尺度梯度与高程相关所致（斜率中位恰为 −6.50），不是订正
过量。

分析：

- **A** 是 P4 自身坐标的精确逆运算，值上正确地把“P4 在 z_ref 上解出的气温”搬到
  格元高度；全球均温下降 0.17 K 不是降尺度造出的误差，而是 P4 参考高度在 136 个
  海岸工作格里低估了气柱下边界——那些工作格的 `T_j` 本就是按过低的边界解出的
  偏暖值，A 把这一偏差在格元上显露出来。
  Standard 同理（−0.11 K，106 个海岸工作格）。
- **B** 全球均温守恒（两档四位小数均相同），但它把 `T_j` 解释为 `H̄_j` 上的气温，
  与 P4 的解相差 `Γ·D_j`：在 P4 已偏暖的海岸工作格上再加一次 `+Γ·D_j`，重复计入。
  **B 不推荐。**
- **C**：把 `H_j := H̄_j = (M h)_j` 定为工作域契约的唯一参考高度，P4 强迫
  （平衡目标、高地反照率先验、梯度/浮力归约）改用它。此时 P4 在正确的下边界上
  求解，降尺度按构造守恒全球面积积分（B 的守恒性）且与 P4 坐标一致（A 的正确性）。
  若 P4 解对边界高度近似 1:1 响应，C 的格元气温 ≈ A [推测，须 §8 T2 实测]。

**推荐，待用户裁定：C。** 理由：唯一既守恒又与粗场坐标一致的方案；`H̄` 只依赖
地形与工作域，是“粗场 + 派生高程”契约的一部分，P4 若被降阶诊断模型替换，新模型
直接采用同一 `H̄`，降尺度零改动。代价：P4 强迫改变，须离线对照质量报告、收敛与
时延后再落地（T2）。**备选 A**：P4 不动，先以 A 发布并把全球均温偏移作为参考高度
定义差异写进诊断；C 落地时只换 `H` 的来源。投影算子本身（现状）也只守恒全球
积分、不逐工作格可逆，B 行的“工作格重叠平均订正 ≠ 0”来自 `M·W` 往返的平滑，不是
降尺度的误差。

### 3.3 为什么这是有成因的降尺度而不是事后修形

- 位移来自过程：气温随高度按环境直减率变化是对流层静力结构；P4 已经用同一常量
  建立了“海平面归约—参考高度”坐标，本设计只是把同一坐标从工作格贯彻到格元与叶片。
- 方法是业界标准：先把气温按直减率归约到共同参考面、再插值、再按目标格高程
  抬升（Dodson & Marks 1997 的线性直减率变体；Liston & Elder 2006 MicroMet 在
  插值后按温度—高程关系订正；Lipscomb et al. 2013 的高程分级降尺度）。
- 没有拟合系数、没有目标指标：Γ 是 P4 已用常量；输出不向任何直方图或目标直减率
  回调。实测 OLS 接近 −6.6 K/km 是结果，不是约束——它仍含工作格间被解析的
  大尺度梯度（p05/p95 −12.1/−0.7 K/km）。
- 不触碰任何通量：降尺度只改近地面气温诊断，不改辐射、蒸发、降水与洋流（§7）。

### 3.5 细层只做显示派生（推荐，待用户裁定）

- L1 至叶片的气温由 §3.1 函数从 L0 发布值与派生高程即时求出，不写入任何产物，
  不被任何科学阶段消费；UI 图例与点击面板标注“派生（Lk，直减率）”。
- 锚点用 `h_c`（格元本身的参考高度），使屏幕上任意叶片与 L0 的温差恰为
  `−Γ·Δh`。[实测，L6] 叶片面积聚合 − `T_c`：Draft 中位 +0.013 K，p05/p95
  −0.44 / +1.21 K，高起伏格（L6 极差 > 453 m，1616 格）p95 +2.28 K、p99 +3.87 K；
  Standard 中位 +0.006 K，p05/p95 −0.18 / +0.36 K，高起伏（2257 格）p95 +1.36 K、
  p99 +2.44 K。
  该残差**恒等于** `−Γ ×（叶片高程聚合 − h_c）`，即高程层级聚合误差（L1 削峰、
  河道雕刻）的换算；温度自身不引入聚合误差。高程聚合守恒归 LOD-1 / v2.2 R1。
- 备选：锚点用格元 L1 面的面积平均参考高度。实测 p05/p95 Draft −0.64 / +0.15 K、
  Standard −0.21 / +0.06 K，高起伏 p05 Draft −1.22 K、Standard −0.76 K——只是把残差移到负侧（L2+ 河道雕刻使叶均值低于 L1），并
  破坏“叶片与 L0 温差 = −Γ·Δh”的可读关系。**不推荐。**
- “画成冻结、按格元未冻结”的跨层差异：[实测] L6 叶片跨过订正后格元年均 0 °C 的
  干陆格 Draft 248 / 4916、Standard 345 / 18636。由于当前**没有任何**读气温的科学过程（§1.3），
  该差异目前在所有尺度都不产生科学矛盾，只需在 UI 声明“派生”。规则：将来新增的
  雪线、冰川、群系等科学消费者一律读 L0 发布值；若需要格元内分布，应在 L0 上按
  亚格元高程分布做高程分级（Lipscomb et al. 2013 的 elevation classes），而不是
  读显示叶片。

## 4. 显示通道：非高程字段走细分 mesh

### 4.1 两种方案

| 方面 | P：逐字段预烘焙叶色（现状扩展） | G：上传派生标量，GPU 按色板着色 |
| --- | --- | --- |

### 4.2 推荐（推荐，待用户裁定）：G

- 一次性渲染器改动：细分顶点第二槽改为 `Uint32` 载荷；`vs_*_amplified` 依
  uniform 中的通道种类解码——地形通道 `unpack4x8unorm`（保持现有地形色与水岸色，
  `terrain_water_color` 仍在 CPU、仍出自 `palette.rs`），标量通道
  `sample_palette((bitcast<f32>(payload) − min)/(max − min))`，与 `decode_fill_color`
  同式。`amplified_mode` 已在 uniform 中占位（`renderer.rs:199, 474, 1817-1819`）。
  建议载荷独立成第二个顶点缓冲，切字段时只重传载荷、不重传几何。
- 批缓存改存 `z_leaf + 类别`（每叶 5 B，替代现每顶点 4 B 颜色、约 1.5 顶点/叶
  [代码推算]），地形色在组装时由同一 `flat_color` 现算；`cached_and_cold_builds_are_bit_identical`
  等既有契约继续成立。
- 字段注册表（`world::fields::FieldSchema`）增加一个与渲染无关的语义属性
  “层级派生种类”：`CellConstant`（默认，整格继承，仍走 L0 mesh）与
  `LapseRate`（本规格）。`field_layers::layer_visibility` 的细分条件从“填色 ==
  高程”推广为“填色字段的派生种类 ≠ CellConstant 或为高程”。`amplified_mesh` 对
  派生种类只有一处 `match`，调用 §3.1 的唯一函数；每格输入（`T_c`、`h_c`）经
  payload 绑定提供。
- 对正交范式的影响：首次引入通道需改渲染器一次；此后新增“已有派生种类”的字段 =
  注册表条目 + payload 绑定，渲染器与求解器零改动；新增“新派生种类”（如 §11.1
  地形降水）= 一个枚举变体 + 其派生函数，渲染器仍零改动。P 方案则每个字段都要
  动着色代码，且量程逻辑被复制到 CPU，违背色板 SSOT。
- 量程：标量通道沿用 L0 字段的量程（由 L0 值计算）；叶片超出量程时饱和到端色，
  只影响显示，不 clamp 数据；图例注明。
- 若用户否决 G（例如要求先不动渲染器）：P 可行，代价是切字段等于一次完整重建
  （M2 记录深层视图重建 2–3.5 s [审计 §3]），且每个新字段都要改 `amplified_mesh`。

## 11. 后续分期

依赖：T1（函数与参考高度契约）与 T4（标量通道）是所有后续分期的公共底座。

### 11.1 第二步：地形降水（提前；另立规格）

- 证据：§1.4。降水块状主要来自粗格稀释；P5 径流、坡面与地形放大都消费降水，
  因此 L0 改动会改变 P5 与整个地貌产物（同一阶段升版）。
- 方法候选：Smith & Barstad 2004 线性地形降水理论（LT，含气流动力 `m·H_w` 项与
  凝结/降落时间尺度 τ_c、τ_f）；其前身 Smith 2003 线性上坡—时延模型（UTD，去掉
  气流动力项，可沿风向在不规则网格上单遍扫描，无需 FFT）。Barstad & Smith 2005
  给出模型评估。
- 只依赖粗场与高程：输入为粗工作域近地面风、气温与比湿（推出湿稳定度与水汽
  标高、`C_w`）以及派生高程；不读 P4 内部量。湿稳定度 `N_m` 需要垂直结构，
  而粗场只发布近地面量：取声明参考廓线（例如湿绝热）还是由粗场新增发布一个
  稳定度诊断，是第二步规格的首个开放问题。
- 避免重复计入：LT/UTD 只作用于“格元高程相对工作格参考高度 `H̄` 的亚工作格地形
  异常”，工作格尺度的地形抬升已在粗场降水中（`tendency.rs:3380-3403` 的地形降水
  分量）。
- 守恒：LT 对零均值地形异常的线性响应在截断（P ≥ 0）前零均值；截断产生净水量，
  是守恒约束还是 AGENTS 禁止的事后修形，交用户裁定（审计开放问题 4）。
- 细层：UTD/LT 的响应长度为 `U·τ` 量级；若 τ 与 U 取典型值，长度远小于格距，
  细层派生只需一环邻格的有界扇入 [推测，须按出处核定 τ 后实测]。
- 验收参考：同格逐位相等比例（Draft 20 %、Standard 46 %）显著下降；非同格雨影值
  （0.280 / 0.210）不劣化；总雨影值（0.223 / 0.113）、蒸发—降水全球不平衡
  （≤ 0.05，既有指标）与 P5 水账守恒继续通过。
- 预计任务：L0 订正与升版、P5 回归与金样、派生种类变体与上屏、点击行、证据记录
  （5–6 项）。

### 11.2 坡向日照与山体阴影

Dozier & Frew 1990 的纯几何 + 太阳几何地形辐射；叶片法向由细分几何与派生高程
直接得到，O(1)/叶，走 T4 标量通道（新派生种类）。是否回馈气温（坡向温差）为
开放问题；首版只做显示。

### 11.3 风

Sherman 1978 质量一致诊断风场需三维求解，成本高；风是向量，细层还需要向量叠加
通道（与标量通道不同），优先级最低，只记路线。地形降水只需工作域风，不依赖本项。

### 11.4 比湿

I8 实测订正使过饱和格月增至 1.6–2.2 倍（§3.4）。候选：保持投影后的相对湿度不变，
`q_c = RH_proj,c · q_sat(T_c)`，`q_sat` 用既有 `saturation_specific_humidity_kg_kg`；
或按 Liston & Elder 2006 的露点直减率路线。两者都只依赖粗场与高程，可并入第一步
（T3 同一升版），也可单列；交用户裁定（§12-6）。注意：现状的 2.6 % / 4.0 % 过饱和与订正
无关（分别投影 q 与 T 的非线性所致 [推测]）；RH 路线只保证订正不扩大它，现状
部分的成因须另查，不得以 clamp 掩盖。
