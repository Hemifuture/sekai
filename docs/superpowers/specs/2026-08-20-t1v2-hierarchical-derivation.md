§7（河流）与 §8 的种子纪律按下文注明的方式继承。M1 连续场实现

## 1. 模型与接口

**图元 = 数据原子**：一个图元有且只有一组值，值不可再分；更细的
信息只能来自图元分割（用户裁定，2026-08-20）。不存在"任意点连续
插值场"。

**数据元形态唯一**：地表数据元只有图元面值这一种形态
（L0 格元与 L1+ 三角形是同一形态的两种几何载体）。本规格
其余一切量——§2 的边锚量、§4 的河床——都是派生函数的
内部临时量：不存储、不可查询、不出现在任何接口上，地位
等同于几何分割中的"中点坐标"。

- 图元层级：L0 = Goldberg 格元（六边形 + 12 五边形）；L1 = 每格元
  扇形三角形（质心 + 相邻边界顶点对；六边形 6 个、五边形 5 个）；
  L2+ = 三角形递归四分（精确嵌套，rep-tile）。
- 层级 ID：`(cell: CellId, sector: u8, path: [2bit; k])`，k ≤ 16。
  几何与值均由 ID 纯函数重算，免存储。
- 核心接口：

```text
value(cell, sector, path) -> PrimitiveValue { elevation_m: f32, regime }
```

- `sample(direction, level)` 保留为薄壳：定位 direction 所在的
  level 层图元，返回该图元值（天然阶梯场）。
- **L0 恒等不变量**：`value(cell, —, [])`（格元本身）恒等于 T0
  发布值。L1 起为派生值，不承诺等于任何 T0 插值。

## 2. 值派生规则（分割规则自带值派生）

派生走**边锚量**（edge anchor，旧称"顶点值"，为防误读改名）：
边锚量是分割规则的内部派生量（如同几何中点一样属于"分割"的
定义），它是相邻图元子代在共享边上逐层靠拢的桥——两个图元
唯一共享的几何要素是边，所以桥必须挂在边上。数据元只有图元
面值。

### 2.1 顶点格与规范种子

- L0 顶点集 = 格元质心顶点 ∪ 格元边界顶点（canonical
  SurfaceVertexId）。
- 质心顶点值 = T0 格元高程；边界顶点值 = 其全部相邻格元
  （2–3 个）T0 高程的算术平均（唯一的一次跨格元组合，作为
  L0→L1 锚定规则显式声明）。
- 每个顶点有**规范种子**：
  - 质心顶点：`blake3(域 ∥ "c" ∥ cell)`；
  - 边界顶点：`blake3(域 ∥ "v" ∥ SurfaceVertexId)`；
  - 细分中点：`blake3(域 ∥ "m" ∥ sort(种子_A, 种子_B))`，A、B 为
    被平分边的两端顶点。
  域 = `"sekai-t1v2-derivation-v1\0" ∥ 世界根种子`。排序保证从边的
  任意一侧派生得到**逐字节相同**的种子——跨格元、跨扇区一致性由
  构造给出，不靠协调。
- 中点顶点值：

```text
value(M) = (value(A) + value(B)) / 2 + A(level, 条件) · N(种子_M)
```

  N(种子) ∈ [−1, 1]：取种子哈希的前 8 字节为 u64，映射
  `u64 / 2^63 − 1.0`。无 RNG 状态，纯哈希（种子纪律与既有带标签
  子流同构：域分隔 blake3；ChaCha 流在此不需要，因为每顶点恰好
  消费一次抽样）。

### 2.2 图元面值

- 三角形图元值 = 三个角顶点值的算术平均。
- regime = 按图元 elevation 对 T0 海平面的离散判定（洋底/陆架/
  海岸带/陆地内部，阈值沿用 M1 §4 的边界常数；v2 为离散标签，
  不做过渡带混合——图元原子模型下混合无意义，着色平滑属 M3）。
- **海岸线分形是涌现结果**：顶点位移使子图元高程在海平面两侧
  重新落位，海岸线随层级自然分形化，不再需要 M1 的显式域扭曲
  （M1 C9 的功能由此涌现替代，幅度侧保留见 §3）。

### 2.3 幅度律

```text
A(level, 条件) = A0(条件) · p^level，p = 2^(−H(条件))
```

- `A0` 锚定：L1 增量幅度与 M1 频谱预算在 λ₀ 波段的幅度同阶
  （切换时视觉连续性的校准起点，精确值在 Task 5 校准期定）。
- H ∈ [0.4, 0.85]，沿用 M1 C10 及其文献结论。

## 4. 河道走廊（继承 M1 §7 与修订 A4）

- 数据与几何完全沿用：P5 河段、水力几何宽深、拓扑 running-min
  单调河床、大圆弧最近点。
- v2 应用点改为图元级：`面值 = min(派生面值, carve(图元质心))`。
- M2 Task 4 引入层级重路由后，carve 改读"当层河道路径"，本规格

## 5. LOD 语义与预算

- 层 k 图元边长 ≈ 格距 / 2^k；路径深度硬上限 k = 16（草稿档格距
  159 km → 最深 ≈ 2.4 m，覆盖 M2 目标；u64 ID 编码预算内）。
- 何时算到多深由 T2 调度（视口预算），本规格只保证任意深度的
  值可即时重算。

## 6. 确定性

- 全部随机性来自 §2.1 的规范种子哈希；无 RNG 状态、无求值顺序
  依赖、无缓存语义（缓存只是加速，不改变值）。
- 冻结指纹：固定层级探针集（覆盖多个格元、全部扇区、深度
  0/2/5/9 的固定路径共 256 个 ID）的 elevation blake3。实现落地
  时按 A3 惯例冻结数值并由集成测试守门。

## 7. 不变量测试（实现前列举）

1. 确定性：同 ID 两次求值逐位相等；
2. 跨母边界一致：相邻格元/扇区各自派生共享边中点，值与种子
   逐字节相等；
3. 幅度界：|value(M) − midpoint(A,B)| ≤ A(level)；
4. L0 恒等：格元面值 == T0 发布值；
5. 河床压制只降不升、沿链单调（判据沿用 M1 模块测试）；
6. 陆比守恒：深层大样本图元的陆地占比与 L0 陆比漂移 ≤ 0.01
   （海岸涌现不改变全球陆海平衡的统计）；
7. 薄壳一致：sample(direction, level) == value(定位出的图元)。

## 8. 非目标

- 不做各向异性山脊排列（C3/C8 方向分量，v2.1 议题）；
- 不做群系/材质通道（M3）；
- 不做任何层级值缓存持久化；
- 不改 T0 产物与证据。

## 9. 科学审查记录（冻结前自审，2026-08-20）

按惯例从行星地质学与文献一致性逐条审查草案，结论与已知取舍：

1. **中点位移的地形学效度**：随机细分产生自仿射分形面，其功率谱
   与实测 DEM 的 β ≈ 2 谱一致（Sayles & Thomas 1978；Huang &
   Turcotte 1989），H 域 [0.4, 0.85] 与 M1 C10 相同的实测支撑。
   已知伪影：独立中点位移存在折痕（creasing）与轴向相关性
   （Miller, SIGGRAPH 1986 的批评）——三角形四分无方格轴向伪影，
   折痕保留为已知项，Task 5 校准期实景评估；若不可接受，v2.1
   候选缓解为菱形平均或每层低通（均有文献先例，不即兴发明）。
2. **海岸线分形维数的物理锚定**：分形布朗面的等高线维数
   D ≈ 2 − H（Mandelbrot 谱系结论）。实测海岸线 D ≈ 1.2–1.33
   （Mandelbrot 1967）→ 海岸带 H 应落 0.67–0.8。本规格 C9 的
   海岸带 H 调制以此为界：崎岖构造海岸取低 H（D→1.33），沉积
   平缓海岸取高 H（D→1.2）。这把 M1 的"海岸扭曲幅度"参数替换
   为有直接实测锚定的参数——比 v1 更强的物理根据。
3. **各向异性的损失（C3/C8 推迟）**：中点位移天然各向同性，
   构造走向的山脊排列（v1 用 Gabor 噪声）在 v2 首版缺席。地质
   上这意味着年轻褶皱带的线状山脊在深 zoom 退化为各向同性
   粗糙——真实且可感的保真度退化，如实声明。缓解路径（v2.1）：
   位移幅度按走向余弦调制（文献中方向位移谱的标准做法），不在
   首版做以控制复杂度。
4. **L0→L1 锚定的守恒性**：边界顶点取邻格元均值引入一次平滑，
   等效于把 T0 场的格元间跳变分配到 L1 尺度过渡——这正是 v1
   smoothstep 想达到而带平台副作用的目标；均值锚定无平台（无
   零导数区），跨界过渡宽度 = 一个 L1 图元。面值三角平均进一步
   保证相邻图元值差有界。
5. **regime 离散化**：v1 的过渡带混合是为连续着色服务；图元
   原子模型下 regime 是每图元离散标签，海岸"带"由多层图元的
   逐层重判定涌现，宽度自然为图元尺度——与制图学的地类划分
   语义一致，无需混合。
6. **河道继承**：§7/A4 的水力几何与单调性论证不受模型切换影响
   （雕刻作用在值上，与值如何派生正交），不重审。
7. **概念清点**：本规格无自创算法——中点位移（Fournier, Fussell
   & Carpenter, CACM 1982）、三角形四分层级（HTM，Szalay &
   Kunszt）、H→p 关系（v1 C10 文献）、等高线维数 D=2−H
   （Mandelbrot）、条件表驱动场全部沿用 v1 已审出处。v2 的原创
   仅在组合：把 C 表映射到每层增量参数，以及规范种子的排序
   构造——后者是确定性工程手段而非科学断言。

     路径 = 深度 d 的折线；d = 0 即 L0 链（"缩小回全球退回 L0
     链"由构造给出）。节点确定性：种子 =
     blake3(域 ∥ "r" ∥ i(u32 LE) ∥ 节点二进制路径)，域同 §2.1。
  2. **蜿蜒幅度律与波长锚**：子段长 ℓ_d = ℓ₀/2^d。侧移候选
     M = M_geo ± t̂·A_r(d) 或不侧移（三选一）；A_r(d) =
     `MEANDER_SINUOSITY_FRACTION`(0.25) · ℓ_d，且当

     `MEANDER_WAVELENGTH_PER_WIDTH`(12) × 水力几何河宽 w（A4 的

  3. **谷线引导 + 种子扰动**：三候选按
     score = 未雕刻派生面值（在候选点、引导层

  4. **走廊限定**：任意节点到 L0 弦大圆的侧距 ≤

### A7 —— 陆地 A0 改为频谱延拓定律（2026-08-21，M2 Task 5 校准）

**动机（实测）**：原 C1/C2 定律 `A0 = 320 m × relief_norm ×
(1 + 450/320 × orogeny) × 修正项` 有两处结构缺陷：
① relief_norm 在 900 m 处饱和——3 km 起伏的造山带与 1 km 起伏的
丘陵拿同一 A0，尺度信息被归一化抹掉；② 常量基准 + 多重压减
系数连乘后，典型陆地 A0 仅 ~76 m，按 H≈0.75 衰减到 1 km 尺度
只剩 ~3 m 起伏（真实地形：平原 5–30 m、山地 200–800 m，SRTM
局地起伏统计），即用户报告的"公里级过于平滑"。

**新定律（C1 v3，最佳实践：谱衔接）**：细分增量阶梯在 T0 点阵
截止处**延拓 T0 自身的谱**——这是把程序化细节接到数据上的标准
原则（Fournier–Fussell–Carpenter 1982 的方差匹配；现代地形放大
文献同理）：

```text
A0 = max(SPECTRAL_CONTINUATION × relief_m, LAND_A0_FLOOR_M)
     × erodibility_amplitude(C4) × sediment_damping(C7)
     × (1 + BADLANDS_A0_SHARE × badlands_gate(C6))
```

- `relief_m` = T0 邻域最大高差（米，不归一化；C 表新增米值通道，
  norm 通道逐位保留，仅供 Hurst/谷壁沿用）；
- `SPECTRAL_CONTINUATION = 0.7`：≈√3/2.5——环形 ~6 邻元的极差
  估计 σ ≈ range/2.5，均匀增量噪声 σ = A/√3，两者相除；
- `LAND_A0_FLOOR_M = 30`：平原保底微纹理（真实平原细尺度以
  切割为主，属 T1 v3 排水期，见该草案）；
- `BADLANDS_A0_SHARE = 0.2`：沿用旧 60/320 比例；
- **C2 造山项从幅度通道移除**（relief_m 已天然携带造山尺度，
  保留会双重计数）；造山仅保留 Hurst 通道（C10 基线）驱动。
  海岸带同陆地定律；陆架/洋底（C7/C8 绝对米值锚）不变。

**随附修正**：最近点下潜的子树剪枝松弛量自 0.25·ℓ 修正为
0.6·ℓ（`NEAREST_PRUNE_SLACK_FRACTION`）——位移几何级数的正确
上界为 0.25·ℓ·Σ0.56^k ≈ 0.57·ℓ（每次中点侧移 0.25·ℓ 后半弦长
≤ 0.56·ℓ），原值过紧存在过度剪枝风险。A6.5 测试的深层单调断言
同时修正为"本河段自身床 + 壁"（min 组合在汇流走廊重叠处沿支流
爬邻河谷壁属预期行为，不变量属于河段自身）。

由 `tests/surface_formation_stage.rs` 守门；同测试复核产品级 L0

### A8 —— 截止层以下的平滑续分与精确剪枝界（2026-08-21，用户反馈）

**动机（用户报告）**：深层放大后河道大量呈直线段。A6.2 的波长
截止（ℓ < λ/2 不再新增随机弯）物理语义正确（Leopold–Wolman），
但路径**渲染**为 λ/2 长的直弦——大河 λ 达公里级，贴近看即
"整屏直线"。真实河道在弯内是光滑曲线（Langbein & Leopold 1966
的正弦生成曲线：蜿蜒是方向变化最平缓的路径）。

**契约**：
1. 蜿蜒帽（A6.2 的 d_cap）以下，路径树继续按**四点插值细分**
   加深（Dyn–Levin–Gregory 1987，w = 1/16，端点箝位，球面
   重归一化）：新中点 = normalize((−P₋₁ + 9P₀ + 9P₁ − P₊₂)/16)。
   确定性纯函数、无新随机量；既有蜿蜒顶点逐位保留（插值性），
   极限曲线 C¹ 光滑——正弦生成曲线的工程化。
2. 平滑深度帽 = d_cap + `SMOOTH_DEPTH_EXTRA`(4)，再钳全局
   `PATH_DEPTH_LIMIT`(16)；顶点间距细至 ≈ λ/32。退化河段
   （d_cap = 0）不平滑。
3. 显示折线与 §4/A6.5 雕刻同源地读平滑后的路径（层 L 读深度
   min(L−1, 平滑帽)）；A6.4 走廊界对随机顶点依旧严格，平滑
   细分允许 ≤ 四点格式的有界超出（≪ 一个帽层振幅，回归测试
   以 0.1·ℓ₀/2^d_cap 弧度余量守门）。
4. **精确剪枝界取代松弛系数**：路径记忆化时自底向上物化每个
   内部节点的真实偏差上界 bound(节点) = d(中点, 节点弦) +
   max(子节点界)（短弧上到大圆弦的距离沿另一短弧拟凸，故子弦
   最坏偏差在其端点取得），并乘 (1+1e−9)、加 1e−6 m 浮点
   安全余量。最近点下潜以此界剪枝——正确性由构造保证，A7 的
   0.6·ℓ 松弛系数废止。

**负载分担（实现说明，非契约）**：细化批构建按核数条带并行
（批为上下文的纯函数，条带只分担负载不改结果；同河段的路径
物化由每段读写锁自然串行、跨河段并行）。实测标准档深放大
重建 0.4–4.8 s → 并行后见计划记录。
