## 2. 问题：现行要求的代价与收益

现行规则（AGENTS 2026-10-25）要求从 L0 格元到显示叶片的整条层级都是支持域，任一层
看到的海岸、水体、河网须物理自洽。Atlas 接入后，这条要求落成“全球规范细场 S4
（`ATLAS_FINE_SCALE`，步长约 4.9 km）上的自适应水体支持网格”。实测（均为单场景
seed 42、Draft）：

| 事实 | 数值 | 来源 |
|---|---|---|
| 规范水体支持网格 | 5,701,224 节点、11,402,444 面，26 轮自适应 | `measurements/2026-11-03-atlas-water-authority-layer.md` §2 |
| 该步耗时 | 182.5 s（另一次 204.1 s） | 同上 §7 |
| 冷发布总耗时 | 232.0 s（stage 230.4 s，LOD 0.58 s，GPU 0.29 s），峰值约 2.78 GiB | `measurements/2026-11-03-civ-atlas-integration.md`；`PROGRESS.md` |
| 时延目标 | Draft ≤ 1 s，Standard ≤ 3 s | AGENTS 时延目标 |
| 均匀层级 L3 作权威层 | 仍有约 29 万 km² 分类翻转、5 组海盆连通改变、3 个湖丢失；L2→L3 翻转只减约 34% | 水体权威层测量 §3–§6 |
| 上游自身 | 粗网格、S4 绘制、像素连通三种表示对同一批负洼地判定互相矛盾 | 同上 §6.4 |

三点结论：

1. **成本**：全球细层拓扑占冷发布的绝大部分，与秒级目标差两个数量级以上。
2. **不收敛**：窄海峡、窄坎、锚点落位决定的拓扑是“采到就有、采不到就没有”，
   加密均匀层级不能保证各层拓扑一致；L4 起只能自适应，又回到现行成本。
3. **没有消费者**：Voxim 青岚 16 km × 16 km，约为 3×3 个 S4 细格、约千分之一个 L0
   格元（格距约 123 km，载体测量 §范围）。Voxim 当前只消费 P4 格距尺度的站点气候
   （`2026-10-26-site-climatology-export-design.md`），其体素地形由 Voxim 服务端内核
   自行生成（Voxim `Docs/R6.md` S4）。全球细层真值在 Voxim 侧目前没有读取者。

因此问题不在 LOD 技术，而在“每层都是全球真值”这一要求：它高成本、无收敛保证，
且不服务 Voxim。

## 3. 设计：三种职责分开

### 3.1 全球真值只在一层定义

- **真值层 T**：Atlas 源格元图（Draft 约 3.4 万格）。海陆、海盆身份与连通、湖泊身份
  与水位、河网主干、气候强迫与 C2 气候全部只在 T 上决定一次。这与上游自身的建模层
  一致：上游 `world.ts` 的海洋分类、`connect_inland_seas`、湖池与侵蚀都在粗格元图上，
  A5b 已把这层海洋节点当作海洋来源锚点。
- **次网格量**：小于格元的海湾、小湖、海峡不以几何身份进入真值，只以每格元的面积
  比例与水量表示，即现有 `AtlasCellFields` 的 `ocean_fraction`、`lake_fraction`、
  `dry_fraction`、`ocean_volume_m3`、`lake_volume_m3`。C2 已按格元读取这些量，消费者
  接口不变。
- **比例的定义（唯一事实源）**：T 的水体身份落在格元站点上（站点属于某海盆、某湖或
  干地）。点 q 落在 T 的站点 Delaunay 三角形 (a, b, c) 内；q 属于水体 W，当且仅当
  三个角点中至少一个站点属于 W，且 `B(q) < level(W)`。`B` 为现行规范细床（含 A3 湖床
  初始化），不变。格元比例与水量是这一判据在格元上按声明求积规则的积分。拓扑由 T
  决定，细床只决定岸线在三角形内的位置与水深；因此岸线沿细床零等值线，不随格元边界
  呈阶梯。三角形同时邻接两个水体时的归属规则，以及海洋锚点有效性（沿用 A5b：站点处
  `B < 0`），在 §5 第 1 项对照中实测后写入本节。
- 这就是水体权威层测量 §2.2 的“继承读数”在 k = 0 时的形式。该测量在 L3 下的继承
  读数全球海面积偏差 −0.017%、海水量 −0.00007%；k = 0 的数值尚未测，见 §6。

### 3.2 LOD 只负责呈现

- 显示叶片是 T 与细床 `B` 的纯函数，用同一 §3.1 判据着色：细点水陆 = 所在格元的
  水体身份 + `B(q)` 与该水体水位的比较。叶片聚合回格元等于发布比例（同一判据、
  同一 `B`，差异仅为求积误差，须测量并声明）。
- 叶片只在视图需要时求值，符合 AGENTS 时延条款“首帧只烘焙当前视图所需叶片”。
- 比 T 细的形态（例如在 T 上判为连通、细床上看似断开的窄海峡；在 T 上判为陆、细床
  为负的封闭洼地）在 UI 中标为“未解析细节”，不宣称是物理有效的独立水体。这履行
  AGENTS 2026-10-30 修订“海峡连通与小岛等未解析细节不得被静默宣称为物理有效”。
- 点选读数与显示同源：都读 §3.1 判据与 T 上的格元量。

### 3.3 Voxim 区域按需嵌套精化（只定契约，现阶段不实现）

- 当 Voxim 出现读取 Sekai 地形的真实消费者时，对作者选定足迹（复用站点导出的锚点、
  尺度、旋转）做区域精化：区域内的精细地形与水系以 T 的格元量为边界条件，包括哪边
  是海、入境河段与流量、格元平均高程、海陆湖比例与气候月值。
- 守恒契约：区域结果按格元聚合须回到父格元的比例、水量与入出流，误差按声明容差。
  区域内不得自行改变 T 的海盆或湖泊连通；溢口与跨区连通服从 T。
- 确定性：区域结果是（世界身份，固定分块）的纯函数。多区域重叠时，各分块在重叠区
  须一致；现阶段只有青岚一个区域，重叠的分块与边缘重叠区设计推迟到出现第二个区域。
- 依据极简原则，本稿不实现 3.3：当前 Voxim 只消费站点气候，其锚点准则（陆地、离岸
  ≥ 2 个 P4 格距、足迹内无湖）都在 T 尺度上判定，§3.1 已满足。

## 修订 R1：真值取上游 Civ Atlas 粗格元分类，不做细尺度水体求解（用户指令，2026-11-03）

### R1.1 用户决定与原因

两轮离线对照（`measurements/2026-11-03-truth-layer-cell-quadrature.md` §1–§8）表明：只要
Sekai 自己在任何离散层上重新求海盆连通与湖泊溢口，就会出现层级相关的拓扑出入，并需要
不断追加机制（局部连通、次网格溢口）。这些对照一直以现行 232 s 规范支持为参照，而用户的
参照是 Civ Atlas 本身的海岸与湖泊。用户裁定：“我就想要一个 civ atlas 的海岸线 + 相对有逻辑、
拟真的气候系统”，“只要最后的气候可解释可演进就行”。

### R1.2 做法

1. **真值层 = 上游粗格元分类。** 每个 Atlas 源格元的站点类别（陆／海／湖）与湖面高程直接取
   上游 `Terrain::water_classification` 与 `water_surface_elevation_m`。Sekai 不再重新求海盆连通、
   湖泊溢口或初始化水位。湖泊身份 = 上游湖站点在源邻接图上的连通片。
2. **细点判据（显示、点选与格元量同一函数）。** 点 q 落在上游源 Delaunay 三角形
   （`FineTerrain::source_triangle`）内：任一角点为海且 `B(q) < 0` 为海；否则任一角点为湖且
   `B(q) <` 该湖面为湖；其余为干地。`B` 为现行规范细床（含 A3 湖床残差），不变。不判细尺度
   连通；比格元更细的形态属于呈现（§3.2）。
3. **格元量 = 同一判据的固定求积。** 每个源扇形均分 `ATLAS_CELL_QUADRATURE_LEVEL − 1` 次取
   叶心，按球面面积加权，得到海／湖／干比例、水量、床高与外露高程均值。求积层取值依据为
   对照测量 §3 的噪声底（每升一层误差约缩小 2.8 倍）与耗时，常量定义处记录。
4. **气候。** C2 及其强迫构造不变，只读取上述格元量与沿气候边按同一判据测得的海洋边比例。
5. **当前汇流。** 在源格元图上进行：陆站点沿上游粗床高的最陡下降流向邻站；湖内站点汇向
   湖根，湖根经最低的非湖邻站外泄（若该邻站高于湖面则不外泄，记为湖滞留）；海站点为终端。
   径流 = 干比例 × 面积 × 降水 × `formation_runoff_fraction`，湖面直接降水单独记账，守恒
   检查沿用 `AtlasRunoffBudget`。
6. **删除。** 全球规范水体支持网格、red/green 自适应细化、细网格 Priority-Flood 水体初始化、
   A5b 锚点有效性重判、A6 工作集许可及只服务于它们的探针。

### R1.3 可解释与可演进

- **可解释**：每个气候输入都能回溯到两件事——上游作者分类与规范细床，经一条声明的判据和
  一个声明的求积层；气候本身是既有 C2，出处见其冻结规格。
- **可演进**：格元量是（作者地形，判据，求积层）的纯函数。二阶段若以 Sekai 降水驱动侵蚀
  改变地形或分类，只需重算格元量并重跑 C2 与汇流，不涉及细尺度网格。

### R1.4 接受的代价

- 放大到格元以下时，细尺度上与海不连通、但紧邻海站点三角形的负洼地会画成海；深入一个
  三角形以外的窄海湾画成干地。它们都属于呈现，不改变真值；UI 不宣称其为独立物理水体。
- 湖泊范围按“湖角点 + 低于湖面”判定，平坦湖岸可能比细尺度连通结果更大；湖面高程以
  上游为准。
- 产物改变，`ATLAS_TERRAIN_MODEL_VERSION` 提升，旧配方按现有兼容机制提示升级。

### R1.5 验证

单场景 seed 42、Draft：守恒（初始水量 = 格元水量之和；汇流残差在 `WATER_VOLUME_RELATIVE_TOLERANCE`
内）、点选与格元量同源、分阶段耗时与端到端冷发布耗时、UI 上的海岸／气候／河网。
用户本人 UI 验收前不标记交付。

### R1.6 出处

- 上游分类、湖面与源三角剖分：固定提交 `176cc9168a69be30d1e09bfd85db84a5f3fb99da` 的
  `world.ts`（`water`、湖池）与 `mesh.ts`。
- 格元分数海陆：§8 ECMWF IFS 分块与 Balsamo et al. (2012)。
- 最陡下降汇流：O'Callaghan & Mark (1984), *Computer Vision, Graphics, and Image Processing*
  28, 323–344（项目已采用）。
