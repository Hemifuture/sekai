01 / OUTCOME

一个水线，两种主张

驱动只决定“已知量”；海面、水量与陆地占比仍由同一组物理关系闭合。

默认 陆壳比例驱动继续使用库存水量求海面，保持今日行为；新的 陆地占比驱动先选面积加权水线，再由同一测高积分反推隐含表层水量。P5 不新增分支，只消费 P3 已发布的 water_inventory_m3。

算法已进入玩家手里

07 / ACCEPT

用户验收路径

唯一仍需人工完成的门：观察海岸线、锁定状态与摘要值是否符合玩家直觉。

启动并复核默认世界

运行 cargo run --release；选择 Continents、seed 42、草稿档，以默认“陆壳比例”驱动重建。预期与 T0 交付一致，陆地约 20%。

切换到 38% 目标

选择“陆地占比”，拨到 38% 后重建。预期海岸线外推、陆架露出，摘要显示 海水量 ≈ 0.693 × 地球。

检查两端行为

拨到 60%：出现“将露出洋底”提示，深海平原成为低地；拨到 10%：内陆海淹没，仅高地露出。

回到物理模式

切回“陆壳比例”并重建。预期回到步骤 1 的画面；陆地滑块被锁定并显示实测值。
